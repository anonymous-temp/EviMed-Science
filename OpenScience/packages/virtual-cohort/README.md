# virtual-cohort

A DSH research bundle exposing native describe, start, read, report and cancel tools for the methods listed in the shared catalogue. It requires @evimed/research-plugin-runtime and @evimed/harness-port. Configure a host adapter or explicitly select standalone mode and install the existing VCR R engine; see the runtime README. No other research-domain package or recruitment plugin is required.

This is a draft: method availability is not validation for a particular population, clinical use or distribution environment. Reports must be interpreted in light of the assumptions and limitations in the underlying job and its sources.
