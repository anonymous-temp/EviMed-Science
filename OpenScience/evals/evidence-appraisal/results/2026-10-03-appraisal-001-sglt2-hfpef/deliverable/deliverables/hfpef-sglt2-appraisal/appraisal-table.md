# 证据确定性评价：HFpEF 患者 SGLT2 抑制剂能否降低心衰再住院

## 评价的问题

在射血分数保留的心衰（HFpEF，LVEF ≥40%）成人患者中，钠–葡萄糖协同转运蛋白 2（SGLT2）抑制剂（恩格列净、达格列净）能否降低心衰再住院？证据的确定性有多高？

本评价覆盖三个结局：**心衰再住院**、**心血管死亡**、**全因死亡**。评价沿用 GRADE 的偏倚风险、不一致性、间接性、不精确性、发表偏倚五个评价域与高／中／低／极低四级阶梯，但**并非经认证的 GRADE 评估**，也未署名应用 RoB 2、ROBINS-I、NOS 或 AMSTAR 2 等量表。本评价只说明证据的确定性高低，不给出任何用药建议。

## 证据集包含什么

题面给出的六项研究，按可解析程度收录为五行：

- **S1 EMPEROR-Preserved**（Anker 等，N Engl J Med 2021；NCT03057951）——恩格列净对比安慰剂的随机、双盲、安慰剂对照试验，5988 例 LVEF >40% 的慢性心衰患者。题面第六项（该试验 2022 年按 LVEF 分层的二次分析）是同一试验的伴生发表，合并计入本行，不重复计入证据体。
- **S2 DELIVER**（Solomon 等，N Engl J Med 2022；NCT03619213）——达格列净对比安慰剂的随机、双盲、安慰剂对照试验，6263 例 LVEF >40% 的心衰患者。
- **S3 五试验 Meta 分析**（Vaduganathan 等，Lancet 2022；PROSPERO CRD42022327527）——预注册的试验水平数据 Meta 分析，其中 DELIVER 与 EMPEROR-Preserved 两项 HFmrEF/HFpEF 试验（共 12251 例）提供本问题直接证据。
- **S4 瑞典心衰登记队列（2023，回顾性，倾向评分匹配）**——未评价。
- **S5 美国医保理赔数据库队列（2022，回顾性）**——未评价。

S4 与 S5 两项观察性队列未评价，原因是题面仅给出登记／理赔数据库、年份与研究设计描述，未提供 DOI／PMID／NCT 等可唯一解析的标识符；在无法唯一定位原始文献的情况下作领域评价，有替换或臆造文献的风险。这两项为回顾性队列研究，即使评价也只会以「低」确定性起步、仅作外部一致性参考，不会改变下述以随机试验为基础的结论。若补齐可解析标识符，可补评。

## 逐项研究的评价

### S1 — EMPEROR-Preserved（随机对照试验）

- **偏倚风险：低。** 随机分配、双盲、安慰剂对照、意向性分析，终点事件由设盲委员会裁定；未发现分配、盲法、失访或选择性报告方面的系统性偏倚来源。
- **间接性：低。** 人群（LVEF >40% 慢性心衰）、干预（恩格列净 10 mg 每日一次）、对照（安慰剂）与结局（心衰住院、心血管死亡）四轴均与所问问题一致。
- **不精确性：低。** 主要终点 HR 0.79（95% CI 0.69–0.90），P<0.001；总心衰住院 HR 0.73（0.61–0.88），区间窄且远离 1。心血管死亡与全因死亡等次要结局区间跨 1，其不精确性在结局层面处理。

### S2 — DELIVER（随机对照试验）

- **偏倚风险：低。** 随机分配、双盲、安慰剂对照、意向性分析，终点由设盲委员会裁定。
- **间接性：低。** 人群、干预、对照与所问问题一致；主要终点中的「心衰恶化」组分包含计划外心衰急诊就诊，较单纯「心衰再住院」略宽，在心衰再住院结局层面说明。
- **不精确性：低。** 主要终点 HR 0.82（0.73–0.92），P<0.001。心血管死亡 HR 0.88（0.74–1.05）跨 1，在结局层面处理。

### S3 — 五试验 Meta 分析（系统综述）

- **偏倚风险：低。** 预注册方案、试验水平个体数据、统一终点定义、固定效应合并；成分试验均为低偏倚 RCT。
- **间接性：低。** 其 DELIVER + EMPEROR-Preserved 两试验子集直接针对 HFmrEF/HFpEF 人群与心衰住院、心血管死亡结局。
- **不精确性：低。** 主要复合终点区间窄（两试验子集 HR 0.80 [0.73–0.87]；五试验 HR 0.77 [0.72–0.82]）。心血管死亡（0.88 [0.77–1.00]）与全因死亡（0.92 [0.86–0.99]，五试验）区间触及或紧贴 1，在结局层面处理。

## 每个结局的确定性

### 心衰再住院 —— 确定性：高

随机试验体以「高」起步，未作任何降级（偏倚风险 0 步、不一致性 0 步、间接性 0 步、不精确性 0 步、发表偏倚 0 步）。

- 两项试验与合并分析方向、量级一致：EMPEROR-Preserved 总心衰住院 HR 0.73（0.61–0.88），DELIVER 心衰恶化 HR 0.79（0.69–0.91），两试验合并首次因心衰住院 HR 0.74（0.67–0.83），均显著低于 1。
- 合并估计区间上界 0.83 远低于 1，精确度足以支持「降低心衰住院」的判断。
- 结局直接针对心衰住院（合并分析采用「首次因心衰住院」；DELIVER 单个估计的「心衰恶化」含急诊就诊，略宽但不改变方向）。

**什么会改变这一判断：** 一项以心衰住院为主要终点、设计良好的独立随机试验若显示 HR 跨越 1，或发现两项试验存在选择性报告，可使确定性下降。

### 心血管死亡 —— 确定性：中

随机试验体以「高」起步，因**不精确性降一级**（偏倚风险 0 步、不一致性 0 步、间接性 0 步、发表偏倚 0 步）。

- 方向一致：DELIVER 心血管死亡 HR 0.88（0.74–1.05），两试验合并 0.88（0.77–1.00），五试验合并 0.87（0.79–0.95）。
- 两试验合并区间上界触及 1.00，不能排除无心血管死亡获益，故降一级。

**什么会改变这一判断：** 更多 HFpEF 特异的心血管死亡事件或更长随访使区间收窄并远离 1，可升至高；若区间稳定跨 1，则确认无获益。

### 全因死亡 —— 确定性：中

随机试验体以「高」起步，因**不精确性降一级**（偏倚风险 0 步、不一致性 0 步、间接性 0 步、发表偏倚 0 步）。

- HFmrEF/HFpEF 两试验的全因死亡效应未在已核实摘要中单独报告；五试验合并全因死亡 HR 0.92（0.86–0.99）紧贴 1，且主要由 HFrEF 试验驱动。就 HFpEF 人群而言，全因死亡获益不精确。

**什么会改变这一判断：** HFmrEF/HFpEF 亚组的全因死亡个体水平合并估计若区间远离 1，可升至高；若无获益则维持较低确定性。

## 一句话结论

在 LVEF ≥40% 的心衰患者中，SGLT2 抑制剂（恩格列净、达格列净）降低心衰再住院的证据确定性为**高**；降低心血管死亡与全因死亡的证据确定性为**中**（区间触及或跨越 1，不能排除无获益）。本评价不据此给出任何用药建议。
