# R10 numerical review — synthetic conversations

This is an independent local numerical replay of retained synthetic scenarios, not a replay of the historical database or a recovery of deleted tables. The historical R10 engine image was found in Docker context `colima-evimed-extension-acceptance` (digest `sha256:d66e31b64afcd38415de841a3f8130422fc9e915353f960a414c4df85dfd4773`); the earlier statement that it was unavailable resulted from inspecting the default context. In isolated, network-disabled, read-only containers, all 52 files under its `/engine/R` matched the separately frozen replay source manifest `f740d8754096cd478d38c0faa3defb44c5c673106942a8932c864a8240cd22a8` byte for byte by SHA-256. Both runtimes report R 4.3.3 on aarch64, and all 70 installed library package versions match; package binary bytes were not compared. The replay therefore uses the same recorded engine source and package versions, not necessarily an identical runtime image. Method versions are checked against the retained transcript. Ordinary exported historical table bytes remain unavailable; model narratives and clinical claims are outside this numerical review. No model API was called and no real patient row was read.

All 35 extracted start scenarios were attempted, excluding the canceled large job; one rejected analytic input was refused again by the replay. The underlying outcome and design assumptions were taken from tool inputs, with explicitly identified host defaults. Identical replay numbers establish reproducibility under the local engine and retained inputs, not independent statistical validation of every algorithm. For completed results where the structured terminal response was parseable, every overlapping numerical measure matched within 1e-8 relative/absolute tolerance. Some tool responses are truncated, so their visible terminal state and early measures are distinguished from a fully parsed result.
