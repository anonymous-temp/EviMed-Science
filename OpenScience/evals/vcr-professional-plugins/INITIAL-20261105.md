# Full-data local engine evaluation

`./run.sh` reads the private inputs in `.evimed-local/acceptance/vcr-benchmark-20261029/numeric` and writes only to `.evimed-local/acceptance/vcr-professional-full-20261105/clinical`. It runs the current checked-out R engine with network disabled, 2 CPUs, 6 GiB and image `evimed-vcr-native-numeric:20261026`. Scripts produce private input and result files, including patient-level data; do not publish them. Use a clean checkout and record its revision and image digest before a repeat. No model API is used. The full synthesis requests five copies with seed 20261029 and 2400 CPU seconds; this image lacks `synthpop`, so it cannot complete that method without a qualified image. Failures are retained as result JSON or task logs and exit files.

To prepare the private library from this workspace, run `python3 OpenScience/evals/vcr-professional-plugins/download_locked_packages.py` from the repository root. It downloads the runtime lock entries and the 2026-09-28 snapshot index to the private acceptance directory. Then run the following isolated install; `r-library.sh` installs and verifies all 70 versions before succeeding:

```sh
mkdir -p .evimed-local/acceptance/vcr-professional-full-20261105/rlib
docker run --rm --network none --cpus 4 --memory 8g \
  -e VCR_R_LIBS=/rlib -e VCR_R_LOCKS=runtime -e VCR_R_BUILD_NCPUS=4 \
  -e VCR_CRAN_REPO=file:///cran -e VCR_ENGINE_ROOT=/repo/项目代码/vcr-engine \
  -v "$PWD:/repo:ro" \
  -v "$PWD/.evimed-local/acceptance/vcr-professional-full-20261105/cran:/cran:ro" \
  -v "$PWD/.evimed-local/acceptance/vcr-professional-full-20261105/rlib:/rlib" \
  --entrypoint bash evimed-vcr-native-numeric:20261026 \
  /repo/OpenScience/scripts/vcr/r-library.sh install
```

The package versions are locked but the remote archive bytes are not individually pinned by this downloader. Retain the private package mirror, library and installation receipt for reproducibility; verify byte hashes separately before treating a later download as the same input.
