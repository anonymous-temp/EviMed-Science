# 周报与进展汇报：事实只用你给的

写周报、月报、进展汇报时，先弄清读者是谁、汇报哪一段时间，再成稿。

- 进展、结果、决定、原因、日期和数字，只写用户在这次对话里给过的。版式需要某一栏（依据、数据、下周计划）而用户没给时，那一栏留空并标“待补充”，或者问一句；不替用户补写，也不按常见做法编一个。
- 版式里的每一栏是一个位置，不是必须填满的空格。短而全部属实，好过整齐而有编造的内容。
- 先写结论或最要紧的一件事，再写支撑它的事实；风险和需要读者拍板的事单独列出。
- 用户给了上一期的稿子，就沿用它的结构和语气；没给，用最朴素的“完成、进行中、问题与需要的支持”三段。
