返回账号设置

把自己的智能体接到记忆胶囊

在账号设置的「外部智能体访问」为每个客户端分别创建密钥。网页、Claude Code 和 Codex 可使用同一账号的记忆，并分别核算用量。保存首次显示的完整密钥到只有本人可读的本地文件。撤销后新请求立即被拒绝。

第一次请求

所有请求经 HTTPS 发到部署地址的 /api/agent-memory/v1。在本机设置 BASE 为该完整地址、KEY_FILE 为密钥文件绝对路径。下例将请求头从标准输入交给 curl。

auth() { printf 'Authorization: Bearer %s\n' "$(cat "$KEY_FILE")"; }
auth | curl -sS -H @- "$BASE"
auth | curl -sS -H @- -H 'Content-Type: application/json' \
  -d '{"query":"我偏好怎样呈现分析结果？","limit":3}' "$BASE/recall"

首个请求返回密钥权限、项目绑定和 capabilities。项目密钥只能访问绑定项目。个人密钥的主体由签发账号决定。机构集成密钥由宿主把已登录人员的稳定标识放在 X-Subject 请求头中。

选择权限

权限允许的操作
memory.read默认权限。检索记忆和做法，读取看板和开场背景。
memory.history.read与读取权限合用，并显式请求 include: ["history"]，读取授权范围内的对话片段。
memory.write提交待本人确认的笔记或对话候选。
memory.remember用 /remember 提交本人明确要求记住的原话、客户端、会话标识和时间。
memory.ingest受信宿主提交本人参与的真实会话。以固定 sessionId、attended: true 和带 role、text、saidAt 的 messages 数组调用 /conversations。相同内容重试返回同一回执。
learning.signal用 /work-events 提交已完成会话中一句人类反馈的序号、UTC 时间、原文和所用记忆或做法。服务端核对来源并裁决。
memory.share账号级分享、接收、导入和撤回。按网页的分享范围和接收身份执行。
memory.manage本人授权的确认、编辑、忘记、恢复、设置及机构主体删除。
memory.observe登记支持的处方编辑观察。
analysis.read / analysis.write数据分析 API 的独立权限。

限额与计费

每账号最多 20 把有效密钥，每分钟每密钥 120 次、账号合计 360 次。JSON 请求最多 256 KiB，分享指令最多 16 KiB，文件包预览和导入最多 256 KiB，响应最多 1 MiB。结果过大时缩小查询或分页。

抽取、模型判断和需要模型的检索按签发账号及密钥记录用量。余额和日、周额度在调用前检查。使用记录与钱包结算分别可查。缺少实测回执的检索标为待核实。撤销密钥保留既有用量。

忘记一条陈述

用有 memory.manage 权限的账号级密钥向 POST /forget 发送 {"statement":"我每周五下午去打羽毛球。"}。陈述一经受理，匹配内容即从检索、开场背景和记忆列表隐藏。

读取 data.forgetStatus。requested 表示已受理，pending_verification 表示正在核验，executed 表示已执行，not_executed 表示未执行。若返回 data.requestId，用同一权限查询 GET /forgotten?requestId=…。请求执行失败后解除临时隐藏。原始对话继续保留，可单独删除。

处理返回值

401 检查密钥及有效期。402 检查余额和用量额度。403 检查权限、项目或学习开关。404 检查目标。409 重新读取资源版本，检查同一会话标识的内容。413 缩小请求或结果。429 等到下一分钟。503 查看服务状态和部署开关。成功的异步提交仍需读取回执中的 state，只有 completed 表示抽取已结束。

DSH 可从已打包的 tgz 安装 @evimed/dsh-memory-capsule，在配置中设置 baseUrl 和 apiKeyFile。MCP 可安装 evimed-memory-mcp 的 wheel，以同名命令启动 stdio，设置 EVIMED_MEMORY_API_URL 和 EVIMED_MEMORY_API_KEY_FILE。两种连接器均可先调用 status 检查权限。
