# 文档结构化解析 API



## 请求



### 本地文件解析

#### 接口信息

- **请求路径**：`/api/v1/extract/text/file`
- **请求方法**：`POST`
- **Content-Type**：`multipart/form-data`

#### 请求参数

**表单数据（multipart/form-data）**

| 字段        | 类型   | 必填 | 描述                                                         |
| :---------- | :----- | :--- | :----------------------------------------------------------- |
| `file`      | File   | 是   | 上传的文件                                                   |
| `checksum`  | String | 是   | 文件校验码（SHA256），用于验证上传文件的完整性。               |
| `filename`  | String | 否   | 原始文件名（含扩展名）。未提供时服务端尝试从文件元数据中获取。 |
| `format`    | String | 否   | 文件格式标识（不含点号，如 `pdf`、`docx`）。未提供时服务端根据文件名扩展名自动检测。设置为 `auto` 表示自动检测。 |

**请求示例（curl）**

```bash
curl -X POST http://localhost:8888/api/v1/extract/text/file \
  -F "file=@/path/to/test.docx" \
  -F "checksum=eb718aa07fb938026a1c7536025f7711088763302a960169ebae4599ca30d555" \
  -F "filename=test.docx" \
  -F "format=docx"
```



### 网络文件解析

#### 接口信息

- **请求路径**：`/api/v1/extract/text/url`
- **请求方法**：`POST`
- **Content-Type**：`application/json`

#### 请求参数

**请求体（application/json）**

| 参数名     | 类型   | 必填 | 描述                                                         |
| :--------- | :----- | :--- | :----------------------------------------------------------- |
| `url`      | String | 是   | 网络文件的完整地址（仅支持 HTTP/HTTPS 协议），服务端将下载该文件并解析。 |
| `filename` | String | 否   | 指定文件名（含扩展名）。若未提供，从 URL 路径尾部或 `Content-Disposition` 响应头中推断。 |
| `format`   | String | 否   | 文件格式标识（不含点号，如 `pdf`、`docx`）。未提供时根据文件名自动检测。 |

**请求示例**

```json
{
    "url": "http://example.com/document.pdf",
    "filename": "document.pdf",
    "format": "pdf"
}
```

```bash
curl -X POST http://localhost:8888/api/v1/extract/text/url \
  -H "Content-Type: application/json" \
  -d '{"url": "http://example.com/document.pdf", "filename": "document.pdf", "format": "pdf"}'
```



## 响应



### 响应参数

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "title": "某项临床研究的标题",
    "authors": ["张三", "李四"],
    "abstract": "本研究旨在评估……",
    "keywords": ["循证医学", "临床决策"],
    "publication_date": "2024-01-15",
    "source": "中华医学杂志",
    "doi": "10.1234/example.2024.001",
    "content": "文档的完整正文内容..."
  }
}
```

| 字段    | 类型   | 说明                                             |
| ------- | ------ | ------------------------------------------------ |
| code    | int    | 业务状态码，`200` 表示成功，其他表示异常。       |
| message | string | 提示信息，成功时为 `success`，失败时为错误描述。 |
| data    | object | 业务数据，详见下方 data 字段说明。               |



### 状态码

| code | 含义                            | message          |
| ---- | ------------------------------- | ---------------- |
| 200  | 请求成功                        | success          |
| 400  | 参数错误                        | 参数错误         |
| 404  | 资源不存在（如 `task_id` 无效） | 资源不存在       |
| 413  | 文件大小超过限制                | 文件大小超过限制 |
| 415  | 不支持的文件格式                | 不支持的文件格式 |
| 422  | 校验失败                        | 校验失败         |
| 500  | 服务器内部异常                  | 服务器内部异常   |
| 502  | 服务器上游异常                  | 服务器上游异常   |



### data 字段说明

当请求成功（code=200）时，data 字段包含解析结果。其中 `content` 为文档解析得到的完整正文，其余字段由大模型从正文中**抽取**得到（仅提取原文真实存在的信息，不做总结或推断；未找到的字段返回 `null`）。

```json
{
  "title": "某项临床研究的标题",
  "authors": ["张三", "李四"],
  "abstract": "本研究旨在评估……",
  "keywords": ["循证医学", "临床决策"],
  "publication_date": "2024-01-15",
  "source": "中华医学杂志",
  "doi": "10.1234/example.2024.001",
  "content": "文档的完整正文内容..."
}
```

| 字段             | 类型                   | 说明                                   |
| ---------------- | ---------------------- | -------------------------------------- |
| title            | string or null         | 标题                                   |
| authors          | array(string) or null  | 作者列表                               |
| abstract         | string or null         | 摘要                                   |
| keywords         | array(string) or null  | 关键词列表（原文标注的关键词）         |
| publication_date | string or null         | 发表/出版日期，尽量保留原文格式        |
| source           | string or null         | 来源（期刊、会议或出版方）             |
| doi              | string or null         | 数字对象标识符（DOI）                  |
| content          | string or null         | 文档的完整正文内容                     |



## 支持的文件格式

| 文件类型           | 格式                                                         |
| ------------------ | ------------------------------------------------------------ |
| PDF                | `.pdf`                                                       |
| Word               | `.doc`、`.docx`                                              |
| PPT                | `.ppt`、`.pptx`                                              |
| Excel              | `.xls`、`.xlsx`、`.xlsm`                                     |
| 图片               | `.jpg`、`.jpeg`、`.png`、`.bmp`、`.gif`                      |
| 音视频（暂不支持） | `.mp4`、`.mkv`、`.avi`、`.mov`、`.wmv`、`.mp3`、`.wav`、`.aac` |
| 其它文档           | `.epub`、`.mobi`、`.htm`、`.html`、`.md`、`.rtf`、`.txt`     |
