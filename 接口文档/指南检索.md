# EviMed 指南检索 API

完整公共约定见[EviMed 医学证据检索 API](./EviMed医学证据检索.md)。生产密钥只能在
SaaS 服务端注入；下面只使用环境变量占位符。

## 指南记录检索

`POST /review/api/guide`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `query` | string | 是 | 自然语言检索词 |
| `count` | integer | 否 | 默认 10，上限 100 |
| `startYear` / `endYear` | integer | 否 | 发表年份范围 |
| `publishers` | string[] | 否 | 发布机构，支持模糊匹配 |
| `language` | string | 否 | `zh` 或 `en` |

```bash
export EVIMED_BASE_URL='https://www.evimed.com/api-evimed/medicine-api/ai-api'
export EVIMED_API_KEY='replace-with-your-key'
curl -X POST "${EVIMED_BASE_URL}/review/api/guide" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${EVIMED_API_KEY}" \
  -d '{"query":"高血压治疗","count":10,"language":"zh","startYear":2022}'
```

响应 `data.total` 和 `data.list[]`；记录可包含 `title`、`year`、`publisher`、
`summary`、`publicationDate`、`fullText`、`language` 和 `url`。

## 指南文本块检索

`POST /review/api/guide-block`

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `query` | string | 是 | 问题、疾病或药物检索词 |
| `language` | string | 否 | `zh` 或 `en` |
| `publisher` | string | 否 | 单个发布机构模糊过滤 |
| `startYear` / `endYear` | integer | 否 | 发表年份范围 |

```bash
curl -X POST "${EVIMED_BASE_URL}/review/api/guide-block" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${EVIMED_API_KEY}" \
  -d '{"query":"糖尿病胰岛素起始治疗","language":"zh","publisher":"中华医学会","startYear":2022}'
```

响应 `data` 可包含：

- `query`、`keywords`、`total` 和药名查询时可能出现的 `enrichedQuery`；
- `guides[]` 中的 `guideId`、`year`、`title`、`introduction`、`formulator`、
  `language`、`publicationDate`、`blocks[]`、`rerankScore`、`rerankRank` 和 `url`。

`publisher` 支持模糊匹配。可选参数不用时必须省略；接口默认只返回最新版本。文本块和
精排分数是定位工具，不能脱离完整上下文形成临床建议。关键结论必须核对完整指南、版本、
发布日期、适用人群和推荐强度。
