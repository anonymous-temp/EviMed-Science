# EviMed 指南检索 API

本文件是指南检索调用的简明说明。完整公共约定见
[EviMed 医学证据检索 API](./EviMed医学证据检索.md)。

## 调用

```bash
export EVIMED_API_KEY='replace-with-your-key'
curl -X POST "https://www.evimed.com/api-evimed/medicine-api/ai-api/review/api/guide" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ${EVIMED_API_KEY}" \
  -d '{
    "query": "高血压治疗",
    "count": 10,
    "language": "zh",
    "startYear": 2022
  }'
```

禁止在示例或源码中放入真实 API Key。生产环境必须从服务端 secret file 或受管密钥服务
读取；客户端只提交业务参数。
