# 记忆胶囊：展示与使用优化方案（2026-09-19）

对象：`main@beece9231`，生产发布 `evimed-5a78008d89ba-1`。方式：只读。我从本机全部 42 个历史会话里抽出了你本人关于记忆、胶囊、自迭代、OpenViking 的 82 条原话（Codex 会话在本机为空），读了规格 §19/§23/§26–§28、自进化方案、09-15 对外产品方案、09-16 与 09-18 两份核查报告，逐文件核对了线上前端与服务端，只读查询了生产库的聚合数字，并联网核实了同类产品在 2026 年的做法。**没有改任何代码，没有改任何数据。**

## 0. 结论

**线上页面展示的是三张数据库表，不是"一个胶囊"；而唯一有内容的那张表，八成是系统写给自己的笔记，不是对你的理解。** 你设想里最看重的四件事——融合成一个胶囊、时间轴看成长、切换成别人的胶囊即插即用、资料经分析层持续进入胶囊——前两件在服务端没有实现，第三件只做到了文件级导出导入，第四件在知识库那一头是断头路。另外有两处使用层面的硬伤：自迭代回路在默认配置下无法启动，生产上胶囊的召回索引还没部署。所以顺序是：先把"什么进来、算谁的"改对，再让回路能转，然后才是重新摆页面。

**代码核实的七件事。**

1. 抽取提示词是英文，没有输出语言要求，并且主动要求把工具结果"记成 analysis 或 project_fact、来源 system、保留数字"（`memoryIntelligence.mjs:950-952`）。药物不良反应谱进"分析要素"是设计内行为。来源为 system 的条目不需要确认就生效（`:324-337`）。"Reinforced:" 不在任何代码里，是提示词里两次出现的 reinforce 说法被模型写进了摘要，旧摘要又回喂给模型，前缀自我延续（`:954-972`）。
2. 平台注入过滤只认 4 种标记，平台实际发出 18 种 `<evimed-*>` 标签；助手正文没有任何平台词汇过滤。
3. 学习回路的两个触发器：同一份交付物既点「采纳」又点「我改过」才入队（`feedbackEvents.mjs:392-420`）；"修复后通过"要求服务端修复轮 ≥1（`server.mjs:1621-1623`），而 09-17 裁决后这个值默认是 0（`config.mjs:793-794`）。**默认配置下第二个触发器不可能触发，第一个要用户做两个动作。** 学习方法页的说明文案与此不符。
4. 学到的方法现在确实会挂载（`capsuleMethods.mjs:384-392` 调 `selectLearnedMethods`），我 09-10 报告的那个断点已修。
5. 三种激活模式里，代码只区分 own 和非 own，guest 与 blend 行为完全相同（`capsuleService.mjs:135-154,239-244`）。导入的胶囊条目全部是待确认，要逐条点采用，采用后只有四类会挂载成技能（`capsuleMethods.mjs:43-48`），对方的画像和立场不进常驻画像。界面看不到当前哪个胶囊生效，不能停用，只能按项目启用。
6. 时间轴只有域里的词表和容器里的文件路径（`capsule.mjs:70-81,105`），服务端没有任何写入方或读取方。
7. 敏感记录在两条召回路径里都被丢弃（`memorySubstrate.mjs:137,245`），但确认弹窗写的是"生效后，它会在后续研究中被读取"（`MemoryPage.tsx:509`）。

**已有但界面没露出的数据**：每条记忆的完整修订史（内容、原因、时间）、范围、来源类型、带过滤的检索接口；每次运行实际召回了哪几条记忆、挂了哪几条方法（`agentRuns.mjs:580-598`，前端对后者零引用）；方法的来源任务、层级、关系、各类计数、评测报告；当前生效胶囊的查询接口；外部 agent 记忆 API 和密钥管理接口（前端零引用）。

## 3. 差距的根因

1. **界面按存储模型摆，不按你的心智模型摆。** 记录、胶囊条目、方法文档是三张表，于是成了三个标签。你要的是"一个我"。
2. **"对你的理解"这个标题名不副实。** 原则 18 要求区分用户陈述、工具事实、助手推断、用户确认的结论，推断不得自动晋升为事实。现在工具事实和助手自述以 system 来源直接生效，和你的画像摆在同一面墙上。
3. **回路没有输入。** 生产上交付物采纳事件为 0，触发条件又过严，所以"学习方法"永远是空的。空不是因为没什么值得学。
4. **知识库和胶囊没接上。** V1、V2 的"融合"在数据层不成立。
5. **胶囊在生产上基本是盲的。** 词法兜底对胶囊事实的召回在评测里 16 问全空，语义索引又没部署。

## 4. 方案

### 4.1 先把内容弄对（否则怎么摆都不对）

- **分三条来源通道，界面分区呈现。**「你说的 / 你确认的」→ 理解；「在任务中观察到的」（推断）→ 理解，标注观察次数，未经确认不进账号级；「任务产物」（工具结果、分析结论、项目决定）→ **项目档案**，属于经历层，不叫"对你的理解"，只在本项目内带着出处被引用。运行摘要只进时间轴，不计入"已生效"。
- **语言与前缀。** 抽取提示词加一句"用用户的语言写摘要，不加 Reinforced 之类的前缀"；对存量做一次只重写摘要、不动原值的中文化作业。
- **平台词汇不进用户记忆。** 用闭集词表（从 `toolNames.mjs` 和契约词表派生，属于原则 5 允许的闭集检查）在写入侧拦下关于平台自身机制的陈述。这类教训属于平台手册回路（自进化方案 §6.6），不属于用户的胶囊。
- **去掉模型手打的置信度百分比**（原则 10c）。换成可数的强度："你说过 3 次"、"在 4 次任务中观察到"、"你确认过"、"上次用到 9-18"。
- **敏感记录**：行为保持不召回，把确认弹窗改成实话。
- 以上都是写入侧卫生，不是对话门禁：不拦任何问题，只作用于写入这一个操作，有生产复现，符合原则 20 的五问。

### 4.2 信息架构：一个胶囊，六个分区

导航项改回你自己的叫法「记忆胶囊」。默认**一人一个**，注册即建，中文标题（现在自动建的那个叫 "Research memory"）。"新建胶囊"收起来；别人分享来的放在独立的"收到的"货架。页面六个分区对应规格 §19.19：

| 分区 | 内容 | 对应现在的 |
|---|---|---|
| 总览 | 一页可读的"EviMed 眼中的你"、健康度、当前生效的工作方式、待你看一眼 | 无 |
| 资料 | 知识库的整理台视图：每份资料产出了几条理解、几条方法线索 | 知识库（导航保留，数据打通） |
| 理解 | 画像与事实，按主题折叠 | 「记忆」标签的四列看板 |
| 方法 | 一个列表，来源徽标：你写的 / 从任务中学到的 / 来自资料 / 来自 A 的胶囊 | 「方法胶囊」条目 +「学习方法」两处 |
| 时间轴 | 成长视图 | 无 |
| 分享 | 发出去的、收到的、连接外部 agent | 导出导入面板 |

"理解"这个名字顺带解决 09-18 附录 B 指出的"记忆里套记忆"。

### 4.4 理解层：主题文件，不是看板

按主题折成十到二十组，列表行只放一句话，展开才见全文、证据原话（可跳到来源片段或运行步骤）、完整修订史、有效期（"3 月到 8 月如此，之后被下一条取代"）。筛选：来源、范围（跟着我 / 仅本项目）、新、待确认、已失效。搜索接到已有的过滤接口。待确认的放在顶部小托盘，三个按钮"是这样 / 不是这样 / 改一下"，收件箱通知上放同样三个键（09-16 报告 M4① 至今未做）。去掉"科研记忆服务已连接"徽标（只在降级时出现）、"疑似任务题面"这类引擎词汇；"已开启"按钮换成真开关。

### 4.5 在对话里感到胶囊在起作用（"使用"的核心）

```
本次用到的背景
  理解 · 你偏好中文、结论先行                    [不对]
  理解 · 课题：老年人阿司匹林一级预防             [不对]
  方法 · 证据分级先看设计再看偏倚（你写的 v3）     [本次不用]
  来自李主任的胶囊 · 超说明书评价五步法 v2         [停用]
本轮新记下 1 条，待你确认 ▸
```

- 对话右栏一个"本次用到的背景"面板。数据已经有：派发时的召回清单和挂载清单都写在运行账本里，记忆页也已支持按记录高亮。这是 ChatGPT 2026-05 上线的 Memory sources 同一个模式。
- 会话顶部身份条："以你的身份"或"以你的身份 · 按李主任的方式"，点击切换或停用。
- 抽取写入后一条轻提示"记下了 1 条：……  撤销"。
- 新方法首次被采用时，回复里说一句"本次按你的新方法 X 执行，如不对请说"。规格说这句话就是审阅，不需要审批流。
- 选中文本"记到胶囊"；明说"记住……"的立即生效。
- 运行详情里的"个性化依据"显示内容而不只是种类，并列出本次带着的方法。

### 4.6 时间轴：成长

不新建写入方。用已有账本在读取时派生：记忆的修订史、运行账本、反馈事件、方法修订、资料入库、胶囊启用与导出。派生视图不会出现"忘了写"的空洞。

```
2026  ▁▂▅▇▃▁▂…      ■资料入库  ■理解变化  ■方法
第 38 周
  9-18  任务 · 阿司匹林一级预防（用了 3 条理解、2 条方法）→ 学到 1 条
  9-17  理解变化 · "只看 RCT" → "RCT 优先，接受高质量队列"（因：你在任务里纠正）
  9-16  方法采用 · 证据矩阵先行 v2（3 次成功，评测不劣）            [回到 v1]
  9-15  资料 · 导入网盘"课题-心衰"32 份 → 9 条候选理解
```

顶部一条年度密度带，点格子过滤下方事件流。事件卡显示前后对比，被取代的事实标"曾经如此"而不是消失，这就是"变化和成长"。每季度生成一份"科研回顾"，写明统计口径，走收件箱。不做打卡、徽章、排行。

### 4.7 分享与切换：把"即插即用"做实

```
李主任的工作方式 v3          签名已验证 · 指纹 9f3a… · 2026-09-12
  内含：方法 7 · 标准与偏好 5 · 背景知识 12（心衰用药）
  不含：原始对话、患者数据、原文件、任何密钥
  方法一览：① 超说明书用药循证五步法 — 何时用：……
  [试用一次]    [按他的方式]    [只借方法]                 [以后再说]
```

- **整包信任，一键生效。** 现在导入后要逐条采用，这和"即插即用"直接矛盾。建议信任边界放在包上：签名已验证、内容已预览、随时可停。启用期间对方的条目以"客体上下文"生效，停用即全部退出，永远不混进我的胶囊，想留下的逐条"收为己用"。方法只是可读文本，不能放宽任何契约，这一点不变。
- **试用一次**：临时会话、不写我的记忆、有额度上限。规格称这是采纳率的关键，至今没做。
- 两种模式要么在代码里真的不同（"按他的方式"：对方的标准覆盖我的；"只借方法"：标准仍用我的），要么先只上一种。
- 账号级启用，项目可覆盖；任何时候看得到谁在生效；冲突时回复里点明"本次按李主任的方式"。
- 发送：三步向导，"对方会看到什么"按接收方视角实时预览，脱敏报告内联；站内按用户名投递、链接（30 天、一次性）、文件三种；"我发出去的"列表含接收状态、启用计数、推送新版、撤回（复述"只影响未来版本"）。新版本到达时收件箱给方法级对比。
- 格式保持 `.evimedcap`（Ed25519 签名加 AES-GCM）。OpenViking 自己的导出包官方写明"不是可信发布格式"，我们的签名包正好补这一块。

### 4.8 资料 → 分析层 → 胶囊

补上那条缺失的发布路径：资料理解的产出进入胶囊的候选，来源标"资料"，**停在待确认**，直到你确认或被你自己的行为印证。这不是保守：2024–2026 年已有多起经由记忆持久化的提示注入（SpAIware、Gemini 延迟工具调用、微软 2026-02 披露的"AI 推荐投毒"），"上传 → 分析层 → 记忆"是同一条路径。展示上按规格的整理台：类型、五维价值小条、深度、覆盖率、产出数、成本、判定理由；每份资料一张结果卡"摘要 · 候选理解 n 条 · 方法线索 n 条 → 全部采纳 / 逐条看"。冷启动向导：5 篇代表作加 1 份方案加 1 份 SOP，十分钟出第一版画像和方法草稿；再加一个粘贴导入（Claude 已有现成的导入流程可参照）。

### 4.9 让自迭代看得见，而且转得起来

- **先改启动条件**：单独的「采纳」就把这次成功轨迹送去蒸馏；"修复后通过"按运行内的修复次数算（交付物的 attempts > 1），不再依赖已关闭的服务端修复轮。「我改过」要带上改动对比，这是最值钱的信号。
- **诚实的空态**：不写"还没有方法"，写"已完成任务 12 · 你采纳 0 · 可学习的轨迹 0。采纳一份交付物，EviMed 才会从中学习"，并链接到运行记录。
- 方法卡露出接口已返回但没用的字段：从哪几次任务学到、用过几次成功几次、最近用在哪、评测结论、还差什么、层级与关系。
- 夜间整理的通知现在是静默且不可跳转的，改成一条"学习动态"：昨晚整理 3 条、合并 1 条、提议停用 1 条，每条有回滚目标。

### 4.10 OpenViking：怎么用，怎么展示

关系是**协同不是包含**：记录永远在 PostgreSQL，OpenViking 是研究记忆与胶囊事实共用的派生召回索引，可重建。当务之急是**把它部署上生产**（需要你在主机上放 DashScope 密钥文件并拉镜像），否则胶囊召回是盲的。上游 09-14 发了 v0.4.20，新增用户记忆策略预设、Agent Experience 模块和 Web Studio，值得按"实测再采纳"的规矩评估升级。可借给终端用户的展示有三样：三个根（资料 / 记忆 / 方法）的只读上下文树作为胶囊的"浏览"模式，目录说明用一句话摘要；每次回答"取用了哪些条目"，就是 4.5 的面板；每次会话的记忆前后对比，就是 4.6 的事件原子。Studio 留给运营排查检索，不给终端用户。私有资料是否也进同一索引，建议分步：先把资料理解的产出作为胶囊知识层进索引（小、派生），原文分块检索不动，用 `evals/memory-recall` 量过再决定。

### 4.11 对外连接与主动科研

外部 agent 的 API 和两工具 MCP 已有、默认关。缺的是密钥管理界面：放在"分享 › 连接"下，创建（范围、绑定项目）、只显示一次、吊销；外部写入单列一条来源通道，恒为待确认。是否对外发布仍等消融给出一个数。主动科研从胶囊取种子：根据当前课题和资料层里还没被分析过的数据集给出议程**建议**，由你点头，不自选课题。
