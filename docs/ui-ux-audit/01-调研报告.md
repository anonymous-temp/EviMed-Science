### 1.2 核心页 LiveSessionPage 详解

- **草稿机制**：`/live` 无 id 时为本地草稿（`DRAFT_KEY`），首条消息创建会话并 `navigate(/live/:id)`，草稿线程平移嫁接不闪屏（`LiveSessionPage.tsx:78-90`、`runtime.ts:536-587`）；首消息自动建 `~/Documents/EviMed/<日期-时间>` 工作目录。
- **空态**：连接就绪且空草稿 → `WorkflowStarters`（4 张工作流入口卡）；`?agent=<id>` → 专项 agent 头卡（分类/描述/建议输入/starter prompt 胶囊）。
- **骨架屏**：`ThreadSkeleton`（全应用唯一骨架屏，模拟用户卡+文本行+工具行形状）。
- **发送/运行双锁**：`sending`（点击→POST 受理）+ `runningSessions`（受理→`session.idle`），工作中发送键同位变形为 Stop。
- **工作指示**：底部打字指示器 = spinner + 情景文案（"正在创建任务空间…/正在执行…/任务已暂停…"）+ 当前运行工具名 + 秒级 `Elapsed`。
- **中断**：Esc（尊重 `e.defaultPrevented` 与已开 dialog）或 Stop 钮 → 线程末尾追加「已中断」status-line；15s `reconcileRunning` 轮询兜底丢失的 idle；WKWebView 60s 杀 fetch 用 `sseSeq` 序号判定。
- **错误**：线程内红字 status-line + 页级 banner（无会话归属时）+ 连接帮助卡；`userFacingRuntimeError` 错误码中文化（但硬编码了 "DeepSeek V4 Pro" 文案，`runtime.ts:64`）。**无重试按钮**。
- **滚动**：`useScrollMemory` 按会话恢复滚动位置；**流式期间无自动滚底、无「回到底部」按钮**（全库无 `scrollIntoView`）。

### 1.3 消息渲染与流式体系

`BlockList.tsx` 分发 9 种 block，但 **figure/table/running-jobs/step-summary 四类只由 mock 数据产生，生产环境永不出现**（图批注这个差异化交互实际不可见）：

- 用户消息：`bg-surface-2` 气泡，**无 `whitespace-pre-wrap`，多行输入被并成一行**（`atoms.tsx:15-21`）。
- Agent 消息：`MarkdownViewer`（react-markdown + remark-gfm，**聊天代码块无语法高亮**，highlight.js 仅 inspector 用）；文末提到的文件名经 `extractArtifactRefs` 验证存在后渲染为可点预览 chip。
- 工具调用：连续 quiet 步折叠为 `ToolGroup`（中文动词计数摘要 "执行了 3 个命令，创建了 1 个文件"），运行中自动展开、结束 2s 后折叠；bash live stdout 250ms 节流、`\r` 进度条折叠、live tail 8 行常显、cap 4KB/64KB；失败计数徽标；子 agent 行下挂脉冲活动行。**文本 token 不节流**，逐 delta 整树重渲染 ReactMarkdown，长回复流式期间主线程压力大。
- 核查卡 `ReviewerCard`：```review fence → 结构化发现卡（级别徽标 + 检查类型 tag + 单条忽略），是"可追溯"唯一专门 UI；文献引用仅靠普通 markdown 链接。
- 产物卡 `ArtifactCard`：按 kind 图标 + "由 {tool} 生成" + 打开进右栏检查器。**`div role="button"` 无 tabIndex、无键盘事件**。
- 检查器 `FilePreviewInspector`：17 类预览（pdf/html/图片/视频/表格/Office/分子/3D/FITS/能带/qcode/相图/markdown/代码…），预览/源文件双 tab + Provenance 版本溯源（生成代码/工具/模型/环境 lockfile + 「复现」预填 composer）。

### 1.4 RunsPage 双形态分裂（最严重的信息架构问题）

- 桌面 `RunsView`（`RunsPage.tsx:108-314`）：sticky 筛选栏（220ms 防抖搜索 + 状态 facet chips + surface chips + 24h/7d/30d + 清除）、按日分组 sticky 标签、行展开（环境/硬件/包 chips、复现/日志/复制命令、stdout/stderr 面板）、keyset 分页 + IntersectionObserver 无限滚动、「复现」预填 composer 跳回会话。
- 托管 `HostedRunsPage`（`:343-453`）：**另一套 UI**——搜索 + 状态下拉 + 全量列表客户端过滤，无分页/无分组/无日志/无环境信息，量大必卡。
- i18n 混乱：同文件手搓 `ZH` 字典 + `translate()`（仅中文），HostedRunsPage 又直接硬编码中文。

### 1.5 Composer 与交互问答

- Composer（558 行，交互最重）：自动长高（上限 160px）、IME 安全（keyCode 229）、`!` shell 模式（warn 色边框）、`/` 命令 palette（chip 化、Backspace 消解）、附件 chips、超长粘贴（>2000 字符或 >25 行）自动转工作区文件、↑/↓ 输入历史（localStorage 上限 100，跨会话共享）、审批模式菜单（Approve for me / Full access，桌面专属**英文文案**）。**无拖拽上传、无语音输入**。
- InteractionPrompt：question 卡（单/多选 + 自定义输入 + quick-pick 即点即答 + 跳过）、permission 卡（拒绝/始终允许/允许一次，同签名并发请求合并批量应答）、子 agent 请求解析父链归并到当前对话。
- `composerDraft` 跨页预填机制：Runs 复现/Provenance 复现 → 预填不自动发送，人机回环设计明确。

### 1.6 快捷键与反馈

- 快捷键：⌘B 侧栏、⌘K 命令面板（仅桌面，5 个硬编码动作）、Esc（中断/关面板/关对话框）、Composer 内 Enter/↑↓/Tab/Backspace、Notebook ⌘/Ctrl/Shift+Enter。**无快捷键帮助页**。
- Toast：底部居中、3.5s 自动消失、点击关闭、success/error 两档；**无 aria-live、无 hover 暂停、无 undo**。所有删除仅靠 ConfirmDialog（自研 alertdialog，**无焦点陷阱/初始焦点/Enter 确认**）。
- 外部链接全局拦截走系统浏览器。

### 1.7 视觉体系

- Token：`index.css:13-68` 双主题 CSS 变量 + `tailwind.config.js` 语义映射。亮色暖纸风：`--bg #f7f5ef`、`--accent #c15f3c`（赤陶）、`--text #2a2723`；暗色 `--bg #16151a`、`--accent #d0764f`、`--accent-fg #16151a`。另有 `--series-1..8` 图表色 + grid/axis（与 `@ai4s/shared`、matplotlib 三方同 hex，经 CVD 校验）。
- 字体：Inter / Source Serif 4（标题 `font-serif`）/ JetBrains Mono，fontsource 自托管。
- 圆角/阴影：`rounded-card 14px`、`rounded-input 10px`；`shadow-card`/`shadow-pop`。
- 主题：`data-theme` 属性切换；初始 localStorage → `prefers-color-scheme`（只读一次）；**只有 light/dark 两项，无 system 选项**；hosted web **没有任何主题切换入口**。
- 组件库：**`packages/ui` 是空壳**（只有 9 行 README）；无 shadcn；Radix 声明 6 个包实际只用 popover 一个；全部手写 + cmdk。
- 样式漂移：`text-[Npx]` 任意字号 **251 处 / 45 个文件**（10.5/11/12.5/13/13.5/15/26px）；`shadow-sm/md/lg` 与 `shadow-card` 并存；`rounded-[5/6/14/16/18px]` 任意值并存；`humanSize` 重复实现两份；Settings 的 `inputCls/btnGhost/btnAccent` 与 WebAccountCard 重复。

### 1.8 主工作台问题清单（按主题）

**功能性 bug（确定性坏体验）**
1. ⌘K 面板两个工作流动作发送**空 prompt**：`CommandPalette.tsx:60-61` 用 id `analyze`/`audit`，真实 id 是 `data-analysis`/`evidence-audit`（`WorkflowStarters.tsx:12-39`），`sendPrompt("")` 不设防 → 白建会话+工作目录。
2. **文件选择取消即卡死**：`tauri.ts:347-367` `pickBrowserFiles` 只监听 `change`，用户取消系统文件框时 Promise 永不 resolve，附件/上传按钮永久 loading（`Composer.tsx:343-353`、`FilesPage.tsx:97-110`）。
3. **<1024px 窗口 RightPane 整体消失**（`RightPane.tsx:78` `hidden lg:block`）：小窗点 artifact「打开」后状态已变但不可见，无抽屉/overlay 降级——产物预览、会话文件、Runs 面板三条主流程全丢。
4. **Esc 在审批菜单打开时误中断 turn**：中断守卫只查 `[role="dialog"]`（`LiveSessionPage.tsx:141`），`role="menu"` 不在列且菜单自身无 Esc 关闭。
5. 图表下载对位图失真：`FigureBlock.tsx:52` 一律按 .svg 保存，非 SVG data URI 下载得到伪 .svg。
6. **暗色主题按钮文字色错误**：`MemoryPage.tsx:196,294`、`ConfirmDialog.tsx:50`、`WebProjectsCard.tsx:248` 硬编码 `text-white` 配 `bg-accent`，但暗色 `--accent-fg` 是 `#16151a`（应为深字）。
7. 用户消息不保留换行（`atoms.tsx:15-21`）。

**一致性（最刺眼的一类）**
8. **中英混杂成体系**：SettingsPage 整页英文 vs 全站中文；侧栏入口叫「账户」落地页标题是 "Settings"；Composer 审批菜单/aria-label 英文；`WorkspaceChip` 英文；子 agent 活动 "Writing…/Working…"；下载 toast 英文 vs 上传 toast 中文；aria-label 按 `approvalLocked`（实为 hostedWeb 标志）中英分叉。
9. 桌面端侧边栏 6 个导航中 2 个是死页面（科研记忆永远"未配置"、科研工作流"仅在线可用"），入口不按平台裁剪。
10. 侧栏历史会话圆点硬编码 `bg-ok` 恒绿，无状态语义；会话列表无重命名/搜索/分组/时间戳。
11. `index.html` favicon 与 `theme-color` 残留上游蓝色 `#2563eb`，与品牌赤陶冲突。
12. 时间格式化不一致：`NotebooksPage.tsx:182` `toLocaleString()` 未指定 locale vs `RunsPage` 的 `zh-CN`。
13. LoginPage development 模式忽略用户输入的账号密码（`LoginPage.tsx:54`）。
14. 「已中断」用 error 红色，与真失败不可区分；失败后无重试入口。

**可访问性**
15. 全应用仅 `AgentsPage.tsx:127` 一处 `focus-visible` 样式，`outline-none` 普遍；ESLint 无 jsx-a11y 插件。
16. 对比度（亮色实测）：`--muted` 3.1–3.6:1、`--warn` 2.94:1、`--accent` 4.23:1、`--ok` 4.08:1、`--error` 4.49:1——小字均不达 WCAG AA 4.5:1（暗色均达标）。
17. 侧栏删除按钮 `hidden group-hover:block` 键盘完全不可达（MemoryPage 反而有 `group-focus-within`，标准不一）；ArtifactCard/FigureBlock 无键盘路径。
18. ConfirmDialog 无焦点管理；Toaster 无 `aria-live`；无 `prefers-reduced-motion` 处理；状态全靠彩色圆点无冗余编码（CVD 不友好）。
19. 拖拽调宽（Sidebar/RightPane）无键盘替代、无 aria 值暴露。

**响应式**
20. RightPane 小屏消失（见 bug 3）；断点使用稀少不成体系；hosted web 同一前端在手机浏览器上基本未覆盖；FilesPage 目录树 `w-72` 固定不可调（与可拖拽的 Sidebar/RightPane 不一致）。

**工程**
21. 死代码成堆（见 1.1）；`researchAgentUi.ts` 把 9 个 agent 的中文标题/starterPrompts 硬编码在前端，服务端新增 agent 即静默退化为英文。
22. 流式文本 token 不节流（性能）；无流式自动滚底（核心体验缺失）。
23. 无 onboarding：`features/onboarding/` 空目录，首启 macOS TCC 等待几分钟只有 pulsing dot 无说明。
24. 输入历史 localStorage 明文存全部 prompt（共享机器隐私暴露）。
25. `navigator.userAgent.includes("Mac")` 判定在 4 个文件重复且脆弱。

## 2. 记忆模块（Memos）调研结果

技术栈：React 19 + Vite 8 + **Tailwind CSS v4** + Base UI + TanStack Query + ConnectRPC + **i18next（43 个 locale）**。即上游 Memos vendored 副本，未做任何 EviMed 品牌化。

### 2.1 页面清单（16 个路由）

路由 `web/src/router/routes.ts` + `router/index.tsx`（全部 lazy + chunk 失败自动刷新）：

| 页面 | 路由 | 要点 |
|---|---|---|
| Home | `/` | 个人时间线：内嵌 MemoEditor + 过滤器 chips + 无限滚动 |
| Explore | `/explore` | 广场（游客仅 PUBLIC） |

### 2.2 核心交互

- MemoEditor：CodeMirror 6 + GFM、Cmd/Ctrl+Enter 保存、Tab 列表升降级、`#` 标签自动补全、粘贴/拖拽文件直接上传、localStorage 草稿、录音 + AI 转写、Focus Mode、可见性选择器。
- 搜索：回车按空格拆词生成过滤器 chip——**无即时搜索/防抖/清除按钮/快捷键，对中文无空格长句不友好**。
- 标签树：`/` 分层、互斥单选、计数徽标——**但标签与展开按钮均为 div/span onClick，无键盘可达**。
- 列表：无限滚动 + 自动补页 + 回到顶部；单列流/瀑布流双布局。
- 反馈：react-hot-toast top-right + 统一 ConfirmDialog；删除无 undo；loading 用延迟 250ms spinner 防闪烁；空态统一 `Placeholder` 组件（像素鸟 SVG）；**但 MemoDetail/UserProfile/AuthCallback 加载中直接 `return null` 白屏**。
- 实时：SSE 刷新缓存，连接状态以头像角标展示。
- **无全局快捷键、无命令面板**。

### 2.3 与主平台的一致性差距（关键）

## 3. Python agents 与报告产物调研结果

### 3.1 无前端，但后端行为直接决定前端体验

五个 agent 均无 Web UI（全量 glob/grep 零命中），"UI" 以三种形态存在：WebSocket 消息生产者（推给外部 `lx-manus` Vue 前端）、FastAPI Swagger 文档、报告产物。与 UX 相关的后端行为：

- **打字机流式**：统一"累积全文 + 固定节奏"推送（`_TW_CHUNK=8 / _TW_DELAY=0.03`，报告写作 `_TW_CHUNK=60`）。
- **图表内嵌**：PNG base64 data-URI 拼进 Markdown delta，且必须携带完整文本（与前端替换协议耦合）。
- **静默失败（体验断点）**：科研选题模块执行失败"不向前端发送错误文字，静默跳过"（`科研选题/app/main.py:615-618`）——**用户看到步骤标 done 但没有内容，无法区分"无结果"与"失败"**。
- **聊天内收凭证**：孟德尔在聊天里引导用户粘贴 OpenGWAS JWT，最多 5 次尝试（`孟德尔随机化/start.py:743-864`）——凭证明文进入对话历史。
- 排队与超时：meta 有公平排队器并暴露队列状态；孟德尔全流程超时 3600s、空闲 30 分钟自动关闭会话。
- CORS 全开（科研选题 `allow_origins=["*"]`）。
- **文档漂移**：科研选题实际端口 6008（文档写 8000）、论文审稿 6009（AGENTS.md 写 8000）。

### 3.2 meta 的 HTML 审计报告（唯一真实存在的"报告页面"）

约 25 个渲染器（`meta/new_meta/core/artifact_package_html.py` 等），每个内联 `<style>`、系统字体栈、浅色纸质风（`#f7f8fb` 底、`#152033` 字、`#b42318` fail / `#067647` pass）、中英双语。**约 25 份复制粘贴的样式块，无共享模板、无暗色、无打印样式、硬编码 hex**——与主站 token 体系是完全无关的第二套视觉语言。

## 4. 总体结论

1. **视觉基线扎实，体系化不足**。主平台暖纸风 + 赤陶品牌色 + 双主题 token + 图表色系统一是很好的底子；但 token 只完成了一半（251 处任意字号、阴影/圆角绕过、`packages/ui` 空壳、无 i18n 层）。
2. **核心对话体验工程成熟度高于界面完成度**。SSE 中断/重连/丢事件兜底、工具折叠 + live tail、审批/问答卡、草稿嫁接都是同类产品中少见的细；但消息换行、自动滚底、重试、会话管理等基础体验反而缺位。
3. **三类"分裂"是最大问题**：中英语言分裂、RunsPage 双形态分裂、主平台 vs Memos 品牌/组件分裂。
4. **可访问性整体低于及格线**：亮色多色不达 AA、焦点可见性近乎缺失、键盘路径多处断头。
5. **确定性 bug 有 7 个**（见 1.8-1~7），其中 ⌘K 空 prompt、文件选择取消卡死、小窗 RightPane 消失是用户必踩的坑，应最先修。
6. **工作区外的 `lx-manus` 是真正的平台前端**——本报告的协议层建议（静默失败、凭证交互、图表协议）需要跨仓库协同落地。
