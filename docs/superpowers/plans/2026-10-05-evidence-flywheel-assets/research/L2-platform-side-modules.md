## Key facts for designing the loop (summary)
1. Individual-account tenancy only; no org and no system tenant (`deploy/web/saas-capability-contract.json:5`, `:26`; users table has no role/org, `controlPlaneDatabase.mjs:15-23`). Platform-produced content hangs off the first operator (frontier `frontierWorker.mjs:60-81`, evolution `evolutionComposition.mjs:62`) or an explicit `--owner` (imported zones), with AI actor user rows `evidence-editor-ai`/`evidence-review-ai` (`import-evidence-content.mjs:118-124`).
2. Memory, capsules, learned methods and handbooks are all per account; memory scope `organization` is vocabulary only. Sharing = `.evimedcap` file copy (password in UI; named recipients API-only), institution integration-key shelf (external API only). No in-platform delivery/gallery/link/live subscription; revoke cannot reach offline copies.
3. Handbooks are owner-scoped even for reviewer-only "how to pass EviMed's checks" lessons (`capabilityHandbooks.mjs:9-21`, `learningService.mjs:84-95`); cross-tenant flow is evolution only: signals up (`evolutionLearningCoupling.mjs:1-11`, dataset metadata, feedback), immutable platform skills down (`platformSkillSupply.mjs:41`).
4. GEO never references 专区/evidence zones/www.evimed.com; its 自有层 is the brand's own channels; anchor layer = 学会/期刊/官方平台 of authoritative categories (owner pack).
5. GEO claim library is evidence-card-shaped but private to a GEO project; GEO reads no zones/frontier/KB/memory/results.
6. GEO buys paid placements via a media vendor; no independence/COI/disclosure/no-paid-placement rule exists anywhere.
7. No public, crawlable surface (SPA behind login, no SEO/OG/robots/sitemap/share links); published zones visible to logged-in accounts only.
8. Science reads www.evimed.com's evidence API (incl. VCR ChiCTR) and receives SSO + AI-search handoffs, but reports may not cite `www.evimed.com/api-evimed/` and nothing publishes back.
9. VCR consumes only per-study verified extractions + 3 shipped packs; outputs carry structural value-source/intended-use labels; kept separate by owner decision; `evidence_item` shape matches an evidence card.
10. Researcher vs platform work is decided by `isResearcherOwnedWork` + internal projects; only kernel/engine/review/web-search are billable; frontier/geo/vcr/evolution are uncapped platform overhead.
11. Existing cross-module links: memory → frontier 与你相关; KB doc → capsule document layer; retraction → memory/method labels; scoping `agenda-delta.json` → autopilot; data semantics → evolution; GEO/autopilot/VCR runs → learning.
