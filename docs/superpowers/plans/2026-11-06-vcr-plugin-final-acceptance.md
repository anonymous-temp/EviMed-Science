## Independent installation and actual product execution

The nine offline archives and installer were generated from clean source and
hash-checked. Each professional bundle installed independently through the DSH
CLI. Native ToolRuntime calls executed trial design, network synthesis, cohort
generation, binary patient scenarios and E-value analysis against the pinned R
engine. The optional suite alone exposed no domain tools; adding trial exposed
only installed tools. Domain uninstall preserved research files, and suite
uninstall preserved a separately installed trial bundle. This outside-kernel
component probe explicitly used the SDK supplied by the CLI; it is not claimed
as a standalone live-model conversation.

Hosted acceptance separately used actual DSH/DeepSeek Flash, fresh accounts,
automated attribution, isolated requested project/session scopes and disabled
memory/learning. R10 completed 20 frozen ordinary-language runs and exported all
seven declared ordinary files. Completion is not an accuracy score. Four native chains with multiple domains installed and four domain-exclusive
native chains passed; R11 retested
the two interpretation defects and frozen input read-back. The real browser
checked a two-turn cohort edit, retained versions, matching CSV aggregates and
390px layout. No real patient data was used in these model conversations.

## Remaining validation and release boundaries

1. Synthetic-population fidelity retains red bands and some unavailable checks;
   full-input generation is not a quality pass. The limited membership test is
   not a privacy guarantee. Improved generators need a newly frozen evaluation.
2. ICU HR prediction remains endpoint/horizon/population-specific. ACTG175
   checks use a composite outcome inside an RCT; they do not establish external
   control transportability. Independent prospective disease/site validation and
   qualified clinical/statistical review remain necessary for registrational use.
3. The actual twenty-paper parser/table-selection benchmark still requires the
   internal parser service URL and key-file configuration. Neither checkout had
   usable configuration; the owner was asked for a file path, not a secret value.
   Real-publication KM and clinical precedent validity retain their earlier limits.
4. After explicit runtime stop and cold extension rebase, saved results remain
   reachable, but some completions return as saved-result notices rather than a
   successful new AI explanation. Improve that continuation UX/observability
   without bypassing the generation or authorization fence.
5. Browser acceptance covers the observed cohort/result/version/export/narrow
   paths. Component/API and CI checks cover more states; unobserved manual
   clinical workflows are not described as browser-tested.
6. Public package-registry/GitHub-release publication, production catalogue
   admission, coordination with the separate matching release, main integration
   and production deployment are later release actions. The first prerelease
   does not establish an upgrade between two publicly released versions.
7. The local cross-clock Frontier/GEO diagnostics are retained separately. No
   production freshness or authorization logic was weakened to make macOS
   diagnostics pass; a future content/version-bound check is recorded in the
   regression ledger.

No deployment or production data migration was performed.
