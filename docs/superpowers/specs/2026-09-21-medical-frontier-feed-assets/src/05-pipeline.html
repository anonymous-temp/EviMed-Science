① 读 —— 程序的事：定时、守规矩、不漏不重

信源登记表一行一个信源：怎么读、多久读一次、走哪个出口、属于哪一栏。是数据不是代码，运营可以增删。
→
采集按信源节奏轮询；带 ETag 只取变化；遵守 robots 和每站限速；四种读法：订阅源、开放接口、列表页、无头浏览器。
→
归一与去重抽出 DOI、PMID、注册号、规范链接；同一篇论文从期刊、PubMed、媒体三路进来，只留一条，其余挂为「报道」。
→
补全期刊条目用 DOI 去 PubMed / Europe PMC 取摘要和文献类型；公告和新闻取正文。取不到摘要的先挂起，5 天内重试。

② 选 —— 模型判断价值，程序复核能复核的部分

初筛（小模型，批量）是不是医学或医学相关的 AI？是不是新闻（不是勘误、来信、招聘、广告）？归到哪一栏、哪个专科？约七成在这里被挡下。
→
打分 + 写导读四个维度：来源权威与证据强度、实践影响、新颖性、与国内读者的相关性。前一项由程序按信源等级和文献类型给出，后三项由模型判断。
→
数字复核导读里出现的每个数字，必须能在原文摘要或正文里逐字找到。找不到：重写一次；还不行：只出标题，不出导读。
→
精选过线才进精选；同一信源每天有上限，八个栏目各有保底；安全警示不看分数，直接进。
↓

③ 编 —— 把散的条目编成读者要的三种东西

事件聚类同一件事的论文、公告、新闻稿和媒体报道并成一个事件。先用 DOI、注册号、药名加时间窗做候选，再用向量相似度，拿不准的交给模型裁决。一手来源置顶。
→
热点榜近 72 小时 Top 10。热度 = 报道它的独立信源数 × 信源权威 × 时间衰减，中英文都报道的加权。一次发布只占一个位置。
→
日报 / 周报每天 07:30（北京时间）定稿：头条、分栏目、安全警示、AI 一分钟。周报每周一出。
