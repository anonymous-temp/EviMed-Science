## Design rules (EviMed 前端设计规范 v2.1 — follow strictly)
- Simplified Chinese UI. One accent colour (brand blue); our arm / chosen scenario = brand blue; comparators and other scenarios = greys (`--comp-1/2/3`). Red (`--safety`) only for real problems (safety, failure); amber (`--attn`) for "needs attention / AI 设定 / unknown"; green (`--ok`) sparingly for "passed".
- Page title one line, **no subtitle** under titles, no text that explains the system ("本页展示…" is banned), no internal ids/state names (no "run_id", "accepted", "token").
- Data pages use the wide column (1200). Tabs: underline style, at most 7. One brand moment per page at most.
- Every number that is a simulation output shows its Monte Carlo SE or interval; intervals are named (置信区间 / 预测区间 / 可信区间 / 蒙特卡洛区间).
- Provenance encoding everywhere: observed = solid line / solid dot; literature aggregate & reconstructed = dashed line; model prediction & synthetic = light band / hatched; assumptions carry a small "假设" tag. Small origin tags next to key numbers: 观察 · 抽取 · 汇总 · 重建 · 预测 · 假设 · 合成 (use `.tag` variants; muted).
- Review state chips: "AI 设定" (amber-soft), "已复核" (ok-soft), "复核后有变更" (grey outline). Scientific state: "可估计" / "有限制地估计" / "不可估计" (the last is a card with the gap list, never a blank or 0).
- The four counts (真实患者数 · 事件数 · 有效样本量 · 生成记录数) appear as a compact row wherever sample size matters.
- Tabular numbers (`.num`), CJK-Latin spacing with a half-width space ("180 例", "HR 0.70"), ranges with "～" in prose and "–" inside numeric intervals like "3.0–5.6" (be consistent within a page).
- Charts: inline SVG, hairline axes (`--line`), labels 12px `--text-3`, one-sentence chart titles (a conclusion, not a label).
- Study page header = study name + two tags (data tier "T0 公开资料" and intended use "研究设计支持") + a 7-step progress rail (定义 · 证据 · 人群 · 患者 · 对照 · 试验 · 匹配) + a secondary button 「对话」 + an icon button "⋯". Then tabs: 总览 · 人群 · 虚拟患者 · 对照 · 试验 · 匹配与招募 · 数据与证据.

## Shared example facts (keep every page consistent with these)
Main study: **「EV-201 二线 NSCLC：单臂 II 期还是随机」** (fictional drug EV-201, a PD-1/VEGF bispecific; indication: EGFR/ALK 阴性晚期非小细胞肺癌，一线含铂化疗 ± 免疫治疗后进展；comparator standard care = 多西他赛). Data tier T0 for design; the matching/recruitment tabs use the partner's T1 data ("合作方：某招募机构，候选人 3,412 名").
- Evidence: 23 precedent trials found (ClinicalTrials.gov 14, ChiCTR 5, CDE 登记 4); 7 docetaxel control arms pooled for PFS.
- Assumption cards (12). Key ones:
  - 对照组中位 PFS 4.1 个月（随机效应汇总，7 项，95% 置信区间 3.6–4.6，**预测区间 3.0–5.6**，I² 41%）— 汇总 · AI 设定
  - 对照组 ORR 12.4%（9 项，预测区间 7.9–18.6%）— 汇总 · 已复核（王统计师 9/27）
  - 目标 HR 0.70（情景假设；敏感性 0.60–0.85）— 假设 · AI 设定
  - 脱落率 10%/年 — 汇总（5 项）
  - 每中心每月入组 0.42 例（先例弱先验，Gamma α=2.1，β=5.0）— 汇总 · AI 设定
  - 筛选失败率 38%（合作方漏斗 2023–2026，1,186 例筛选）— 观察
- Literature control: 3 KM curves reconstructed (Guyot), QC passed (风险人数最大差 2 人；事件数差 1.8%；中位数差 2.4%；|Δlog HR| 0.03). Pooled docetaxel RMST at 12 months 5.9 months.
- Real external control (patient-level): **不可估计** — 缺 3 项：同期治疗记录（后续治疗线）、结局评估频率（影像随访间隔）、ECOG 缺失 38%.
- Designs:
  - A 单臂 + 文献对照：n = 60，目标 ORR ≥ 25%（对照 12.4%），功效 86%（±0.2），成功把握 58%（±0.4），末例入组中位 9.8 个月，成本约 1,450 万元
  - B 2:1 随机（EV-201 : 多西他赛）：n = 180（120 : 60），事件数 128，功效（HR 0.70）81%（±0.3），**成功把握 71%（±0.4）**，末例入组中位 16.2 个月（80% 区间 13.1–20.4），成本约 3,900 万元
  - C 1:1 随机 + 一次期中分析（Lan-DeMets O'Brien-Fleming）：n = 220，事件数 160，功效 85%（±0.3），成功把握 73%（±0.4），期望样本量 204，末例入组中位 19.5 个月，成本约 4,600 万元
  - D 1:1 随机 n = 240 无期中（被 C 占优，置灰）
  - Null scenario (HR 1.0): I 类错误 B 2.47%（±0.11），C 2.51%（±0.11）; 20,000 replicates each; alternative 5,000+.
- One-sentence conclusion (overview): 「方案 B（2:1 随机，180 例）在当前证据下成功把握 71%，高于单臂方案 A 的 58%；真实外部对照暂不可估计，缺 3 项数据。」
- Recruitment: target 180 randomized; 14 sites planned; predicted last patient 2027 年 3 月（80% 区间 2027-01～2027-06），按期（2027-04-30）完成概率 64%; actual so far (partner, for the recruitment tab only): 3 sites activated, 11 enrolled vs 9.6 predicted.
- Matching (T1): protocol v2 has 14 criteria (I1–I8, E1–E6). Among 3,412 partner candidates: 612 可能符合（至少 1 条未知）, 57 符合（全部满足）, 2,743 不符合. Example patient **P-0192**: 男 63 岁，腺癌 IV 期，一线卡铂 + 培美曲塞 + 帕博利珠单抗，2026-07 影像进展；ECOG 1（2026-08-14 门诊记录）；E3「活动性脑转移」未知（最近头颅 MRI 在 2026-02，证据超过 12 周）→ 补证建议：申请近 4 周头颅 MRI；E5「末次免疫治疗距今 < 28 天」待复评（2026-10-06 满 28 天）. Overall: 「不能判为符合：排除标准 E3 未知」.
- Virtual patients page uses the second study **「GLP-1 周制剂 III 期：样本量与脱落情景」** (T0; 文献模型「成人 2 型糖尿病 HbA1c 轨迹 v1.2」，适用：HbA1c 7.5–10.5%、52 周、BMI 25–40；来源 9 项试验). 2,000 virtual patients generated. Example VP-0412：56 岁，女，BMI 29.8，HbA1c 8.6%，eGFR 78，病程 7 年；来源：批量合成（人群 v3）。Scenario 对照（安慰剂 + 二甲双胍）vs 试验（周制剂 + 二甲双胍）: 52 周 HbA1c 变化 −0.3%（预测区间 −1.1–0.6）vs −1.4%（预测区间 −2.3– −0.5）. Group mean difference −1.1%（汇总效应，9 项）. 低血糖事件 52 周 2.4% vs 3.1%。Sensitivity (tornado): 处理效应（−0.8～−1.4）> 基线斜率 > 脱落率（8%～16%）> 基线 HbA1c 分布.
- Other studies for the home list: 「心衰 SGLT2 抑制剂：真实世界外部对照」(T2，专病库数据，外部对照 可估计·有限制); 「小儿疳证 中药复方 RCT 设计」(T0, 中医证候: 脾虚气滞证); 「NSCLC 三期 招募匹配（合作方）」(T1, 匹配 57 符合 / 612 待补证).
