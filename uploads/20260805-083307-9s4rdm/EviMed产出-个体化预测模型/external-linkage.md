# 外部连接图（external linkage map）

规则：每个资源必须写明——**以哪个字段连接、什么粒度、能回答本数据单独回答不了什么问题、映射成本**。标准词汇表是基础设施：药物走 ATC/RxNorm，诊断走 ICD-10/SNOMED，检验走 LOINC（LOINC 不带单位，必须配 UCUM；同一 LOINC 码可同时接 mg/dL 与 mmol/L）。

## 语义精度提示（映射成本）

- 阿立哌唑存在**三种浓度口径**：母药（阿立哌唑）、活性代谢物（脱氢阿立哌唑）、活性成分和（总阿立哌唑）。文献中"阿立哌唑 100–350 ng/mL"指母药（或活性成分，视研究而定）——**合并任何外部数据前必须固定口径**，本机构 `REFFR_SCOPE` 已按口径分开（100–350 母药 / 150–500 总），与 AGNP 一致。
- `PROJECT_CODE` 本地码 → LOINC 的映射若做错方法/单位，会在多中心合并时静默引入偏差；本数据无单位字段，是映射前必须补齐的缺口。
- 中医诊断（`TCM_TYPE`、`TCM_TYPE1`、癫病/郁病等）与 ICD-10 并存于诊断记录表，按诊断类型（`DIAGNOSTIC_TYPE` 1/2/3）分流后再映射，避免"郁病→抑郁发作"式的 up-hill 语义损失。
