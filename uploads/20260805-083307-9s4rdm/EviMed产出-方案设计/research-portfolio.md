# 方案一（含 A/B 两项审计）：现在就能做的两项审计研究

## 一A. 审计 A — 阿立哌唑剂量校正浓度（C/D）分布与参考区间达标率审计

### 1. 研究问题与假设

**问题**：本院住院精神科阿立哌唑 TDM 中，(i) 剂量校正浓度（C/D，ng/mL 每 mg/日）的
个体间分布如何、与已发表参照（TDM-VIGIL 分层、CYP2D6 效应锚点）是否偏离；
(ii) 参考区间达标率在本院口径、AGNP 2017 口径与 Hart 2022 修订口径下各是多少、分类差异在哪。

**假设**（预注册，非推断检验）：
- H1（描述）：C/D 个体间离散 ≥2 倍（以跨样本 C/D 最大值/最小值 ≥2 为"离散超常"的服务质量信号）；
- H2（描述）：母体达标率在本院口径 <50%（服务质量信号）；
- H3（方法学注记）：至少 1 个样本在 Hart 2022 修订口径下改判（本院口径与 Hart 口径分类不一致率 >0）。

**性质声明**：描述性服务审计/病例系列（n=6 采样事件），不做推断外推、不做因果声明。

### 2. 纳入与排除

| 项 | 规则 |
|---|---|
| 纳入（采样事件） | `检验.PROJECT_NAME ∈ {阿立哌唑, 总阿立哌唑, 脱氢阿立哌唑}` 的所有测定，按 `SAMPLENO` 聚合为采样事件（6 个） |
| 纳入（患者） | `病案首页` 5 例全部进入"患者级描述"；进入 C/D 归一分析的仅限有可解码口服阿立哌唑医嘱者 |
| 排除（C/D 分析） | `panel_order_conflict=1`（P2：检验面板含阿立哌唑但医嘱无口服阿立哌唑）→ 只进"面板-医嘱一致性"统计，不进 C/D |
| 排除（剂量计算） | `FREQUENCY=ONCE` 且 `MEDICATION_WAY ∈ {化验, 出院带药, 退药}` 的医嘱（非给药用途） |

### 3. 变量定义与构造算法（逐字段）

> 取值来源：`检验`/`医嘱记录`/`病案首页` 三表（字段名见 `data-profile.md`）。
> 所有日期统一解析为 datetime（预处理 PR3/PR4）；剂量计算先完成 PR1/PR2。

| 变量 | 字段/来源 | 构造规则（含算法） |
|---|---|---|
| 采样事件 ID | `检验.SAMPLENO`（源标识符，产物中写 S1–S6） | 按 `TEST_DATE` 升序编号 S1–S6；同日多样本（4/1 两事件）按 `SAMPLENO` 字典序 |
| 母体浓度 C_parent | `检验.PROJECT_NAME='阿立哌唑'` 的 `TEST_RESULT` | 单位 ng/mL（预处理 PR9 待检验科书面确认） |
| 总活性浓度 C_active | `PROJECT_NAME='总阿立哌唑'` 的 `TEST_RESULT` | 同上 |
| 代谢物浓度 C_dari | `PROJECT_NAME='脱氢阿立哌唑'` 的 `TEST_RESULT` | 无参考范围（REFFR_SCOPE 缺失 6/6），只报浓度 |
| 代谢比 MR | C_dari ÷ C_parent | 仅对同一采样事件内配对测定计算 |
| 采样日剂量 D（mg/日） | `医嘱记录`（ARI 长期口服医嘱） | 算法见下框 **D-ALGO** |
| C/D（母体） | C_parent ÷ D | 仅 D 可解码时计算；不可解码标记 `cd_not_estimable` |
| C/D（总活性） | C_active ÷ D | 同上 |
| 达标分类达标₁ | `TEST_RESULT` vs `REFFR_SCOPE`（本院口径） | 区间含端点判"达标"；低/高于区间判"低于/高于" |
| 达标分类达标₂ | C vs AGNP 2017：母体 100–350、活性 150–500 | 与 `REFFR_SCOPE` 值一致时判"本院口径=AGNP 口径" |
| 达标分类达标₃ | C vs Hart 2022：母体 120–270、活性 180–380 | 重算分类；与达标₁ 不一致的样本逐条列出（H3 的直接证据） |
| 稳态标志 | `医嘱.START_DATETIME` 链 | **SS-ALGO**：采样日落在某长期口服 ARI 医嘱生效区间，且该剂量（mg×次/日）已连续 ≥14 天 → `steady=1`；<14 天 → `steady=0`；无法判定（无医嘱/剂量冲突）→ `steady=NA` |
| 在药天数 | 采样日 − 首条长期口服 ARI 医嘱开始日 | 整数天；医嘱开始日早于入院日时以入院日截断 |
| 并用 CYP 相关药物 | `医嘱记录.ORDER_CONTENT` | 列出采样日生效的 CYP2D6/3A4 相关药物（帕利哌酮、氯氮平、奥氮平、丙戊酸、碳酸锂、氯硝西泮等）作为描述字段，不入模型 |
| 联用中药计数 | 同表 | 仅计数描述（Q8 判定不可行，不作交互分析） |

**D-ALGO（采样日剂量解码算法）**
```
输入：采样日期 d0；医嘱表
候选集 = {医嘱 r : r.ORDER_CONTENT 含"阿立哌唑"
           AND r.LONG_D_NO=1
           AND r.MEDICATION_WAY='口服'
           AND r.START_DATETIME ≤ d0 ≤ r.END_DATETIME(哨兵日期按 PR3 处理)}
if 候选集为空: D = NA（标记 dose_missing）
else:
  对每个 r: 次数 n_r = FREQ_DECODE(r.FREQUENCY)   # 主解码表见下
           日剂量_r = r.DOSAGE(mg) × n_r
  if 所有 r 的日剂量相等: D = 该值
  else: D = Σ 日剂量_r（并集）且 dose_conflict=1   # P5 的 QD+QD16 属此
返回 D, dose_conflict
```
**FREQ_DECODE 主解码表**（HIS 字典核验前先按此运行，核验后以字典为准并登记于 `FREQUENCY_DICT`）：
| FREQUENCY 值 | 主解码（次/日） | 敏感性区间 |
|---|---|---|
| QD、QD11、QD15、QD16、QD20、QD12、QD9 | 1（`QD16` 等后缀=疗程天数，不影响次/日） | 固定 1 |
| QN | 1（每晚 1 次） | 固定 1 |
| BID、BID4、BID5、BID8、BID1 | 2（`BID4` 后缀=疗程/频次修饰码，待 HIS 核验） | **1–3 次/日**（敏感性分析，见 5.4） |
| TID、TID4 | 3 | 2–4 |
| QOD | 0.5 | 固定 |
| W1D8/W2D8/W3D8/W4D8/W5D8/W6D8、W1D、W2D、W2D1、W5D | 周频：`WnD` → n/7 次/日（`WnD8` 后缀=疗程周数修饰） | 0–n/7 |
| ALWAYS、ALWAYS1、PRN | 不用于剂量计算（按需/持续医嘱），标记 `prn_or_always` | —— |
| ONCE | 单次医嘱，不参与日剂量（PR2 剔除） | —— |

### 4. 统计分析计划（SAP）

**4.1 描述统计**：
- 每例/每采样：C_parent、C_active、MR、D、C/D（母体、总活性）、达标分类（三口径）、稳态、在药天数。
- C/D 分布：几何均数（对数正态假设）、几何 SD、范围、跨样本最大/最小比；
  按稳态（steady=1/0/NA）分层报告；P2 单列说明（panel_order_conflict）。
- 达标率：三口径各报 达标/低于/高于 的计数与百分比。

**4.2 区间估计方法**（不做基于观测数据的效能回算）：
- 达标率：**Clopper-Pearson 精确 95% 置信区间**（小样本二项比例唯一恰当方法）。
  预期宽度（n=6，提前声明，非回算）：观测 0/6 → 95% CI (0.000, 0.459)；
  观测 2/6 → (0.044, 0.777)；观测 3/6 → (0.118, 0.882)。
  **由上式直接给出结论限制**：n=6 时达标率的 95% CI 半宽 ≥22 个百分点，任何"达标率=某个数"
  的陈述都不成立，只能报区间。
- C/D 几何均数：对 log(C/D) 用 t 分布法（n=5 个可归一化样本，df=4）。
  以实际观测（P1 两样本、P3/P4/P5 各一）为例：log 均值 2.66（SD 0.46），
  几何均数 14.3，95% CI ≈ (8.1, 25.3)——**预期区间宽度比 ≈3.1 倍**；
  意味着该审计不能分辨"本院 C/D 水平是文献的 1.5 倍还是 2 倍"，只能报告"在哪一个数量级"。
- **最小可检出效应（MDE，前瞻声明）**：以 n=5 个可归一化样本、α=0.05（双侧）、
  检验功效 0.80、单样本 t 检验，最小可检出 log(C/D) 偏移 d_min =
  (t_{0.975,4}+t_{0.80,4})/√5 ≈ 3.72/2.24 ≈ **1.66 个 SD ≈ log 尺度 0.76 ≈ 2.1 倍**。
  即：本审计只能检出"≥2 倍"量级的 C/D 水平偏移；<2 倍的偏离一律判为"无法区分"。
- 代谢比 MR：只报逐例值与文献参照带（0.17–0.49 vs 文献分布），不做假设检验。

**4.3 缺失与哨兵值处理**：
- `REFFR_SCOPE` 缺失（脱氢 6/6）：达标分类不适用 → 只报浓度与代谢比。
- `END_DATETIME=0/0/0 00:00:00`：按 PR3 以出院日或同组最近 END 插补，`end_source=imputed` 标记，
  敏感性分析见 5.2。
- P2 无剂量：C/D 不可估 → 列入 `panel_order_conflict` 统计，不进入 C/D 分布。
- 重叠剂量（P5）：并集日剂量 + `dose_conflict=1`，敏感性分析见 5.3。

**4.4 敏感性分析（明确、可执行）**：
1. **FREQUENCY 解码敏感性**（对含 `BID4`/`BID5`/`BID8` 等歧义码的样本）：按解码区间
   {1, 2, 3} 次/日逐一重算 D 与 C/D，报告 C/D 的**区间呈现**（C/D_min–C/D_max）；
   若某样本 C/D 区间跨越 ≥2 倍，标记 `cd_sensitivity_high` 并降级为"仅可定性"。
2. **哨兵日期敏感性**：`END_DATETIME` 插补 vs 不插补（剔除该医嘱）两种策略下重算 D，
   报告在药天数与稳态标志的变化。
3. **重叠剂量敏感性**：P5 取"并集 10 mg/日" vs "取较大 10 mg/日"（两者在 P5 中相等）
   vs "若 QD16 实际为每日 2 次（未核验）则 20 mg/日"——量化 `dose_conflict` 的影响。
4. **稳态阈值敏感性**：稳态判据在同剂量 ≥14 天 / ≥21 天 两档下重算 `steady` 分层
   （21 天档对应 PM 患者更长 t½ 的保守选择），报告分层样本变化。

## 一B. 审计 B — TDM 采样规范性审计

### 1. 研究问题与假设

**问题**：本院 TDM 采样在四个规范维度上的表现：(i) 稳态采样比例（采样时是否已达稳态）；
(ii) 重复采样可得性（每人是否 ≥2 次可对照采样）；(iii) 谷浓度信息完备性（是否有采血时刻字段）；
(iv) 采样-医嘱时间对齐质量（采样日是否落在可判读的用药区间内）。

**假设**（预注册，描述性）：
- H4：稳态采样比例 <50%（6 事件中可确认稳态者 <3）；
- H5：谷浓度信息完备性 =0%（`TEST_DATE` 无时刻字段 → 无任何采样可判谷/峰）；
- H6：≥1 例存在"采样日落在无口服 ARI 医嘱区间"（面板-医嘱错位，即 P2 情形）。

### 2. 纳入与排除

- 纳入：全部 22 条检验记录（6 采样事件），含非 ARI 项目（氯氮平、奥氮平、帕利哌酮、氯硝西泮）——
  因为审计对象是"采样规范"而非"某一药物"。
- 排除：无（全量审计）；医嘱表仅用于时间对齐（PR2 子集）。

### 3. 变量定义与构造算法

| 变量 | 构造规则 |
|---|---|
| 稳态判定 | SS-ALGO（同审计 A 3）；对非 ARI 项目（氯氮平按 ≥5–7 天、奥氮平 ≥5×t½≈1 周、帕利哌酮 ≥5 天）分别设定稳态阈值的**注释版**，仅作描述 |
| 重复采样 | 同一 `PATIENT_ID` 的采样事件数 ≥2 者标记 `repeat_available=1` |
| 谷浓度信息完备 | `检验` 是否存在采血时刻字段（现状：无）→ `trough_information=0/1` |
| 采血-给药间隔可判 | 医嘱是否有给药执行时间（现状：无）→ `dose_to_sample_interval_known=0/1` |
| 采样日-医嘱对齐 | 采样日是否落在 ≥1 条长期口服医嘱生效区间 → `aligned=1/0/NA`（NA=无医嘱，P2） |
| 采样目的 | `TEST_PURPOSE` 三值分类计数 |
| 重复采样间隔 | 同一患者两次采样的 `TEST_DATE` 差值（天） |

### 4. 统计分析计划

- 全部为**比例 + Clopper-Pearson 精确 95% CI**（n=6 或 n=5 患者）。
  **预期宽度（前瞻声明）**：n=6 时合规率 95% CI 半宽 ≥22 个百分点；观测 0/6 → (0, 45.9%)。
  **由上式直接给出的结论限制**：即便观测到"0 个采样有采血时刻"，也**不能断言**"全院 TDM 均无时刻"
  ——只能写"本次 6 事件全部缺时刻"。
- 不做任何假设检验；不做基于观测数据的效能回算。
- 缺失/哨兵：无采血时刻为**审计对象本身**（不是可插补的缺失）；`END_DATETIME` 哨兵按 PR3。

### 5. 偏倚与应对

| 偏倚 | 应对 |
|---|---|
| 采样驱动选择（只在临床需要时采） | 报告 `TEST_PURPOSE` 分布；结论定位"问题清单"而非"率估计" |
| 时间对齐误判（哨兵日期） | PR3 插补 + 敏感性（插补 vs 剔除） |
| 稳态阈值误设（ARI 长 t½） | 14/21 天两档敏感性；非 ARI 项目阈值仅注释不判读 |

### 6. 产出表格

| # | 产出 | 回答的问题 |
|---|---|---|
| 表B1 | 六事件×四维度合规矩阵（稳态/重复/谷时刻/对齐） | H4–H6 逐项证据 |
| 表B2 | 各维度合规比例 + 精确 CI | "合规率是多少（区间）" |
| 表B3 | 采样目的分布 + 重复采样间隔 | 采样行为画像 |
| 表B4 | 问题清单（每条→改进动作→责任方） | "规范性问题清单"（Q4 判定） |
| 图B1 | 合规矩阵热图（6 事件×4 维度） | 一眼看出短板 |

STROBE 对照同审计 A（条目 10 的样本量陈述一致）；审计 B 的额外报告出口为"质量改进报告"，
可附 SQUIRE 2.0 核对（院内质控报告用，非投稿必需）。

### 7. 前置条件与失败条件
**前置**：PR3/PR4（哨兵与类型规范）必须完成，否则在药天数/对齐判定不可计算。
**失败/中止**：若 `END_DATETIME` 插补后仍 >50% 事件无法判定对齐 → 审计 B 只报"维度 1–3"
（稳态/重复/谷时刻，不依赖医嘱区间），并在报告中声明维度 4 不可判定。

# 方案二：外部群体模型 + 个体贝叶斯（MAP）后验 — 唯一有条件可行路径的执行方案

> 性质再声明：这是**演示性应用（proof-of-concept）**，不是模型开发、不是模型验证、
> 不是临床决策依据。任何个体化输出必须标注"演示"。

### 1. 先验模型选择：Kim 2008（主选）及其依据

**选定：Kim JR 等，Population pharmacokinetic modelling of aripiprazole and its active
metabolite, dehydroaripiprazole, in psychiatric patients（Br J Clin Pharmacol 2008；
PMID 19032724；DOI 10.1111/j.1365-2125.2008.03223.x）[4]**。

选择依据（逐项对照本数据）：

| 匹配维度 | Kim 2008 模型 | 本数据 | 匹配度 |
|---|---|---|---|
| 人群 | 80 例精神科患者（稳态浓度，10–30 mg/日口服） | 住院精神科患者（P1–P5） | ✅ 直接匹配 |
| 剂型 | 口服片剂 | 口服片/口崩片（`博思清`/`安律凡`） | ✅ 直接匹配 |
| 模型结构 | 一室、一级吸收；ARI 与 DARI 各一室同时建模；ka 固定 1.06 h⁻¹；V/F=192 L；CL/F 受 CYP2D6 基因型影响（IIV 37.8%→30.5%；IM CL/F≈EM 的 60%） | 有 ARI+DARI 双测定 | ✅ 代谢物模型匹配（本数据测了 DARI） |
| 协变量 | CYP2D6 基因型（本数据无基因型 → 按 EM 假设并标注，见拒绝条件 3） | 无基因型 | ⚠️ 缺失协变量 → 演示时以 EM 先验 + 标注 |
| 外部验证 | 未检索到该模型的独立外评记录 | —— | ⚠️ 方案四正是要补的"外评" |

**备选（不采用及原因）**：AOM 长效 PopPK 模型（Clin Pharmacokinet 2022；PMID 34979059）[5] 与
2 月长效 RTU 模型（Clin Pharmacokinet 2024；PMID 38602057）[6]——三室/LAI 吸收结构主导、
剂型（肌注长效）与本数据（口服）不匹配 → **不选**；它们在本方案中仅作"剂型不匹配"的反例论证。
若实施时 Kim 2008 全文的方差矩阵/残留误差模型无法取得（摘要级已核验参数典型值，全文未开放），
则**中止该路径**并记录"模型参数不完整"（见失败条件）。

### 2. 软件实现

- **首选：R + nlmixr2 重建模型 + mapbayr 做 MAP 估计**。依据：
  nlmixr2 与 NONMEM 的 MAP 估计在外部模型评价中表现一致（Duong & Marsot 2024；PMID 38465725）[10]；
  mapbayr 是开源 R 包，可直接读入 NONMEM 格式模型并输出个体 MAP 参数（PMID 34342170）[8]。
- **备选：AdDS（R 开源 MAP-Bayesian 工作流，PMID 34618919）[9]**。
- **环境**：院内脱敏工作站（无外网），R ≥4.2，固定依赖版本清单（renv 锁文件）；
  全部脚本入库（git），随机种子固定，输出可复算。
- **模型实现细节**：用 Kim 2008 论文参数（ka=1.06 h⁻¹、V/F=192 L、CL/F 典型值与 CYP2D6 系数、
  IIV 30.5%、残留误差模型）在 nlmixr2 中重建；若论文未给出 IIV 协方差矩阵，以
  "对角 ω、按论文 IIV% 反推方差"实现并在结果中标注"IIV 结构假设"。

### 3. 输入字段（每例）

| 输入 | 字段/来源 | 说明 |
|---|---|---|
| 剂量事件史 | `医嘱记录`（ARI 长期口服，PR2 子集） | 每条：(起始时间, 结束时间, DOSAGE mg, 次/日=FREQ_DECODE)；采样日前剂量链 |
| 采样观测 | `检验`（`TEST_DATE`、`TEST_RESULT`；ARI 与 DARI） | 每个观测需"相对最近一次给药的时间"——**本数据缺失，见 4 时间假设** |
| 协变量 | `病案首页.AGE/SEX`；体重（`体征.SIGN_TYPE=体重`，最近一次） | 模型未用体重则注明 |
| CYP2D6 表型 | 无字段 | 按 EM 假设 + 标注"未检测"；如并存 CYP2D6 抑制剂则触发拒绝条件 3 |

### 4. 采血时刻缺失下的时间假设与敏感性分析

**主分析时间假设（T0）**：由于 `TEST_DATE` 无时刻，对每个采样观测设定
**"上次给药时间 = 该日 08:00（QD/QN 习惯服药点）、采样时间 = 该日 08:00 后 12h"**（即
给药间隔中点假设，对 QD/QN 方案近似"中点浓度"）。**该假设写入结果的第一行，不得省略。**

**敏感性分析（时间假设网格）**：对每个观测在以下 4 种时刻假设下重跑 MAP：
- T1：采样=给药前 30 min（谷浓度假设，t≈0.5h 前）；
- T2：采样=给药后 2 h（吸收早期）；
- T3：采样=给药后 6 h（分布期）；
- T4：采样=给药后 12 h（主假设 T0）。

对每个假设输出个体 CL/F 后验中位数与预测稳态浓度；计算跨假设的**相对极差
（max−min)/median**。判定：
- 跨假设预测稳态浓度相对极差 <30% → 该例输出可标注"对时间假设稳健"；
- 相对极差 ≥30% → 该例标 `time_sensitive=1`，**只输出区间不输出点值**，并注明
  "采血时刻缺失使个体估计对时刻假设高度敏感"。
（阈值 30% 依据：外评中位预测误差达标线 ±20%、可接受上限 ±30% 的常用界（氯氮平外评 [7]），
并为贝叶斯区间留出余量；该阈值属预设判据，不依结果调整。）

**对"无给药执行记录"的附加说明**：剂量事件史来自医嘱而非执行记录（PR2 已剔除出院带药/化验），
依从性未知 → 每个个体输出附加"假设 100% 依从"声明。

### 5. 结果呈现与"演示"标注

- 输出格式：每例一张"个体卡"：剂量史摘要、观测（S 编号、浓度）、时间假设（T0–T4）、
  CL/F 后验中位数与 95% 区间、预测稳态浓度（当前剂量下）、与观测拟合残差。
- **强制标注（每条输出）**：① 顶部红色标注"演示性应用（proof-of-concept），非临床决策依据；
  未经本院数据外评验证（外评见方案四）"；② 时间假设与依从性假设显式写出；
  ③ 无基因型信息声明；④ 拒绝条件触发的样本只出"不可输出原因"页。
- 输出仅用于：(a) 方法学演示/教学；(b) 为方案四的采样与模型选择提供先验体检；
  **不得进入病历、不得用于剂量调整建议、不得作为处方依据**。

### 6. 必须拒绝给出个体估计的条件（触发任一即不输出）

| # | 条件 | 判定字段/规则 |
|---|---|---|
| R1 | 无口服 ARI 医嘱或剂量不可解码 | `dose_missing=1` 或 FREQ 解码失败（P2 属此） |
| R2 | 时间敏感性超限 | 4.4 中跨假设相对极差 ≥30%（`time_sensitive=1`） |
| R3 | 并存强 CYP2D6/3A4 抑制剂或已知非 EM 表型 | 医嘱含强抑制剂（如氟西汀、帕罗西汀、奎尼丁）或基因型非 EM → 模型先验失效，标注并拒绝点值 |
| R4 | 非稳态采样且剂量史 <5 天 | `steady=0` 且剂量链过短 → 暴露重建不可信 |
| R5 | 浓度超出模型验证范围 | C_parent 或 C_active 超出模型建模范围（如 >2× 文献范围上限 500 ng/mL） |
| R6 | 模型参数不完整 | Kim 2008 全文方差/残留参数不可得（见 1 失败条件） |
| R7 | 标识符/数据链路异常 | 面板-医嘱冲突（P2）、`dose_conflict` 未消解、哨兵日期插补失败 |

**演示批次的期望**：前两轮判定本数据可跑通 4 例（P1 两样本、P3/P4/P5 各一；P2 剔除）；
其中仅 1 例可确认稳态。按 R2/R4 预计部分样本仅输出区间或不可输出——**这是预期结果而非失败**，
须在报告中如实呈现"多少样本被拒绝、为何被拒绝"。

### 7. 前置条件与失败条件
**前置**：PR1–PR7 完成；nlmixr2/mapbayr 环境就绪；Kim 2008 全文参数核验（方差/残差）。
**失败/中止**：① Kim 2008 关键参数（IIV 协方差、残差模型）无法从全文取得 → 中止并记录；
② 所有可跑样本均触发 R2/R4 → 中止个体输出，仅保留"方法学流程演示"；
③ 机构伦理/信息科不同意"演示性计算"边界 → 中止。

# 方案三：数据采集改造方案（信息科/药学部对接件）

> 依据：前两轮"最小可行升级路径"五项。本方案将其转为**可执行规格**：
> 字段名、数据类型、取值域、来源系统、责任方、验收标准、不补导致哪个分析失败。
> 零成本项 = 现有系统已有该数据、仅需导出/勾选；需开发项 = 需 HIS/LIS 改造。
> 实施顺序按"依赖关系 + 成本"：先零成本（1→2→3），再开发（4），后流程（5）。

## 改造项 1：TDM 采样时间戳（零成本）

| 项 | 规格 |
|---|---|
| 字段名 | `COLLECT_DATETIME`（检验表新增/导出字段） |
| 数据类型 | DATETIME（YYYY-MM-DD HH:MM:SS） |
| 取值域 | 实际采血时间；禁止 00:00 占位；缺值 = NULL（不得填 0） |

| 来源系统 | 检验申请界面（开单弹窗，强制填写方可提交） |

| 第 2 批 | 项 5（稳态加采流程） | 流程改造 | 2–4 周 | 项 1 上线（时刻是加采判定的前提） |

**里程碑验收（整体）**：第 0 批完成且验收达标 → 解锁"审计 A/B 正式版 + 方案二演示批"；
第 1 批完成 → 解锁"方案四（前瞻外评）入组"；第 2 批完成 → 解锁"方案四双样本子队列"。
任一验收未达标 → 对应批次分析推迟并在月度质控会上报告，不进入下一批。

# 方案四：升级后第一阶段研究 — 外部模型外评 + 本地校准（≥30–50 例前瞻）

## 1. 研究设计与时间线

**设计**：单中心、前瞻性、观察性外评+校准研究（不是干预试验；不改药、不加采血负担之外的操作）。
**对象**：住院/门诊精神科接受口服阿立哌唑 TDM 的患者。
**阶段**：
- 阶段 0（月 1–3）：数据采集改造（方案三）第 0 批上线；伦理申报；SOP 与 eCRF 定稿；试运行 5 例。
- 阶段 1（月 3–9）：入组 30–50 例（目标每月 6–8 例，24–36 周）；每例按采样方案采血。
- 阶段 2（月 9–11）：外评分析 + 本地校准；敏感性分析。
- 阶段 3（月 11–12）：报告撰写、内部答辩、投稿（按 TRIPOD+AI 外评/校准报告线 [18]）。

**判定阈值全预设（见 4），分析期间不调整（若有调整必须记录为偏差）。**

## 2. 样本量依据（前瞻，非事后）

- 锚点：精神科唯一直接实证——氯氮平外部评价用 **53 例/151 观测**，判定达标用
  MPE ≤±20%、MAPE ≤30% [7]；儿童万古霉素 MIPD 用 80 例/226 浓度 [12]。据此取
  **目标 ≥40 例、每例 ≥2 个观测（≥80 观测）**，下限 30 例、上限 50 例。
- **预期精度（前瞻声明，非回算）**：假设预测误差 SD≈20%（参考氯氮平外评量级），
  对 MPE=0 的检验，n=30 → SE≈3.7%、95% CI 半宽 ≈±7.2%；n=50 → 半宽 ≈±5.5%。
  即：30–50 例足以把 MPE 的 95% CI 收窄到判定阈值（±20%）的 1/3 以内，
  **可清楚分辨"达标(±20% 内)"与"显著偏倚(>±20%)"**。
- **最小可检出偏倚（前瞻）**：n=40、α=0.05、功效 0.80、配对 t（预测 vs 观测），
  可检出 MPE ≈ 0.46×SD ≈ **±9%**（即 <9% 的系统偏倚将被判"未检出"，须如实报告为"不可分辨"）。
- 校准子样本：预留 20%（≥6 例）作校准验证留出集；不做基于观测数据的效能回算。

## 3. 采样方案（每人几次、什么时点、为什么）

| 项目 | 方案 |
|---|---|
| 每人采样次数 | 2 次（基础）；住院 ≥5 天者加 1 次（3 次，可选亚组） |
| 时点 | 第 1 次：同剂量 ≥14 天（稳态）后任意日；第 2 次：第 1 次后 3–5 天；第 3 次（可选）：给药后 2–4 h（吸收相信息） |
| 时刻记录 | 每次必须记录 `COLLECT_DATETIME`（方案三项 1）与 `LAST_DOSE_DATETIME`（项 3）——**缺时刻的样本标记为"不可用于外评主分析"** |
| 为什么 2 次 | 1–2 个设计良好的时点即可做个体 MAP（万古霉素儿科中点采样 [12]）；2 观测显著收紧后验（方案二依据）；稳态间隔 3–5 天保证暴露条件近似但观测独立 |
| 为什么记录给药时刻 | 时刻缺失使预测误差被污染（[11] 的采样时机敏感性结论） |
| 中心实验室 | 同一检测方法（检验科 TDM 平台），记录 LOINC/单位（方案三中期项） |

## 4. 外评的评价指标与判定阈值（全预设）

**主分析**：用 Kim 2008 模型（先验，同方案二）对每例每观测做"仅用第一个观测"的
个体 MAP，预测第二个观测（或下一观测）；**逐观测独立**计算预测误差。

| 指标 | 定义 | 判定阈值（预设） |
|---|---|---|
| 中位预测误差 MPE（%） | median((ŷ−y)/y)×100 | 达标 ≤ |±20%|（依据氯氮平外评 [7]） |
| 中位绝对预测误差 MAPE（%） | median(|ŷ−y|/y)×100 | 达标 ≤30% [7] |
| 预测误差在 ±20% 内比例 | P20 | ≥50% |
| 校准斜率/截距 | ŷ 对 y 的回归 | 报告（不设硬阈值，供校准参考） |
| 个体内精度 | 同患者两观测的预测误差差 | 报告（需双样本子集） |

**外评结论判定（预注册）**：
- 通过：MPE 与 MAPE 双双达标 → 模型可在"标注前提下"作演示级应用（仍非临床决策）；
- 偏倚可校准：MPE 超标但 |MPE|<40% 且校准图形线性 → 进入本地校准（5）；
- 失败：MPE ≥40% 或 MAPE >50% → **停止该模型路径**，记录失败原因（人群/剂型/协变量/执行差异），
  不强行校准（他克莫司"外评失败后放弃模型"的先例 [33→12 教训]）。

## 5. 校准/模型更新的方法与预设判据

- **方法（按优先级）**：① **Bayesian 先验更新**：用本地 80% 数据把 Kim 2008 的 CL/F 先验
  分布更新（AdDS 提供的"先验再估计"工作流 [9]）；② 若偏倚呈线性 → 仅校准截距/比例系数
  （元建模，不改动力学结构）；③ 样本 ≥100 例后才允许考虑参数重估（Riley 判据：3 参数 ≥111 例 [16]）。
- **预设判据**：更新后模型在留出 20% 样本上：MPE 相对改善 ≥50%（如 −25%→−10%）
  且 MAPE 不劣于原模型（恶化 ≤5 个百分点）→ **采用更新版**；否则保留外部模型并记录
  "本地更新无净获益"。
- 更新版本同样**只作演示级使用**，直到满足 TRIPOD+AI 的报告线 [18] 与更大样本外评。

## 6. 伦理与知情同意要点

- 前瞻观察性 + 多余 1–2 次抽血（≤15 mL）→ 按"最小风险研究"申报；
- 知情同意书要点：研究目的（评估外部模型在本院人群的适用性）、抽血次数与量、
  数据去标识化（化名 P1–Pn、无标识符出库）、结果**不用于个体临床决策**（明确声明）、
  随时退出权；无利益冲突披露；
- 数据：院内脱敏工作站，仅聚合结果出库；伦理批件归档于研究主文件；
- 回顾性审计（方案一）按质控/质量改进备案，与前瞻研究分开申报。

## 7. 数据管理与质控

- eCRF 字段：化名、采样事件 ID、`COLLECT_DATETIME`、`LAST_DOSE_DATETIME`、
  剂量事件史（医嘱+执行）、`STEADY_STATE_FLAG`、浓度与单位、`TEST_PURPOSE`；
- 双人双录 + 逻辑核查（日期单调、剂量>0、单位一致）；每月质控会；
- 版本控制：模型代码、字典、脚本全部入库；分析前冻结数据集（freeze 日期）；
- 缺失处理：时刻缺失样本标记 `time_missing`（不插补），主分析排除并计数报告。

## 8. 预期产出与投稿定位

- 产出 1：外评报告（MPE/MAPE/P20 + 校准图 + 敏感性）→ 投稿 **Ther Drug Monit /
  Pharmacopsychiatry**（外评方法学短报；氯氮平外评同刊 [7]）；
- 产出 2：本地校准/更新结果（附 Riley 判据与 TRIPOD+AI 对照表）→ 与产出 1 合稿或独立短报；
- 产出 3：数据采集改造的"上线前后对比"（方案三验收数据）→ 院内质量改进报告/药学服务期刊；
- 定位声明：**外评+校准研究，不是模型开发**；报告按 TRIPOD+AI [18]/STROBE 补全；
  不宣称"验证通过即可临床使用"。

## 9. 前置条件与失败条件
**前置**：方案三第 0 批验收达标（时刻、字典、快照三字段 100% 填写）；伦理批件；
`COLLECT_DATETIME` 覆盖率 ≥95%（30 例试点后核查）。
**失败/中止**：① 入组 6 个月内 <30 例 → 评估并延长至 12 个月；仍 <30 例 → 中止，
  转写"采样可行性报告"（这本身是产出）；② 外评 MPE ≥40% → 中止模型路径（4）；
③ `time_missing` 样本占比 >30% → 主分析不可靠，中止并回退到"仅描述浓度分布"；
④ 数据泄露/伦理违规 → 立即中止。
