# 候选问题 × 目标试验七要素矩阵（feasibility-matrix）

方法：对每个候选问题按 Hernán 2016 目标试验框架与 TARGET 报告规范（Cashin 2025）填写七要素，逐项判定本数据集能否实现、用哪个字段、缺什么。判定发生在画像（Phase 1）、领域量（Phase 2）与证据扩充（Phase 3）之后。
数据集底数：5 名患者（P1–P5，伪名）、6 个 TDM 采样点、915 行医嘱、56 行诊断、537 行体征；连接键 `CASE_NO` 五表 100% 可达。

---

## Q1. 阿立哌唑 TDM 描述性试点：C/D 分布、参考范围达标率（双口径）、活性部分代谢比 —— 中国精神科住院患者
- **入组标准 eligibility** → ✅ `检验.PROJECT_NAME∈{阿立哌唑,脱氢阿立哌唑,总阿立哌唑}` 且 `医嘱` 中能重建给药时间线（P1/P3/P4/P5 共 5 个采样点；P2 无阿立哌唑医嘱，单列）
- **治疗策略 treatment strategies** → ⚠️ 由医嘱推断：`FREQUENCY` 本地编码需解码（BID4→2 次/日等，见 data-quality 预处理 #3）；出院带药/作废医嘱剔除
- **分配机制 assignment procedure** → ✅ 观察性：按实际处方（非随机）
- **时间零点 time zero** → ✅ 采样日 `TEST_DATE`；因 `APPLY_DATE→TEST_DATE` 滞后 1–5 天，做敏感性分析（用 APPLY_DATE 与 TEST_DATE 各算一次，报告区间）
- **结局 outcome** → ✅ 描述性结局：剂量归一化浓度 C/D（ng/mL per mg/day）、相对参考范围位置（AGNP 2018 100–350/150–500 vs 2022 修订 120–270/180–380 双口径）、DARI/阿立哌唑代谢比；无因果结局
- **因果对比 causal contrast** → —— 不适用（纯描述，无对比组）
- **分析计划 analysis plan** → ✅ 描述统计 + 精确二项 CI（Wilson）+ 与已发表中国人群 C/D 中位数（gpsych n=299：单药 12.2、IQR 7.4–19.7；台湾 n=64：20.4±9.4）的点对点并列展示
- **判定 verdict：可行（feasible，试点/短篇报告级别）**。绑定检验：缺失的采样时刻不构成障碍——阿立哌唑 t½≈75 h、QD/QN 给药，24 h 给药间隔内浓度波动约 ±20%（exp(−ln2×24/75)≈0.80），而个体间 C/D 变异为 2.7 倍、约一个数量级，故"随机浓度 vs 谷浓度"的不确定性不会改变 C/D 的分布结论。可发布形式：病例系列/短篇报道/letter，目标《临床精神医学杂志》《精神医学杂志》《中国临床药理学杂志》或 Ther Drug Monit（brief）；详见 research-portfolio Q1。

## Q2. TDM 采样实践审计：稳态达标率、采样时间记录缺失、面板使用与医嘱编码可解码性 —— 单中心
- **入组标准 eligibility** → ✅ `检验` 全部 22 行（6 采样点）；医嘱 915 行（审计医嘱编码完整性）
- **治疗策略 treatment strategies** → ⚠️ 审计对象为"监测行为"而非治疗：需区分 TDM 申请（`TEST_PURPOSE`）与实际出结果的分析物（`PROJECT_NAME`）
- **分配机制 assignment procedure** → ✅ 观察性审计（无分配）
- **时间零点 time zero** → ✅ 采样日；稳态判定以"最近一次剂量变更点 + 5×t½（≈15.6 天）"为准（t½ 取汉族人群 62–75 h，Zuo 2006 / 文献）
- **结局 outcome** → ✅ 审计指标：①稳态达标采样占比；②采样时刻可确定占比（本数据 APPLY/TEST 均无时刻 → 0/6）；③面板完整性（P2 面板 4 药全部出结果 ✅）；④无对应医嘱的 TDM 申请数（P2 阿立哌唑 1 次）；⑤TDM 结果与后续剂量调整的时序一致性（观察到 P3 高浓度后减量、P4 低浓度后加量）
- **因果对比 causal contrast** → —— 不适用（审计不设因果对比）
- **分析计划 analysis plan** → ✅ 描述性比例 + 精确 CI；与 AGNP 2018（稳态采血 ≥5×t½）、中国精神科 TDM 共识 2022、住院 TDM 审计文献（Ther Drug Monit 住院审计）逐项对照
- **判定 verdict：可行（feasible，质量改进/审计报告级别）**。绑定检验：稳态判定依赖"最近剂量变更日"的重建，本数据 `START_DATETIME` 100% 填充、剂量变更点可唯一确定（P1/P3/P4/P5），重建误差 <1 天，相对 15.6 天阈值的敏感性低；唯一不确定的 P2 因无阿立哌唑医嘱而被排除于稳态分析（如实报告），不影响其余 5 个采样点的判定。

## Q3. 多药 TDM 面板下的超范围浓度病例系列（氯氮平 721 ng/mL、帕利哌酮 86.4 ng/mL 超上限；阿立哌唑+4 药联用）
- **入组标准 eligibility** → ✅ P2（4 药面板）为主例；P4（阿立哌唑+奥氮平）为对照例
- **治疗策略 treatment strategies** → ⚠️ 回顾性重建：氯氮平 300 mg QN（另见 QD12 重复录入 100 mg，按重复录入处理，敏感性分析按 400 mg/d 重算 C/D：721/400=1.8 vs 721/300=2.4，均落在西安队列 1.6–2.8 区间内，结论稳健）；帕利哌酮 6 mg BID4=12 mg/d → C/D=7.2
- **分配机制 assignment procedure** → ✅ 观察性
- **时间零点 time zero** → ✅ 采样日 2020-12-30（TEST_DATE）；氯氮平自 2020-12-25 起 QN 300 mg，采样距启动 5 天（约 1 个 t½）——**非稳态**，病例报告中须明示
- **结局 outcome** → ✅ 病例描述：各药浓度、C/D、相对参考范围位置、合并用药全景、TDM 后未观察到剂量调整（出院带药维持原方案）→ 临床讨论点（氯氮平 721 高于 350–600 上限的粒细胞/惊厥风险背景）
- **因果对比 causal contrast** → —— 不适用（病例系列）
- **分析计划 analysis plan** → ✅ CARE 病例报告规范；无推断统计
- **判定 verdict：可行（feasible，病例报告/letter 级别）**。绑定检验：氯氮平日剂量的双重解读（300 vs 400 mg/d）使 C/D 在 1.8–2.4 间浮动，两种解读均得出"超范围但 C/D 在中国人群分布内"的同一结论，故剂量解读不确定性不改变病例核心事实（721 ng/mL 超 350–600 上限）。

## Q4. DARI/阿立哌唑代谢比分布（独立成题）
- **判定 verdict：删除（已答）**。该指标作为 CYP2D6 表型代理已被文献充分刻画：儿科 PPK（n=84，PMC9755210）证实代谢比可区分 UM/NM/IM；PM 表型识别方法（PMID 33560096）已发表；东亚 CYP2D6*10 高携带率下代谢比分布已有多个队列。n=6 的代谢比描述无法超越现有知识 → 并入 Q1 作为一个结果表，不单独立项。

## Q5. 浓度-疗效（暴露-反应）关联
- **入组标准 eligibility** → ⚠️ 缺结局量表字段（无 PANSS/CGI/BPRS 任何评分）
- **治疗策略 treatment strategies** → ✅ 可重建
- **分配机制 assignment procedure** → ✅ 观察性
- **时间零点 time zero** → ✅ 可定
- **结局 outcome** → ❌ **缺失字段：结局量表（PANSS/CGI/BPRS/UKU）**——五张表均无任何疗效或不良反应量表
- **因果对比 causal contrast** → ——（不适用：该方向在领域层面已被系统评价与荟萃回答，本数据又无结局量表，因果对比无从建立）
- **分析计划 analysis plan** → 若有量表：浓度分层 vs 应答率（台湾 n=64 的范式）；但量表缺失使分析计划不可执行（见 verdict 行）
- **判定 verdict：不可行 + 已答（删除）**。缺失字段：结局量表。绑定检验：领域层面已给出结论——Sparshatt 2010 系统评价（21 篇报告，结论"浓度与临床应答关系证据有限，TDM 价值有限"）与 Hart 2022 荟萃（N=3,373，浓度-疗效证据等级 C/D、相互矛盾）已经系统回答；本数据即便有量表，n=6 也远低于检测浓度分层的需求。**退而求其次**：数据仍可描述"TDM 结果与随后剂量调整行为"的时序（P3 高浓度→减量 15→10 mg；P4 低浓度→加量 10→15 mg；P1 出院减量），作为 Q2/Q3 的临床行为学证据，不声称疗效。

## Q6. CYP2D6 基因型-阿立哌唑暴露关联
- **入组标准 eligibility** → ✅ 可定
- **治疗策略 treatment strategies** → ✅ 可重建
- **分配机制 assignment procedure** → ✅ 观察性
- **时间零点 time zero** → ✅ 可定
- **结局 outcome** → ❌ **缺失字段：基因型数据**（五表无任何 PGx 检测结果）
- **因果对比 causal contrast** → ——（不适用：基因型-暴露关联已被大样本队列回答，本数据无基因型字段，无法建立该对比）
- **分析计划 analysis plan** → 若有基因型：代谢比/浓度按基因型分层（Lancet Psychiatry 2019 队列范式）；但基因型字段缺失使分析计划不可执行（见 verdict 行）
- **判定 verdict：不可行 + 已答（删除）**。缺失字段：基因型（回顾性不可补）。绑定检验：领域已答——CYP2D6 对阿立哌唑暴露的影响已被大样本回顾队列（Lancet Psychiatry 2019）、系统评价与荟萃（Zhang 2019，J Clin Pharm Ther）、儿童 PPK（n=84）与药理学数据库（PharmGKB/CPIC）反复量化；本数据 n=5 无基因型，无法贡献新信息。**退而求其次**：数据仍可报告 DARI/阿立哌唑代谢比（0.17–0.49）与文献 UM/NM/IM 区间的对照描述（并入 Q1），仅作表型线索、不作基因型结论。

## Q7. 中医证型-血药浓度关联（诊断记录含 心脾两虚证/痰气互结证/肝郁脾虚证 等）
- **入组标准 eligibility** → ✅ 证型字段存在（`诊断记录.DIAGNOSTIC_NAME`，56 行，100% 填充）
- **治疗策略 treatment strategies** → ✅ 可重建
- **分配机制 assignment procedure** → ✅ 观察性
- **时间零点 time zero** → ✅ 可定
- **结局 outcome** → ⚠️ 浓度可定；但组间比较需要足够每组样本
- **因果对比 causal contrast** → ⚠️ 证型为时变/多重诊断（同一患者多次记录不同证型），无固定分组
- **分析计划 analysis plan** → 证型分组比较浓度 → **绑定检验失败**：n=5 例、2–3 个证型组，按文献 C/D 的变异（CV≈50%），在 α=0.05、功效 80% 下最小可检测组间差异需约 3–4 倍，超出本数据已观测的 2.7 倍跨度——组间比较在数学上无功效
- **判定 verdict：不可行**。缺失字段：样本量（至少 30–50 例/组才有任何组间比较意义；需医院 HIS 全量抽取）。**退而求其次**：证型/中医诊断分布与浓度的描述性并列（不检验），并入 Q1。

## Q8. 模型引导的个体化给药（model-informed precision dosing / 个体清除率估计）
- **入组标准 eligibility** → ✅ 可定
- **治疗策略 treatment strategies** → ⚠️ 剂量可重建，但无给药时刻（医嘱 `START_DATETIME` 有，给药执行无记录）
- **分配机制 assignment procedure** → ✅ 观察性
- **时间零点 time zero** → ⚠️ 采样时刻缺失（见 Q1）
- **结局 outcome** → ❌ **缺失字段：给药后采样时间点与多次浓度-时间序列**（每例仅 1–2 个浓度，无法估计个体清除率/个体 PK 参数）
- **因果对比 causal contrast** → ——（不适用：单点采样的描述性数据无法估计个体 PK 参数，无因果对比可言）
- **分析计划 analysis plan** → 群体 PK（NONMEM/PopPK）需要每例 ≥2–3 个带时刻的浓度 → n=5、单点采样，绑定：个体 PK 参数不可识别
- **判定 verdict：不可行**。缺失字段：带时刻的多次浓度序列（回顾性不可补）。**退而求其次**：C/D 的区间描述仍可行（Q1）——绑定检验支持：缺失的采样时刻造成的日内波动约 ±20%，远小于 2.7 倍个体间变异，故"不能估计个体清除率"与"能描述 C/D 分布并界定斜率符号"是不同层级的结论，后者成立。

## 汇总判定

| 问题 | 判定 | 依据 | 缺失字段（若不可行） |
|---|---|---|---|
| Q1 阿立哌唑 TDM 描述性试点 | **可行**（试点/短篇） | 描述性设计；绑定检验通过（±20% 日内波动 << 2.7 倍个体间变异） | — |
| Q2 TDM 采样实践审计 | **可行**（审计/QI） | 审计指标全部可由现有字段构造 | — |
| Q3 多药面板超范围病例系列 | **可行**（病例报告） | CARE 可报；剂量双重解读不改变结论 | — |
| Q4 代谢比独立成题 | 已答，删除 | 文献已充分刻画 | — |
| Q5 浓度-疗效 | **不可行 + 已答，删除** | 系统评价/荟萃已答（证据等级 C/D）；缺结局量表 | 缺失字段：结局量表（PANSS/CGI）；退而求其次：TDM-剂量调整时序描述 |
| Q6 基因型-暴露 | **不可行 + 已答，删除** | Lancet Psychiatry 2019 等已答；缺基因型 | 缺失字段：基因型数据；退而求其次：代谢比描述 |
| Q7 中医证型-浓度关联 | **不可行** | n=5 组间比较无功效（MDE≈3–4 倍 > 观测 2.7 倍） | 缺失字段：样本量；退而求其次：证型分布描述 |
| Q8 模型引导个体化给药 | **不可行** | 个体 PK 参数不可识别 | 缺失字段：带时刻的多次浓度序列；退而求其次：C/D 区间描述（Q1） |

**存活课题**：Q1、Q2、Q3（均为描述/审计/病例级别，无推断性统计）。判断口径：本数据 5 例/6 采样点的规模决定了**没有任何推断性课题可存活**；存活课题的发布形态、最近已发表工作、差异轴与可执行方案见 `research-portfolio.md` 与 `study-protocol.md`。
