# 研究方案（study-protocol）— 可执行版

> 每节按字段名给出变量构造算法、估计量、缺失与哨兵值处理、敏感性分析、产出表图、
> 报告规范对照、前置条件与中止条件。任何第二分析者应能不加询问地执行。
> 患者一律以化名 P1–P5 指代（P 表：`P = f(PATIENT_ID)`，按 PATIENT_ID 升序编号）。

## 通用数据管道（所有课题共用，先执行）

1. 读取 `20260803TDM.xlsx` 五张表（病案首页/医嘱记录/检验/诊断记录/体征），统一 `CASE_NO` 为连接键（诊断记录 `PATIENT_ID` 为空，禁止用其连接）。
2. 化名：`pids = sorted(病案首页.PATIENT_ID.unique())`，`P1..P5` 依序。
3. **医嘱清洗**：
   - 药嘱：`医嘱记录.DRUG_FLAG == 1`；
   - 排除：`MEDICATION_WAY ∈ {出院带药, 退药}`；
   - 哨兵：`END_DATETIME` 匹配 `^0+[/-]0+[/-]0+.*$` 视为"出院时仍有效"（出院日=病案首页 `DIS_DATE` 的 23:59）；
   - 日期解析：`%d/%m/%Y %H:%M:%S`，失败则 `%d/%m/%Y`；
   - 频次解码（日次数）：`QD/QN/QD11/QD12/QD16→1`，`BID/BID1/BID5/BID8→2`，`TID/TID4→3`，`BID4→[1,2]`（区间），`ONCE→`仅当 `MEDICATION_WAY ∈ {口服,静滴,塞肛,肌注+注射器5ml}` 且起止时间构成跨度时按 1 次计，否则不计；
   - 商品名→检验项目映射：`阿立哌唑{阿立哌唑口崩片(国产),阿立哌唑片(安律凡),博思清}`；`帕利哌酮（帕潘立酮）{芮达,帕利哌酮}`；`奥氮平{*奥氮平片}`；`氯氮平{*氯氮平片}`；`氯硝西泮{氯硝西泮片}`。
4. **日剂量重建函数** `daily_dose(patient, draw_date, project)`：
   - 取该患者药嘱中 `DRUG_NAME` 匹配项目映射的医嘱，排除出院带药/退药；
   - 活性判定：`START_DATETIME ≤ draw_date` 且（`END_DATETIME` 为哨兵或 `draw_date ≤ END_DATETIME`）；
   - 同一 `DRUG_NAME` 多条活性医嘱（如氯氮平 QD12+QN 分次）→ **相加**；不同 `DRUG_NAME` 重叠（如博思清+口崩片）→ `lo=单商品最大日剂量，hi=全部相加`；
   - 返回 `(lo, hi)`；无活性医嘱→`(0,0)`→该例 C/D 标记 `NA`（不可计算，不插补）。
5. **检验清洗**：`REFFR_SCOPE` 按 `-` 拆 `(ref_lo, ref_hi)`；无区间（脱氢阿立哌唑）不作出界判定；单位声明为 ng/mL（与参考区间一致，UCUM 标注）。
6. **出界规则**：`低 = TEST_RESULT < ref_lo`；`高 = TEST_RESULT > ref_hi`；`带内` 其余；`警戒` 按 Q3 阈值。
7. **稳态判定**：`距上次剂量变更天数 ≥ 5×t½/24`，t½：阿立哌唑 75 h、脱氢 94 h、奥氮平 30 h、氯氮平 16 h、帕利哌酮 24 h、氯硝西泮 35 h；"上次剂量变更"=该药活性医嘱在采血日前的最近 `START_DATETIME` 或 `END_DATETIME`。

## Q1 协议 — 阿立哌唑 C/D 与代谢比人群基准

**目标人群**：检验表 `PROJECT_NAME ∈ {阿立哌唑, 脱氢阿立哌唑, 总阿立哌唑}` 的采血点；主表限定"稳态或接近稳态"（≥10 天剂量不变），非稳态单独附表。
**变量构造**：
- `C` = `TEST_RESULT`（原形/总分别）；`D_lo/D_hi` = `daily_dose(P, TEST_DATE, 项目)`；
- `C/D` = `C/D_hi`（保守，区间上界剂量）与 `C/D_lo` 两列，或直接存区间；
- `代谢比` = `TEST_RESULT(脱氢阿立哌唑)/TEST_RESULT(阿立哌唑)`（同日配对）；
- 单位换算（外比时）：nM/mg→ng/mL/mg 乘 0.4484（阿立哌唑 MW 448.4）。
**分析**：
1. 每例 C/D 与代谢比列清单（区间形式）；
2. 与基准比较：EM 中位数 11.8、PM 中位数 20.4 ng/mL/mg（原形；PMID 17828532）、活性部分 16.6/24.2；Oslo 25/75 百分位分层法（PMC11098931）；
3. 定位规则：`<0.5×EM中位=低清除样`、`0.5–1.5×EM中位=EM样`、`1.5–2×EM中位=IM样`、`>2×EM中位=PM样`（先验分层，写明为探索性阈值）；
4. 一致性检查：代谢比 <0.25 且 C/D≥2×EM 中位 → 记"慢代谢签名一致"；不一致则讨论合并用药/依从性。
**敏感性**：①频次双方案（BID4=1×/2×）；②重叠医嘱单/全量；③采血时刻 0–24 h：C 谷值校正 = C/1.25（阿立哌唑）、C/1.19（脱氢），重算定位与出界；④排除非稳态样本复算。
**产出表图**：表1 患者特征（化名、性别、年龄、诊断、住院天数）；表2 每例 C/D 区间、代谢比、定位档；图1 C/D 森林点图（区间须）叠加人群 EM/PM 带；图2 代谢比-浓度散点（按患者着色）；表3 敏感性矩阵（各假设下定位档是否改变）。
**报告规范**：STROBE 22 条 + RECORD 6.2（入组所用编码=院内检验项目与 REFFR_SCOPE，未经验证研究，明示）；STROBE item 10 写"样本量由可得数据决定（n=5 患者/6 采血点）"，附 MDE 与区间宽度（见 portfolio）。
**前置条件**：预处理清单 #1–#10 完成；确认检验单位为 ng/mL。
**中止条件**：若信息科确认 `BID4` 语义与 `DOSAGE` 单位存在系统性错误（>1 个 TDM 药受影响）且无法修正 → 中止，改为仅报告"剂量重建不可靠"的方法学记录；若 P2 阿立哌唑处方缺失原因无法查证 → 该例从主表移除并注明。

## Q2 协议 — TDM "结果→剂量调整"闭环审计

**目标人群**：全部有 `REFFR_SCOPE` 的检验行（n=21）。
**变量构造**：
- `出界`：按通用规则 6；
- `结果后调整`：对每例出界行，查该患者医嘱中同药（项目映射）的医嘱，其 `START_DATETIME ∈ (TEST_DATE, TEST_DATE+7d]` 且日剂量（通用函数）与结果前最后活性日剂量比较 → `升/降/不变/无新医嘱`；
- `方向一致性`：结果=高且调整=降（或结果=低且调整=升）→ 一致；反之为不一致。
**分析**：
1. 出界比例 + Clopper-Pearson 95%CI；
2. 按药物分层的出界比例（n 小，仅描述）；
3. 调整事件清单（每例一行：化名、结果、日期、调整、方向一致性）；
4. 与已发表比例对照：Tveit 2020（抗抑郁药 3.6–27.1% 超上限）；AGNP 共识"浓度指导调整"预期。
**敏感性**：调整窗口 3 天/7 天/14 天；出界定义改用谷值校正浓度（Q4）重算。
**产出表图**：图1 每例时间线（浓度点、剂量台阶、调整标记）；表1 出界率（总体+按药，含精确区间）；表2 调整事件；图2 出界比例 vs 文献比例点图（无误差棒，纯对照）。
**报告规范**：STROBE（审计即观察性）；如按 QIP 输出另用 SQUIRE 2.0。
**前置条件**：通用管道通过；`END_DATETIME` 哨兵处理验证（抽查 P4 医嘱起止与出院日期一致）。
**中止条件**：若 >20% 检验行无法匹配到患者医嘱（如 P2 阿立哌唑型缺处方）且影响出界率分母 → 明确分母范围后继续（只报有处方匹配的亚组），否则中止。

## Q3 协议 — 浓度-毒性代理结局审计

**目标人群**：检验表 `PROJECT_NAME ∈ {氯氮平, 奥氮平, 帕利哌酮（帕潘立酮）}` 的患者（P1、P2）。
**变量构造**：
- `阈值带`：氯氮平 350–600（上限 600，警戒 >1000）；奥氮平 20–80，增重阈值 ≥20.6；帕利哌酮 20–60；
- `谷/峰区间`：氯氮平 `C/1.68–C`（间隔 12 h）、帕利哌酮 `C/2.0–C`（间隔 24 h）、奥氮平 `C/1.32–C`（间隔 12 h，Q1 的 BID 场景；若按 QD 则 1.61）；
- `体重轨迹`：`体征.SIGN_TYPE=体重` 的 `RECORD_CONTENT`（数值化），采血日前 14 天至出院；`Δ体重%` ≥7% 标记；
- `EPS 代理`：该患者药嘱 `DRUG_NAME` 含 `安坦|苯海索` 且 `START_DATETIME` 在采血日前后 14 天内。
**分析**：逐例陈述（案例系列，无推断）；氯氮平例给出 429–1211 的谷/峰区间并对照 600/1000 线；奥氮平例对照 20.6 阈值与体重轨迹；帕利哌酮例对照 60 上限与 43.2–86.4 区间。
**敏感性**：t½ 取文献范围端点（氯氮平 12–20 h → 峰/谷 1.52–1.99×）重算区间。
**产出**：表1 每例阈值-浓度对照（含区间）；图1 体重轨迹（奥氮平例）；图2 P2 时间线（氯氮平浓度区间带 + 1000 警戒线）。
**报告规范**：CARE（病例系列声明：n=2 报告为 2 例案例系列而非队列）。
**前置条件**：确认体重字段单位 kg、身高可用；P2 吸烟状态不可得（吸烟显著降低氯氮平浓度，PMID 41293932）→ 在局限中声明。
**中止条件**：若确认检验单位非 ng/mL（如 µg/L）→ 全部阈值换算后再继续，否则中止并记录。

## Q4 协议 — 敏感性载具（并入 Q1–Q3 分析章节）

**方法**：对每个采血点计算 `峰/谷比 = exp(ln2 × 给药间隔 / t½)`（间隔=日剂量方案倒数，QD→24 h、BID 分次→12 h）；假设"采血时刻在间隔内均匀/极端（0 与 24 h）"，对浓度作谷值校正 `C_谷 = C / 峰谷比`，重算：①出界状态；②C/D 定位；③阈值带判定；输出"结论变化矩阵"。
**产出**：表（每采血点：原始 vs 谷值校正的分类，标注是否翻盘）+ 文字结论（阿立哌唑±12% 不翻主结论；氯氮平/帕利哌酮跨线，报区间）。
**报告规范**：方法学小节按 PMID 41724034 的换算方法（引用），并声明换算公式来源与验证（该文配对数据 RE<15%，仅适用于其药物；本方案按同式类推并注明"未在本机构验证"）。

## Q6a 协议 — 外部模型模拟（退而求其次的"预测"版本）

**What**：用已发表阿立哌唑群体药动学参数（优先 38957736 中国患者模型：体重+氟西汀合并用药影响清除率；备选 26902506 韩国健康者模型），在本数据协变量（体重、年龄、性别；`体征` 体重/身高→BMI）下模拟稳态浓度分布（如 NONMEM/Simulx 或解析式 `C_ss = F·D/(CL·τ)`，CL 取群体值±个体间变异），输出每例"预期浓度带"并与实测 C/D 对照。
**边界声明（必须写入）**：未用本地数据拟合/校准；预测区间宽（个体间清除率变异 30–60% + 无基因型）；**不作临床剂量决策依据**；产出定位为方法学演示与前瞻性数据补采的动机。
**前置条件**：获得 38957736 模型参数表（或全文参数）；体重/身高齐备（已核：5 例均有身高，体重 3–7 次/例）。
**中止条件**：若模型参数不可获取（付费全文）→ 改用 26902506 或文献综述范围（32008418），并在方法中注明参数来源与版本。
