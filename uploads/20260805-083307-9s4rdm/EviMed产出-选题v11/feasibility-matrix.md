# 候选课题 × 目标试验矩阵（feasibility-matrix）

> 判定标准：目标试验七要素（Hernán 2016；TARGET 报告规范 Cashin 2025）逐项核对——
> 入组标准、治疗策略、分配机制、时间零点、结局、因果对比、分析计划。
> 对无法直接从字段读出的要素：先量化缺口代价（与所研究效应同量纲比较），再写可弥合的假设并做敏感性分析。
> 任何"不可行"判定必须在同一判定行写出缺失字段（missing field）——仅当答案在假设范围内确实翻盘才判不可行，并给出退而求其次的可答问题。
> 患者一律以化名 P1–P5 指代（按 PATIENT_ID 升序分配，稳定顺序）。

**总体数据事实（供所有课题共用）**：5 名住院精神科患者（P1–P5）；检验 22 行、含阿立哌唑/脱氢阿立哌唑/总阿立哌唑/奥氮平/氯氮平/帕利哌酮/氯硝西泮 7 个项目；医嘱 915 行；参考区间与 AGNP 共识一致（阿立哌唑 100–350、总阿立哌唑 150–500、奥氮平 20–80、氯氮平 350–600、帕利哌酮 20–60 ng/mL）。关键派生量：总阿立哌唑 C/D 组间离散 4.5–4.7 倍（两种频次解码方案下均成立）；21 个可评估结果中 10 个出界（4 高 6 低）；脱氢/阿立哌唑代谢比 0.17–0.49。

## Q1 — 阿立哌唑剂量归一化浓度（C/D）与代谢比对人群参考的描述性基准

科学问题：本机构住院患者的阿立哌唑 C/D 与脱氢/原形代谢比，处于已发表人群参考（EM/PM 分层中位数、TDM 登记处 25/75 百分位）的什么位置？是否存在慢代谢表型签名？

| 目标试验要素 | 可实现性 | 依据字段 / 缺失字段 |
|---|---|---|
| 入组标准 | ✅ | 检验表 `PROJECT_NAME=阿立哌唑/脱氢阿立哌唑/总阿立哌唑` + 病案首页 `IN_DATE`；限定住院窗内采血 |
| 治疗策略 | ⚠️ | 医嘱重建日剂量（`DRUG_NAME`×`DOSAGE`×`FREQUENCY` 解码）；`BID4` 与重叠医嘱产生 2 倍歧义，按区间处理；P2 阿立哌唑无处方 → 该例排除（同 Oslo 登记处"无剂量信息排除"规则） |
| 分配机制 | ✅ | 观察性，按实际处方 |
| 时间零点 | ⚠️ | 无给药时刻/采血时刻；用 `TEST_DATE`+医嘱 `START_DATETIME` 重建"距上次剂量变更天数"，稳态判定按 5×t½（阿立哌唑 75 h→15.6 天） |
| 结局 | ✅ | C/D（ng/mL per mg/day）与代谢比（无单位）为连续结局；分类结局=相对人群参考的位置（低/正常/高） |
| 因果对比 | —— | 非因果设计：单组描述 + 对已发表人群分布的位置比较 |
| 分析计划 | ✅ | 见 study-protocol Q1；频次解码双方案 + 采样时刻 0–24 h 敏感性 |
| **判定** | ✅ **可行** | 作为描述性基准研究。关键不变量：C/D 分类对解码与采样时刻均稳健（见下） |

**绑定检验（采样时刻缺失是否卡得住）**：阿立哌唑半衰期约 75 h、给药间隔 24 h，间隔内峰/谷比 = exp(ln2×24/75) ≈ **1.25×**（±12%）；而本研究实测组间 C/D 离散 **4.5–4.7 倍**、基因型分层效应（Jukić 2019）**1.59 倍**——采样时刻不确定比所研究信号小约一个数量级，**不绑定**。频次 `BID4` 歧义（P4：10 vs 20 mg/天）使 C/D 在 20–40 之间移动，但两端都高于 EM 中位数（约 11.8 ng/mL/mg）1.7–3.4 倍——**分类结论（慢代谢样）稳健**。敏感性分析详见 study-protocol Q1/Q4。
**注意**：P3 原形 354 与 P4 总 503 的"超上限"次生结论在谷值校正（÷1.25）后回到区间内——报告不得把"超治疗窗"当主结论。

## Q2 — 精神科 TDM "结果→剂量调整"闭环审计

科学问题：住院 TDM 检测出界率多高？出界结果之后是否触发剂量调整？调整方向与浓度方向是否一致？

| 目标试验要素 | 可实现性 | 依据字段 / 缺失字段 |
|---|---|---|
| 入组标准 | ✅ | 检验表全部行（有 `REFFR_SCOPE` 者可判出界）+ 对应患者医嘱 |
| 治疗策略 | ⚠️ | 同 Q1 剂量重建（频次解码区间）；`ORDER_STATE` 区分停止/作废 |
| 分配机制 | ✅ | 观察性 |
| 时间零点 | ✅ | 以 `TEST_DATE`（结果日）为事件日；`START_DATETIME` 定位结果后新医嘱 |
| 结局 | ✅ | 主结局=出界状态（`TEST_RESULT` vs 拆分后 `REFFR_SCOPE`）；次结局=结果后 7 天内同药医嘱剂量变化（升/降/不变）与方向一致性 |
| 因果对比 | —— | 审计/描述，无因果声明 |
| 分析计划 | ✅ | 比例+精确 95%CI；变化事件逐例列举（n=21 尺度） |
| **判定** | ✅ **可行** | 模板=Tveit 2020 挪威 TDM 登记处十年审计。**实测信号**：出界 10/21=0.48（95%CI 0.26–0.69，宽 0.43）；可见 1 例（P3，阿立哌唑 354 高、4/1 出结果，9/1 剂量 15→10 mg/天）结果后降量，另 4 例出界无调整——"监测-行动"存在可观察差异 |

**精度口径（按最小可检出效应与预期区间宽度表述，Bland 2009）**：n=21 个可评估结果。最小可检出效应：对"出界率=30%"（AGNP 体系下真实队列的常见预期）的偏离，α=0.05、目标检验效能 0.80 时仅能检出 ≥0.25–0.30 的绝对差异（n=21 下对应效能 0.69@0.25、0.83@0.30）——即本审计只能检出"出界率显著偏离 30% 达 25–30 个百分点"级别的信号，细粒度比较留待扩充样本。预期区间宽度：p̂=0.48 时 95%CI≈0.26–0.69。结论须按此粒度表述。

## Q3 — 无疗效量表条件下的浓度-毒性代理结局审计

科学问题：以已发表浓度-毒性阈值为基准，本数据中的氯氮平/奥氮平/帕利哌酮浓度是否处于中毒风险带？可观察的代理结局（体重轨迹、抗胆碱能药物医嘱）与浓度是否一致？

| 目标试验要素 | 可实现性 | 依据字段 / 缺失字段 |
|---|---|---|
| 入组标准 | ✅ | 检验表 `PROJECT_NAME∈{氯氮平,奥氮平,帕利哌酮（帕潘立酮）}` 的患者 |
| 治疗策略 | ⚠️ | 同 Q1 剂量重建；氯氮平 P2 为 100 mg QD12 + 300 mg QN=400 mg/天（同一商品名分次，无歧义） |
| 分配机制 | ✅ | 观察性 |
| 时间零点 | ✅ | `TEST_DATE` 为事件日；体重轨迹取采血日前后的 `体征.RECORD_CONTENT`（SIGN_TYPE=体重） |
| 结局 | ✅ | 代理结局（无疗效量表，故用毒性代理）：①浓度相对阈值带（氯氮平 >600 上限、接近/超过 1000 ng/mL 警戒；奥氮平 ≥20.6 ng/mL 增重阈值；帕利哌酮 >60 上限）；②体重变化 ≥7%（随访 11–49 天）；③EPS 代理=`医嘱记录.DRUG_NAME` 含安坦/苯海索的抗胆碱能医嘱 |
| 因果对比 | —— | 案例式描述（n 为个位），不推断因果 |
| 分析计划 | ✅ | 逐例陈述 + 阈值对照表 |
| **判定** | ✅ **可行（描述性）** | 模板=Freeman & Oyewumi 1997 氯氮平阈值、Perry 2005 奥氮平 20.6 ng/mL 阈值。**实测**：P2 氯氮平 721 ng/mL（>600；谷/峰校正后 429–1211，跨 1000 警戒线，见 Q4 敏感性）；P2 帕利哌酮 86.4（>60）；P1 奥氮平 54.2（>20.6）且体重 80→82 kg/11 天；P4 有苯海索片 BID4 医嘱（EPS 处理代理） |

**绑定检验（"无疗效量表"是否卡得住）**：所研究效应若为"疗效"，则本数据无任何疗效测量（无 PANSS/BPRS/CGI 字段、`DIAGNOSTIC_CONTENT` 全空、出院后无随访）——缺口即结局本身，**绑定（100%）**；因此本课题不做疗效声明，只做毒性/安全性代理（阈值来自已发表文献，同一量纲可比）。这一降级设计（退而求其次）就是本课题本身。

## Q4 — 采血时刻缺失与频次解码歧义的方法学敏感性分析（贯穿 Q1–Q3 的载具）

科学问题：当采血时刻未知时，把"随机时刻浓度"当"谷浓度"解释会引入多大误差？本地频次编码歧义（BID4/重叠医嘱）在多大范围内改变 Q1–Q3 的结论？

| 目标试验要素 | 可实现性 | 依据字段 / 缺失字段 |
|---|---|---|
| 入组标准 | ✅ | 全部检验行 |
| 治疗策略 | ⚠️ | 剂量重建双方案（BID4=1×/2×；重叠医嘱=单/全量） |
| 分配机制 | ✅ | 观察性 |
| 时间零点 | ⚠️ | 采血时刻缺失 → 显式假设"距上次给药 0–24 h 均匀/极端分布" |
| 结局 | ✅ | C/D 与出界分类的**区间**（非点值） |
| 因果对比 | —— | 方法学敏感性，无因果 |
| 分析计划 | ✅ | 半衰期-间隔模型：C(t)/C谷=exp(ln2·t/t½)，按药逐个计算峰/谷比，重算所有分类 |
| **判定** | ✅ **可行（方法学转移）** | 直接移植 **PMID 41724034 的"随机浓度→稳态谷浓度换算"方法**（该文以配对数据验证，RE<15%）：对阿立哌唑（t½ 75 h）换算系数 ≤1.25×、影响小；对氯氮平（t½ 16 h、间隔 12 h）峰/谷 1.68×、帕利哌酮（t½ 24 h）2.0×——这些药物的出界判定必须带区间报告 |

**已算好的敏感性结论（同量纲）**：氯氮平 P2=721：若采血为峰→谷 429（低于 600 上限），若为谷→峰 1211（超 1000 警戒）——**氯氮平"是否出界/是否接近警戒"对采血时刻敏感**，结论必须报区间 429–1211。阿立哌唑：P3/P4 校正后回到参考区间内，"超治疗窗"次生结论翻盘，但 C/D 对人群参考的比较（主结论）不翻盘。帕利哌酮 P2=86.4：谷/峰校正 43.2–86.4，跨 20–60 上限的结论仅在谷值假设下成立。

## Q6 — 个体化用药预测模型（模型化精确给药 MIPD）：训练/验证 vs 外部模型应用

科学问题（对应委托方第 6 问）：这份数据能否支撑个体化用药的预测模型？

| 目标试验要素 | 可实现性 | 依据字段 / 缺失字段 |
|---|---|---|
| 入组标准 | ✅ | 检验行 + 医嘱 + 病案首页 |
| 治疗策略 | ⚠️ | 同 Q1 剂量重建 |
| 分配机制 | ✅ | 观察性 |
| 时间零点 | ❌ | 无给药执行时刻、无采血时刻（MIPD 的贝叶斯反馈需要"浓度-时间"配对） |
| 结局 | ✅ | 预测目标=个体稳态浓度/给药后浓度（可计算） |
| 因果对比 | —— | 预测模型，非因果 |
| 分析计划 | ❌ | 训练/验证：5 名患者、22 个样本、每患者 1–2 个采血点——无法估计哪怕单室模型的个体参数；无独立验证集 |
| **判定** | ❌ **训练/验证个体化预测模型：不可行。缺失字段：采血时刻、给药执行记录、CYP2D6/CYP3A4 基因型、足够样本量（EPV 约束下需要每参数 ≥10 事件，本数据每药 ≤6 个浓度点）。** 绑定检验（同量纲）：预测目标是个体浓度，而本数据可测的组间 C/D 离散为 4.5–4.7 倍，已发表群体模型个体间清除率变异约 30–60%，基因型分层 1.59 倍（Jukić 2019），依从性未知跨度 0–100%，采血时刻 ±12–50%（按药）——把这些缺口叠加，95% 预测区间跨约 10 倍，而治疗窗 150–500 ng/mL 仅 3.3 倍：**无基因型+无依从性+无采样时刻的模型无法在治疗窗内做剂量决策，缺口确实卡得住**。**退而求其次（仍可回答）**：①Q1 的 C/D 百分位定位（对已发表人群分布的位置描述，即"预期浓度带"的静态版本）；②外部模型模拟：借用已发表阿立哌唑群体药动学参数（PMID 32008418 综述 16 模型；26902506 韩国模型；38957736 中国 TDM 数据模型），在给定体重/年龄/性别下模拟预期浓度带，明确标注"未用本地数据验证、预测区间宽、不作剂量决策依据"；③为院方补采数据（采血时刻+给药时刻+基因型）后的前瞻性 MIPD 试验设计（见 study-protocol Q6 前置条件） |

## 矩阵小结

| 课题 | 判定 | 一句话理由 |
|---|---|---|
| Q1 C/D 基准 | ✅ 可行 | 信号 4.5× ≫ 缺口（采样 ±12%、解码 2×），分类稳健 |
| Q2 闭环审计 | ✅ 可行 | 出界 0.48（CI 0.26–0.69），P3 见结果后降量，可观察 |
| Q3 毒性代理审计 | ✅ 可行（描述性） | 阈值文献充分（氯氮平 1000、奥氮平 20.6、EPS 代理），P2/P1 有实据 |
| Q4 敏感性方法学 | ✅ 可行 | 方法可移植（随机→谷浓度换算），氯氮平/帕利哌酮必须报区间 |
| Q5 疗效关联 | ❌ 不可行 | 缺失字段：疗效结局量表/随访；缺口=结局本身（100%），无弥合假设 |
| Q6 预测模型训练 | ❌ 不可行 | 缺失字段：采血/给药时刻、基因型、样本量；预测区间 ~10× ≫ 治疗窗 3.3× |
| Q6a 外部模型模拟/C/D 定位 | ✅ 可行 | 描述性应用，须声明未验证 |

**绑定检验说明**：本矩阵对"采样时刻缺失"（Q1/Q4）、"频次解码歧义"（Q1）、"无疗效量表"（Q3/Q5）、"无基因型/无执行记录/小样本"（Q6）分别做了同量纲比较——半衰期对给药间隔、C/D 离散对基因型效应、缺口叠加对治疗窗宽度，全部量化；判定不可行的课题（Q5、Q6）的缺失字段已在判定行逐项写出（疗效结局量表/随访；采血时刻、给药执行记录、CYP2D6/CYP3A4 基因型、样本量），并做了弥合假设检验，同时给出退而求其次的可答问题。
