# 可行性矩阵（candidate question × target-trial）

每个候选问题按 Hernán 目标试验七要素逐项判定：✅=字段直接支持，⚠️=可推断但需假设/敏感度分析，❌=缺失。判定依据以本数据实测为准（详见"缺项成本"栏，缺失字段必须量化其代价）。

## Q1 预测建模：以暴露/表型预测稳态浓度或达标剂量（MIPD）
- 科学问题：给定人口学+剂量+代谢比，预测阿立哌唑稳态浓度落在参考范围内的概率，反推达标剂量。
- 目标试验要素：
  - 纳入标准 → ✅ `MAIN_DIAGNOSIS_CODE`（F20/F31 系）+ `IN_DATE`/`CASE_NO`
  - 治疗策略 → ⚠️ 由医嘱重建（`START/END_DATETIME`、`DOSAGE×FREQUENCY`）；无给药记录，依从性设为"住院观察下近似 100%"（精神科住院给药有护士核对，合理）
  - 分配机制 → ✅ 观察性、按实际处方
  - 时间零 → ✅ 医嘱 START_DATETIME（分钟级）；采样日=SAMPLENO 前缀
  - 结局 → ✅ 检验浓度（原型/代谢物/总量）；参考范围（同行）
  - 因果对照 → 预测性（非因果），无需对照臂
  - 分析计划 → ✅ 分层/嵌套交叉验证；ML（模板 PMC9552071）或 PPK（模板 PMC10925492）
- **缺项成本量化**：无给药时刻。阿立哌唑 t½≈75h、QD/QN 给药 → 给药间隔内浓度摆动 exp(−ln2×24/75)≈0.80，即 ≤20%；本数据个体间 C/D 跨度 7.99–23.60（2.95 倍）。未知采样时刻引入的误差量级（<20%）远小于建模目标信号（约 3 倍）→ **不构成决定性阻碍**（若换 t½=2h 的药物则构成）。
- **缺项假设**：谷浓度近似（采样在早晨给药前，符合检验科 TDM 惯例）；敏感度分析：将采样时刻视为 [给药后 0,24h] 均匀区间重算。
- 判定：**可行**（预测目标）；所需样本量见研究组合。

## Q2 同类药分析：类别内 C/D 分布与参考范围达标（描述+协变量）
- 科学问题：抗精神病药类别中，各药剂量校正浓度（C/D）的分布、参考范围内外比例、及年龄/性别/合并用药协变量。
- 目标试验要素：
  - 纳入标准 → ✅ 检验表有浓度 + 医嘱有同日剂量（C/D 可算）
  - 治疗策略 → ⚠️ 同 Q1（医嘱重建）
  - 分配机制 → ✅ 观察性
  - 时间零 → ✅ 采样日
  - 结局 → ✅ C/D（连续）、范围内/外（二元）
  - 因果对照 → 描述性+协变量关联，无因果主张
  - 分析计划 → ✅ 分位数回归/多元线性（模板 PMID 36286707）
- 缺项：无。DHC 无参考范围属正常设计（AGNP 只给原型与活性部分范围）。
- 判定：**可行**。注意：附带检测（未用该药但面板含其浓度，样本中 P2 的 ARI 63 ng/mL）必须用医嘱暴露排除，否则污染 C/D 分布。

## Q3 关联挖掘：中药+西药共处方模式
- 科学问题：住院患者中药（煎服法）与西药共处方的频繁项集、关联规则（支持度/置信度/提升度），及与诊断的关联。
- 目标试验要素：
  - 纳入标准 → ✅ CASE_NO + 医嘱
  - 治疗策略 → ✅ 医嘱（中药 138 条、含剂量 g 与日期；5/5 患者中西同用）
  - 分配机制 → ✅ 观察性（处方行为）
  - 时间零 → 不适用（横断面共处方篮）
  - 结局 → 规则（支持度/置信度/提升度）与后验浓度差
  - 因果对照 → 关联性陈述（明确非因果）
  - 分析计划 → ✅ Apriori/FP-Growth（模板 41947916、PMC11200891）；处方篮按"同一患者同住院期间"
- 缺项：中药处方无"使用依从"记录（住院给药，假设已执行）；汤剂实际饮用量不可知。
- 判定：**可行**（关联层）。**因果层见 Q4**。

## Q4 因果推断：中药暴露对 CYP2D6 底物浓度的影响
- 科学问题：合用中药煎剂（含 CYP 抑制成分的药材）是否使阿立哌唑代谢比（DHC/ARI）下降、浓度-剂量比（C/D）上升。
- 目标试验要素：
  - 纳入标准 → ✅ 有阿立哌唑浓度+医嘱
  - 治疗策略 → ✅ 中药医嘱（成分、剂量、起止）
  - 分配机制 → ✅ 观察性（医生处方）
  - 时间零 → ✅ 中药医嘱 START_DATETIME（精确分钟）；采样日 ≥ 中药开始后
  - 结局 → ✅ 代谢比/浓度（检验）
  - 因果对照 → 中药组 vs 非中药组（倾向评分/协变量调整）
  - 分析计划 → ⚠️ 需要足够暴露对照数；亚组按药材（活血/清热/补益）分组
- **缺项成本**：中药成分对 CYP2D6/3A4 的抑制证据目前仅体外/动物（PMID 25640685、26990021）；观察性设计无法排除处方指征混杂（医生给"代谢慢"的人少开补益药等）。但**效应方向与代谢比可测**：若样本中药组代谢比中位数差 > 组内变异即产生可发表的探索性证据。
- 判定：**部分可行（探索性）**；以"效应方向与幅度估计+置信区间"为目标，不做因果证明；MDE 见研究组合。

## Q5 因果推断（替代设计）：阿立哌唑浓度/代谢比对住院内结局的影响
- 科学问题：稳态浓度（或 C/D、代谢比）与住院期间体重轨迹斜率、血压变化的关系。
- 目标试验要素：
  - 纳入标准 → ✅ 有 ≥2 次体重（5/5 患者满足，样本共 22 条体重记录）+ 有浓度
  - 治疗策略 → ⚠️ 浓度作为暴露（检验），剂量为中间变量
  - 分配机制 → ✅ 观察性
  - 时间零 → ✅ 首次体重记录（IN_DATE 附近）
  - 结局 → ✅ 体重斜率（体征 RECORD_CONTENT 纵向）、血压斜率
  - 因果对照 → 浓度高/低组、代谢比表型组（表型=暴露）
  - 分析计划 → ⚠️ 混合模型（时间×浓度交互）；需按患者多次测量聚类
- **缺项成本**：住院时长中位 28 天左右（样本 15–49 天），体重变化量小（样本 ±1–4 kg）；浓度-增重关联若存在，效应量约为剂量-反应 meta（PMID 35137229）给出的 0.5–1 kg/6 周量级——住院窗内可测但需集中趋势估计。代谢比作为表型（0.17–0.49，2.8 倍跨度）是更强暴露。
- 判定：**可行（表型-代谢轨迹关联）**；以浓度（暴露）的**个体内变异（P4 +26%）**作为测量噪声上界。

## Q6 ADR 分析：体征轨迹作为结局的药物警戒
- 科学问题：哪些药物暴露与住院内体重增加、血压升高、心率变化相关；剂量-毒性信号（氯氮平>600、帕利哌酮>60 的超限浓度与体征的关系）。
- 目标试验要素：
  - 纳入标准 → ✅ 体征有 ≥2 点（体温150/脉搏150/呼吸150/血压53/体重22/血氧6/身高6 条）
  - 治疗策略 → ✅ 医嘱（药物、剂量、时间）
  - 分配机制 → ✅ 观察性
  - 时间零 → ✅ 首条体征
  - 结局 → ✅ 纵向体征（体重斜率、平均动脉压、心率）
  - 因果对照 → 暴露组间比较（氯氮平 vs 阿立哌唑等）
  - 分析计划 → ⚠️ 混合效应模型；暴露-时变协变量需注意时间对齐（体征记录时刻 vs 给药时间）
- 缺项：无实验室代谢参数（血糖/血脂/泌乳素）——**但体重轨迹（22 条）已可承担"代谢副作用"代理结局**（skill 规则：构造的代理结局是真实结局）。
- 判定：**可行**。

## Q7 公共数据库关联：C/D 分布与外部参考样本/自发报告对照
- 科学问题：本院 C/D 分布（分位数）与挪威参考样本 25/75 百分位（PMC11098931）、12 药汇编（Jönsson）是否可比；FAERS 信号方向与院内体征轨迹是否一致。
- 目标试验要素：不适用目标试验框架（基准对照研究）。
- 连接键：药物成分 + C/D 概念（见 external-linkage.md）。
- 判定：**可行**（需要规模化后正式对齐百分位；样本量：见 Q7 部分——C/D 分位数比较的精度由样本量决定）。

## Q8 多库文献分析：C/D/代谢比术语的文献计量与证据综合
- 科学问题：dose-corrected concentration / metabolic ratio 作为正式检索词在 PubMed 的发文量（文献计量实测：精确短语仅 3 篇，2020–2021）、证据分歧点（阿立哌唑代谢比与 CYP2D6 关联：支持者 PMC9755210 vs 存疑者 PMC11528948），本院数据在其中的位置。
- 判定：**可行（作为各课题的框架章节）**；不单独成文。

## Q9 描述性/审计：TDM 面板描述流行病学
- 科学问题：TDM 监测的适应症分布、采样-医嘱对齐率、面板附带检测发生率、范围外浓度比例（样本实测 5/6 ARI 样本在参考范围外）、医嘱调整与浓度监测的时序。
- 判定：**可行**；为 Q1–Q7 的"描述基线"章节，不作为独立论文推销。

## 判定汇总

| 问题 | 判定 | 决定性缺项 | 缺项是否经量化验证 |
|---|---|---|---|
| Q1 浓度/剂量预测 | 可行 | 给药时刻（≤20% 摆动 vs 3 倍信号）| 是：t½=75h 定量 |
| Q2 同类药 C/D 分布 | 可行 | 无 | — |
| Q3 中药-西药共处方 | 可行（关联层）| 汤剂实际饮用量 | 是：住院给药假设 |
| Q4 中药→浓度因果 | 部分可行（探索性）| 指征混杂；机制仅体外 | 是：效应方向可测 |
| Q5 浓度→代谢轨迹 | 可行 | 住院窗内效应量小 | 是：对照剂量-反应 meta 效应量 |
| Q6 体征轨迹 ADR | 可行 | 无实验室代谢参数 | 是：体重轨迹承担代理结局 |
| Q7 外部基准对照 | 可行（规模化后）| 样本量 | 分位数精度随 n 增长 |
| Q8 多库综合 | 可行（框架）| 无 | — |
| Q9 描述基线 | 可行 | 无 | — |

**不可行清单（含缺失字段）**：①基因型-表型正式分型（缺基因型字段；以代谢比表型替代，PMC9755210 支持）；②出院后临床结局（复发/PANSS）（缺院外随访；以住院内结局替代）；③给药后时间-浓度曲线拟合（缺给药时刻与多点采样；以稳态近似+敏感度分析替代）；④药物经济学（缺费用分项；FEE_TOTAL 单值且样本 5 行）。
