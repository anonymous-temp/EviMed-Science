# 数据质量报告（data quality）

按 Kahn (2016) 分类术语组织；每项标注 **verification**（对照元数据与本地知识）或 **validation**（对照外部基准）。
填充率口径一律为 Weiskopf 四义中的 **density completeness**（该字段在多少比例的行上有值），不涉及取值正确性。

源文件：`20260803TDM.xlsx`（sha256 `5b52d6d8...`），五张表：病案首页 5×38、医嘱记录 915×22、检验 22×12、诊断记录 56×11、体征 537×10。
样本为医院同一 schema 的结构样本，非研究人群；以下所有数量都是管道存在性证明，不是人群估计。

## 1. 一致性（Conformance）

### 1.1 值一致性（verification）

| 检查 | 结果 | 影响 |
|---|---|---|
| **诊断编码体系** | 至少 **3 套编码并存**：①ICD-10 含国标 x 扩展（`F20.400`、`B18.101`、`E22.100x001`），病案首页 MAIN 全部用此套；②中医病证码（`BNX071` 癫病、`BNG110`），出现在 OUTP_DIAGNOSIS_CODE 与诊断记录；③院内层级码（`A04.01.20.01`、`ZYTV10`、`ZZXP60`），仅诊断记录。诊断记录 45 个有值代码中 ICD-10 样 32、中医 10、其他 3 | 任何"按诊断分层"的分析必须先做编码归一化；跨套编码直接并表会错误合并 |
| **日期格式** | 全库 **day-first（日/月/年）**；任何列均未出现"同日列内 DMY 与 MDY 并存"（0 列冲突）；但日≤12 的条目单看有歧义（医嘱 START 517 条、END 447 条、体征 286 条落在歧义区） | 需以"同列强制 day-first 条目占多数 + 无反向强制条目"为据锁定约定并写入预处理；否则日期解析歧义会错位医嘱时间窗、使日剂量重建失效 |
| **哨兵日期** | 医嘱 `END_DATETIME` 105/915（11.5%）为 `0/0/0 00:00:00` | 该值 = "医嘱仍在执行/未停"；按"仍在执行"处理否则日剂量重建会丢失仍在用的药 |
| **年龄表示** | 病案首页 `AGE` 为文本 `56岁`，检验表 `AGE` 为整数 23 | 跨表按年龄分层前必须统一解析 |
| **过敏字段** | `DRUG_ALLERGY_MARK` 5/5 = 1（有过敏），但 `DRUG_ALLERGENS_NAME` 0/5 有值 | 过敏原名称缺失：任何"过敏史"分层只能使用标记，不能用名称 |
| **频率编码** | `FREQUENCY` 含 30+ 值：标准（QD/QN/BID/TID/QOD/ONCE/ALWAYS）+ 本地（`BID4`、`QD11`、`W4D8`、`W5D8`、`QD15`…） | 数字后缀是执行模板标识，不是"每日次数"；`BID4` 读作 BID×4 次/日会把日剂量翻倍——必须按解码表处理（见 §5） |
| **给药方式编码** | `MEDICATION_WAY` 含中药煎服法（`煎服`116、`先煎`12、`另包`9、`冲服`1）与西药途径（口服79、静滴12、外用216）及非给药（化验104、出院带药25、领药/退药6） | 中药-西药区分的第一判据；`出院带药` 医嘱不得计入住院期暴露 |

### 1.2 关系一致性（relational / cross-table 约束，verification）

| 检查 | 结果 | 影响 |
|---|---|---|
| **总浓度恒等式** | **总阿立哌唑 = 阿立哌唑 + 脱氢阿立哌唑，6/6 样本全部成立**（353.6+79→433、400+103→503、317+55→372、79.9+27.4→107.3≈107、100+26.6→126.6≈127、63+31→94，均在 0.5 ng/mL 舍入内） | 授权使用任一成分或三者互相校验；是 C/D 与代谢比计算的合法性依据 |
| **住院天数** | `DIS_DATE − IN_DATE` 与 `DAY_TOTAL`：3/5 一致；2/5 因 `DIS_DATE` 缺失不可算（`DAY_TOTAL`=18、15 提供权威天数） | 住院时长以 `DAY_TOTAL` 为权威字段，`IN_DATE` 为时间零 |
| **出生日期 vs 年龄** | 4/5 可核对（如 1964-06-18 ↔ 56 岁一致）；1/5 `BIRTHDATE` 缺失 | 缺失行年龄以 `AGE` 文本为准 |
| **连接键** | `PATIENT_ID` 五表同集合（5 人），**完全包含**；`CASE_NO` 五表同集合、两两交集 5/5 | **唯一例外：诊断记录 `PATIENT_ID` 填充率 0%**，但其 `CASE_NO` 满且与其余表交集 5/5 → 诊断记录只能经 `CASE_NO` 连接 |
| **类型冲突** | 跨表 `AGE`（文本 vs 整数）由 profile 脚本检出 1 处 | 预处理必须统一；否则跨表年龄分层静默失败、协变量回归失真 |

### 1.3 计算一致性（computational，verification）

- 检验 `TEST_RESULT` 与 `REFFR_SCOPE` 同行携带 → 范围内/外判定可逐行计算，无需外部表（结果见 Phase 2 派生量）。
- `SAMPLENO`（如 `20210104TDM014`）前 8 位 = 采样日期；与 `TEST_DATE` 对照：3/6 样本 `TEST_DATE` 缺失（P1/P3/P4 的 20210301/20210104 样本），SAMPLENO 日期是唯一采样日来源 → 采样日一律取 SAMPLENO 前缀。

## 3. 合理性（Plausibility，verification）

- **唯一性**：`DOCTOR_ORDER_ID`/`RECORD_ID` 均唯一；`SAMPLENO×PROJECT_NAME` 唯一（6 样本 × 每样本 3-6 项目）。
- **时间合理性（atemporal→temporal）**：医嘱 `START ≤ END`（END 哨兵除外）；`APPLY_DATE ≤ TEST_DATE`（检验 22/22 满足）；采样日均落在住院窗口内（P4 两次采样 12/21、1/4 ∈ 11/28–1/16 住院窗）。未发现采样日在住院窗外的行。
- **值域合理性**：阿立哌唑浓度 63–400 ng/mL 落在实验室线性范围内（对照 PMC9755210 报道的 HPLC 线性 10–1490 ng/mL 量级合理）；体重 54–82 kg、体温 36–37 量级合理。

## 4. 外部基准对照（validation）

- **参考范围与 AGNP 2017 一致**：检验表 阿立哌唑 100–350、总（ARI+DHC）150–500 ng/mL 与 AGNP 2017（PMC9755210 引用 Hiemke 2018）**逐字一致** → 该院参考范围直接可作 AGNP 兼容标准判据。
- **C/D 分布可对标的发表值**：奥氮平中国人群 C/D 中位数 2.73 (ng/mL)/(mg/d)、变异 64.1 倍（PMID 36286707）；氨磺必利中国 C/D 中位数 1.04（PMID 36863030）；阿立哌唑原型 C/D 尚无中文人群发表值——本研究 7.99–23.60 (ng/mL)/(mg/d) 与挪威 LCD/NCD 参考样本（PMC11098931）量级可比，但需在规模化后与 25/75 百分位正式对齐。

## 5. 强制预处理清单（mandatory preprocessing list）

每一项列出"不做的后果"——不做则哪些下游分析直接失效：

1. **日期统一解析为 datetime（day-first 约定）**，`0/0/0 00:00:00` → 标记为"医嘱仍在执行"（END=None）。*后果：日剂量重建（课题 Q1/Q3/Q5/Q6）全部失效；P4 同剂量两次采样 317→400 的个体内变异证据会因 END 哨兵被误排而丢失。*
2. **FREQUENCY 解码表**：QD/QN=1/日、BID=2/日、TID=3/日、QOD=0.5/日、WnD8=n/7 日、ONCE/ALWAYS=不可计日剂量、数字后缀忽略（模板标识）。*后果：`10mg BID4` 若按字面=40mg/日，C/D 差 2 倍，代谢比/浓度-剂量关联全部失真。*
3. **出院带药/领药/退药医嘱从住院暴露中剔除**（`MEDICATION_WAY`∈{出院带药,领药,退药} 或 `ORDER_STATE`=已作废）。*后果：出院带药计入采样日暴露会把"出院日"误作"治疗日"，P5 的 C/D 会变成伪值。*
4. **暴露=采样日在用医嘱重建**：日剂量 = Σ(DOSAGE × 频率/日) 对 START≤采样日≤(END 或 None) 的药品医嘱；检验面板附带检测（如 P2 未用阿立哌唑但 TDM 面板含 ARI 63 ng/mL）**不构成暴露**。*后果：不做此条，P2/P5 的"无暴露浓度"会被当暴露纳入，暴露-浓度关系被稀释。*
5. **诊断编码归一化**：ICD-10（含国标 x）→ 保留；中医 BN 码 → 标记 `TCM_BN`；院内层级码 → 标记 `local`；分析时按 `MAIN_DIAGNOSIS_CODE`（病案首页）或诊断记录经 CASE_NO 连接。*后果：三套编码直接并表会把 F20 精神分裂症与 BNX071 癫病混为不同诊断或重复诊断。*
6. **诊断记录经 `CASE_NO` 连接（PATIENT_ID 全空）**；其余表可经 PATIENT_ID 或 CASE_NO。*后果：不用 CASE_NO 则诊断信息完全丢失，任何诊断分层课题（Q2/Q4）无法开展。*
7. **年龄统一**：病案首页 `AGE` 文本（`56岁`）解析为整数；与检验表 AGE 对齐。*后果：跨表年龄分层（Q6 协变量）静默失败。*
8. **标识符掩蔽**：`PATIENT_ID`/`CASE_NO`/`DOCTOR_ORDER_ID`/`SAMPLENO`/`RECORD_ID` 一律不导出；分析内以稳定假名 P1–P5 指代（映射只在内存，不落盘）。*后果：任何泄露即违反本工作区隐私契约。*
9. **血压复合值拆分**（`129/74`→SBP/DBP 两列，53 条）。*后果：血压无法作为 ADR 分析（Q6）的纵向特征。*
10. **采样日统一取 `SAMPLENO` 前 8 位**（TEST_DATE 3/6 缺失）。*后果：暴露时间窗对不齐，C/D 重建错位。*
