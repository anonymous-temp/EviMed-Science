# 外部连接图（external linkage）

原则：每条连接必须写明 **连接键、粒度、它回答了哪些本数据单独回答不了的问题**、映射成本。"检索文献"不是连接。

## 标准词汇层（基础设施，先做）

| 资源 | 连接键（本数据字段）| 粒度 | 能回答什么 | 成本/注意 |
|---|---|---|---|---|
| **ATC 分类**（WHO） | `DRUG_NAME` 归一化后（如 阿立哌唑口崩片→N05AX12） | 药品→ATC 类 | 同类药分析（Q2）的类别聚合；跨药等效剂量沟通 | 需先建 DRUG_NAME→ATC 映射表（约 60-90 个西药名+中药名）；阿立哌唑片与口崩片同名不同厂商（国产/安律凡）→ 按成分合并 |
| **RxNorm**（已连通） | `DRUG_NAME` → RXCUI（阿立哌唑 RXCUI 1998453-1998463 等已验证可查） | 成分/剂型级 | 与 OMOP/OHDSI 词汇对齐；剂量换算（mg 一致性校验） | RXCUI 是美标，国产名（口崩片/安律凡）需人工映射一次 |
| **LOINC + UCUM** | `检验.PROJECT_CODE/PROJECT_NAME`（3018=阿立哌唑、0448=脱氢、0449=总等院内码） | 检验项→LOINC | 浓度数据标准化、跨院可比；**LOINC 不带单位，必须配 UCUM**（本项目单位已隐含 ng/mL，需显式声明） | 阿立哌唑血清浓度的 LOINC 码需查（常见 35821-5 阿立哌唑?需核）；院内码表是封闭的，映射一次后全院复用 |
| **ICD-10（国标扩展）** | `MAIN_DIAGNOSIS_CODE`（F20.400 等）、诊断记录 `DIAGNOSIS_CODE` | 诊断→ICD-10 | 人群定义（精神分裂症 F20/F25、双相 F31）；排除混杂诊断 | 三套编码并存（ICD-10/中医 BN/院内层级）必须先归一；ICD-10 国标 x 后缀（E22.100x001）需保留原码 |
| **PharmGKB/CPIC/DPWG** | `DRUG_NAME`（阿立哌唑）+ 表型（代谢比推导） | 基因-药对 | CYP2D6 表型→剂量建议的权威注释；本数据无基因型，但代谢比表型可与 CPIC 表型定义对照 | 本次运行 clinpgx-pharmgkb 连接返回 HTTP 404（部署缺口，已记录）；可改由 CPIC 公开页核对 |

## OMOP 迁移风险提示

按 OMOP 文档，"上坡"映射损失语义精度（其例：ICD-9 "bitten by goose"→SNOMED "pecked by bird"）。本项目风险点：①中医 BN 码与院内层级码无 OMOP 对应，需自定义 vocabulary 或降级为文本特征；②`FREQUENCY` 本地模板码（BID4/W4D8）在 OMOP 无对应，必须保留原码并附解码表；③检验项目院内码→LOINC 映射若错配（如 3018 阿立哌唑 vs 0448 脱氢）会直接污染浓度数据——映射后必须用"总=原型+代谢物"恒等式（6/6 成立）做自动校验。
