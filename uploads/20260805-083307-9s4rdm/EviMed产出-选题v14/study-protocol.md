# 研究协议（study protocol）

每个协议以"第二分析师无需提问即可执行"为标准：字段名、阈值、决策规则写死；敏感度分析承载假设；每节给前置条件与停止条件。

## 共享构造管道（所有协议先跑此管道）

**输入**：`20260803TDM.xlsx` 五表（规模化后同 schema 全量）。

**P0 日期**：正则 `^(\d{1,2})[-/](\d{1,2})[-/](\d{4})` 按 day-first 解析为 datetime；`0/0/0 00:00:00` → END=None（仍在执行）。
**P1 频率解码**：`QD|QN=1/日; BID=2/日; TID=3/日; QID=4/日; QOD=0.5/日; WnD8=n/7 日; ONCE|ALWAYS=不参与日剂量; 数字后缀=模板标识忽略`。解码集合记入敏感度。
**P2 暴露重建**：药品医嘱（DRUG_FLAG=1）且 `MEDICATION_WAY ∉ {出院带药,领药,退药}` 且 ORDER_STATE≠已作废；日剂量 = Σ(DOSAGE × 频率/日) 对 START≤t≤(END 或 ∞)。
**P3 采样日**：`SAMPLENO` 前 8 位 `YYYYMMDD`（不用 TEST_DATE，3/6 缺失）。
**P4 附带检测排除**：检验行若无对应药品医嘱在采样日生效，该药物浓度行标记 `incidental=True`；C/D 计算剔除 incidental 行（Q2/Q4/Q5/Q7 必需，Q9 专门计数其发生率）。
**P5 代谢比/C/D**：MR = 脱氢阿立哌唑/阿立哌唑；C/D = 阿立哌唑/日剂量。
**P6 假名**：PATIENT_ID 排序 → P1..Pn；映射仅内存，任何输出禁止出现源标识符。
**P7 恒等式校验**：每批数据先跑 总=原型+代谢物（允许 ±0.5 ng/mL），失败>0.5% 则停止（见各协议停止条件）。

**前置条件**：P0–P7 全部通过且打印校验报告。**停止条件**：P7 失败率>0.5%、P2 出现无法解码的 FREQUENCY 新值且无法归类、CASE_NO 连接失败（诊断记录无法并入）。

## 协议 Q1：浓度/达标剂量预测

- **人群**：成年（AGE≥18）住院患者，MAIN_DIAGNOSIS_CODE 以 F2/F3 开头（精神分裂症谱系/心境障碍），有 ≥1 次阿立哌唑稳态浓度（采样日 ≥ 医嘱开始后 14 天），暴露重建成功（非 incidental）。
- **结局**：log(阿立哌唑浓度)；达标概率 = P(100≤C≤350)。
- **特征**：AGE（解析整数）、SEX（1/2）、体重（体征表住院首条）、日剂量（P2）、CYP2D6 抑制剂合用标志（医嘱含氟西汀/帕罗西汀/安非他酮→strong；含舍曲林/西酞普兰→moderate；按 Flockhart 强度，引用 PMC11528948）、诊断类（F20/F31/其他）、既往 MR（若该患者有更早样本）。
- **模型**：A. Gradient boosting（特征≤12，10 折嵌套 CV，按患者分组）；B. 一房室 ARI+DARI 联合 PPK（结构照 PMC9755210：ka 固定 1.06/h，体重幂指数，表型分层协变量），Bayesian 个体化。
- **评价**：MAE（log 域）、R²、±30% 命中率、PTA；与 Zhu 2022（R²=0.54、命中率 63.4%）并列表格比较（注明人群差异）。
- **时间验证**：按采样年切分（早期训练/晚期测试）；随机 CV 只作辅助。
- **敏感度**：①采样时刻假设（谷 vs [0,24h] 均匀）重算；②FREQUENCY 解码集合上下界；③剔除 incidental 行 vs 保留为 0 暴露。
- **报告**：TRIPOD（模型 1a-1c 完整报告）；每特征部分依赖图。
- **前置条件**：≥300 患者、≥600 稳态测量。**停止条件**：稳态样本 <150；附带检测率 >30%（暴露定义失效）。

## 协议 Q2：同类药 C/D 分布与协变量

- **人群**：有浓度 + 暴露重建成功的检验-医嘱配对行（剔除 incidental）。
- **变量**：log C/D（因变量）；协变量 AGE（≥60 二分 + 连续）、SEX、丙戊酸合用、氯硝西泮合用、中药合用、剂量带（<10/10-15/>15 mg/d）、诊断类。
- **分析**：药物分层线性回归（log C/D）；分位数 bootstrap（1000 次）得 P25/P50/P75 与 CI；参考范围达标率（原型 100–350，AGNP 2017）按患者计数（多次采样取首稳态）。
- **输出表**：每药 n、中位 C/D、IQR、GMR(性别)、GMR(≥60)、GMR(丙戊酸)、达标率。
- **敏感度**：剔除丙戊酸合用者（丙戊酸已知诱导，PMID 36286707）；对数 vs 原始尺度。
- **前置条件**：阿立哌唑 ≥400 测量。**停止条件**：<200 测量（分位数精度不足，P25 SE>0.06 log）。

## 协议 Q3：中药-西药共处方关联挖掘

- **处方篮**：每 CASE_NO 住院期内，中药医嘱（MEDICATION_WAY∈{煎服,先煎,另包,冲服}）按 DRUG_NAME 聚合为中药篮；西药按成分（DRUG_NAME 归一化）聚合。
- **算法**：FP-Growth（最小支持度 5%，置信度 30%）；规则按提升度排序；多重比较用置换检验（固定行列边际重排 1000 次，规则级 FDR<0.05）。
- **输出**：top 20 中药味-西药规则（支持度/置信度/提升度/FDR）；CYP2D6/3A4 底物标注列（西药侧）；按煎服法分层重跑。
- **敏感度**：支持度阈值 3%/10% 重跑；仅长期医嘱（ORDER_TYPE=1）重跑。
- **前置条件**：≥400 患者、中药暴露率 ≥20%。**停止条件**：中药医嘱 <50 条（篮太稀）。

## 协议 Q4：中药共处方对代谢比/C/D 的影响（探索性）

- **人群**：阿立哌唑稳态浓度 + 代谢比可算的患者。
- **暴露**：采样日有 ≥1 条中药医嘱（按味或按方聚合）。
- **对照**：采样日无中药医嘱（同院、同年）；倾向评分（AGE、SEX、诊断、丙戊酸、氯硝西泮、剂量）最近邻 1:1 匹配。
- **结局**：log MR、log C/D；估计量：匹配后 GMR 与 95%CI。
- **配对亚组**：同一患者中药前/后各 ≥1 次采样（若有）→ 配对差。
- **阴性对照**：氯氮平（非 CYP2D6 底物）浓度-中药关联应为零（逻辑引 PMC11528948）。
- **敏感度**：E-value（未测混杂）；按药材类（活血/清热/补益）分层；剔除丙戊酸。
- **因果语言限制**：结论句只允许"与…相关（方向+区间）"，禁止"导致"。
- **前置条件**：≥200 患者（≥100/臂）。**停止条件**：中药臂 <60。

## 协议 Q5：浓度/表型对住院内代谢轨迹

- **人群**：≥2 次体重记录（体征 SIGN_TYPE=体重）+ ≥1 次浓度。
- **结局**：体重斜率（kg/周）：体重记录对采样日线性混合模型（患者随机截距+斜率）；血压斜率（SBP/DBP 拆分自 `129/74` 复合值，53 条样本）。
- **暴露**：log 浓度、MR 分层（P25/P75 三分）、C/D。
- **模型**：`体重 ~ 时间×暴露 + AGE + SEX + 诊断 + 剂量`（LMM，患者随机效应）；报告暴露×时间交互系数（kg/周 per log 浓度）。
- **验证**：仅 ≥3 点重跑；剔除出院前 3 天体重；阴性对照=体温斜率。
- **前置条件**：≥150/组（暴露高低组）。**停止条件**：体重中位点 <2/人（轨迹不可估）。

## 协议 Q6：住院 ADR 扫描（SCCS）

- **结局事件**：临床增重（体重 +2 kg/月）、MAP>110 首次事件、HR>100 首次事件。
- **暴露期**：医嘱窗（START–END）；浓度超限事件（检验 vs REFFR_SCOPE 超上限）。
- **设计**：自我对照病例系列（SCCS）：事件发生者在暴露期 vs 非暴露期的人时比较（IRR，条件泊松）；氯氮平/阿立哌唑/帕利哌酮分层。
- **输出**：每药 IRR（体重/MAP/HR 事件）与 95%CI；超限浓度并发表。
- **敏感度**：暴露窗 ±7 天偏移；删除多药重叠期。
- **前置条件**：每药 ≥50 暴露期、事件合计 ≥60。**停止条件**：总事件 <30。

## 协议 Q7：外部基准对照

- **对照 1**：PMC11098931 参考样本（147,964 测量）的 25/75 百分位 C/D——按药物成分对齐（ARI 活性部分定义需一致：用总浓度/日剂量，注明单位换算 nmol/L↔ng/mL：ARI 分子量 448.4，DHC 447.4）。
- **对照 2**：Jönsson 2018 12 药汇编 ARI 分布。
- **对照 3**：FAERS（经公开 API）ARI/氯氮平/帕利哌酮"weight increased"PT 的 ROR/PRR 方向 vs 本院轨迹方向（符号一致性）。
- **分析**：Q-Q 图 + 百分位表；本数据点标注在医院版本日期。
- **前置条件**：≥400 ARI 测量。**停止条件**：单位换算无法核验（浓度单位须从检验科确认 ng/mL）。

- RECORD 6.2：人群选择用码需在正文注明编码来源（ICD-10 国标）；7.1：暴露/结局/协变量完整码表；12.3：外部连接方法与质量。
- RECORD-PE 7.1.c：暴露时间窗与左截断；19.1.a：数据库对目标药物暴露的捕获完整性（附带检测发生率作为捕获质量指标）。

- 不做基于观测数据的功效回算（Hoenig & Heisey 2001）；按 MDE 与预期区间宽度计划（Bland 2009，见 research-portfolio）。
