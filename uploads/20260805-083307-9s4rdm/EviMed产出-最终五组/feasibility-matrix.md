# 候选问题 × 目标试验矩阵（feasibility-matrix.md）

框架：Hernán 2016 目标试验七要素 + TARGET 报告规范（Cashin 2025）。逐项标 ✅（字段可实施）/⚠️（需推断）/❌（缺字段，且已量化该缺口是否真正束缚设计）。**本文件的行数是字段结构的样本，不是研究人群**；所有"规模化 n"见 research-portfolio.md。

---

## C1. 未知采血时刻下的稳态暴露重建（群体药动学 + 贝叶斯 MAP）
- 入组标准 → ✅ 病案首页.MAIN_DIAGNOSIS_CODE ∈ F20/F31 + 医嘱记录.DRUG_NAME 归一=阿立哌唑 + 检验.PROJECT_NAME=阿立哌唑/总
- 治疗策略 → ⚠️ 实际处方（医嘱记录.START/END_DATETIME），无给药执行记录（依从性按区间处理）
- 分配机制 → ✅ 观察性，按实际处方
- 时间零点 → ✅ 采血日期=SAMPLENO 内嵌 YYYYMMDD；⚠️ 采血**钟点**未知
- 结局 → ✅ 浓度本身（TEST_RESULT）
- 因果对比 → ——（估计性研究：CL/F、稳态谷浓度）
- 分析计划 → ✅ popPK（NONMEM/NLMIXR）+ MAP-Bayesian；日剂量=医嘱.DOSAGE×前缀频率
- **缺口量化**：日内时刻未知是否束缚？阿立哌唑 t½≈75 h、QD 给药，给药间隔内浓度摆动约 exp(−ln2×24/75)≈0.80（±20%），而本样本个体间 C/D 跨度 2.95 倍、个体内波动 26%——未知钟点比信号小一个数量级，**不束缚**。处理：把时刻编码为给药间隔内位置区间（0–24 h），做区间似然/敏感性分析（模拟峰-谷摆动 ±20%）。
- **判定：可行**（估计性设计，不是假设检验）。缺失字段：采血钟点（不束缚，敏感性覆盖）。

## C2. 早期浓度→稳态/最优剂量预测（并入 C1，见合并说明）
- 与 C1 共用数据路径（检验×医嘱）与估计量族（popPK/贝叶斯预测）；作为 C1 的**验证性子分析**（用第 1 次样本预测后续稳态浓度，对照后续实测）。最接近工作：FTD 0000000000358（第 1 周浓度预测最优剂量）。
- **判定：并入 C1**（共用估计量与数据路径，按用户规则合并为一个研究的两部分）。

## C3. 西药合并用药对阿立哌唑 C/D 的影响（DDI，含表型代理）
- 入组标准 → ✅ 同 C1（有 ≥1 次稳态 C/D 的阿立哌唑患者）
- 治疗策略 → ⚠️ 暴露=采血日在院合并用药集合（医嘱记录，分子归一后；酶抑制/诱导剂按 ATC/RxNorm 类）
- 分配机制 → ✅ 观察性（非随机合并用药）
- 时间零点 → ✅ 采血日期（SAMPLENO）
- 结局 → ✅ log C/D（TEST_RESULT ÷ 日剂量）
- 因果对比 → DDI 对比：合并用药组 vs 非合并用药组（调整年龄/性别/体重/吸烟代理）
- 分析计划 → ✅ 线性混合模型（患者随机截距）+ 多药同时纳入；DHA/ARI 代谢比作 CYP2D6 表型代理（机制中介）
- **判定：可行**。约束：需稳态样本（P1 类非稳态样本剔除或敏感性纳入）；P2 类无在院医嘱行标记 exposure_unmatched。

## C4. TDM 结果→剂量调整的反馈回路（浓度指导实践质量）
- 入组标准 → ✅ 检验.PROJECT_NAME∈TDM 项目 + 有结果日期
- 治疗策略 → ⚠️ 实际剂量变更（医嘱记录 DOSAGE/FREQUENCY 变更，同分子新医嘱）
- 分配机制 → ✅ 观察性
- 时间零点 → ✅ TEST_DATE（结果回报日）
- 结局 → ✅ 7 天内同分子剂量变更（是/否）+ 至变更时间（天）
- 因果对比 → 超范围样本 vs 范围内样本的剂量变更概率/时间（实践回路对比，非疗效因果）
- 分析计划 → ✅ 时变暴露 Cox（时间=变更）+ 逻辑回归；与移植/肿瘤的"制度性浓度指导"文献作基准对照
- **判定：可行**。样本上已见：6 次阿立哌唑检验后 7 天内仅 1 次有剂量变更——回路存在但响应稀疏，正是 G3 的问题素材。

## C5. 抗精神病药类级 C/D 群体分布与个体内变异比较（并入 G6 描述层）
- 类级比较（跨药 C/D 百分位、个体内变异），数据路径=检验×医嘱，与 C1 部分重叠但估计量为混合模型分层描述。
- **判定：并入 G6**（作为 G6 的"多药位置"分析；阿立哌唑主分析，奥氮平/氯氮平/帕利哌酮在规模化样本下补充——样本中仅 P2 有 4 药面板，单药 n=1，只能作管线存在性证明）。

## C6. 不规则纵向体重轨迹与抗精神病药暴露 → 代谢表型
- 入组标准 → ✅ 体征.SIGN_TYPE=体重 ≥2 次 + 医嘱暴露
- 治疗策略 → ⚠️ 抗精神病药暴露（分子/剂量/累积天数），TCM 作协变量
- 分配机制 → ✅ 观察性
- 时间零点 → ✅ 首次体重记录（RECORD_DATE）
- 结局 → ✅ 体重轨迹斜率 / ≥7% 增重（RECORD_CONTENT，kg，去重后）
- 因果对比 → 暴露-增重关联（剂量-反应）
- 分析计划 → ✅ 线性混合模型（时间×暴露）+ GRU-D 式缺失处理对照（重症信息学借源）；不规则间隔用时间协方差
- **判定：可行**。样本上：22 条体重记录、每患者 3–7 条、P4 六周 +2 kg、P2 四周 −4 kg（方向性信号存在）。

## C7. 暴露-不良反应关联（TDM 样本内）+ FAERS 外部三角互证
- 入组标准 → ✅ 有 TDM 检验患者 + 诊断记录（RECORD_DATE 可定位）
- 治疗策略 → ⚠️ 抗精神病药暴露（浓度 C/D 为连续暴露）
- 分配机制 → ✅ 观察性
- 时间零点 → ✅ 诊断记录.RECORD_DATE（ADR 代理诊断：高泌乳素血症/肌张力障碍/迟发性运动障碍/肝功能不全/低钾血症）
- 结局 → ✅ 代理诊断事件（诊断记录.DIAGNOSTIC_NAME 匹配；OTHER_DIAGNOSIS_NAME 辅助）
- 因果对比 → 高暴露 vs 低暴露的 ADR 诊断风险（logistic/Cox，EPV≥10）
- 分析计划 → ✅ 逻辑回归 + 时间窗；外部 FAERS 不均衡（ROR/PRR/IC）作为并行信号源
- **判定：可行**（暴露-反应关联，非因果裁定）。样本已见：高泌乳素血症、肌张力障碍、迟发性运动障碍、肝功能不全在诊断字段出现；氯氮平 721 ng/mL 超 600 上限。

## C8. 采样实践审计 + 多库证据定位（描述性+多库合成）
- 入组标准 → ✅ 全部 TDM 检验行
- 治疗策略 → ——（审计，无干预）
- 分配机制 → ——（审计设计无分配：不设干预，目标试验分配要素不适用）
- 时间零点 → ✅ APPLY_DATE/TEST_DATE/SAMPLENO
- 结局 → ✅ 采样适宜性维度：是否稳态（距剂量变更 ≥14 天）、是否谷浓度（无法确认→区间标注）、适应症（医嘱/诊断上下文）、重复采样
- 因果对比 → ——（审计无干预对比：仅描述与定位，不作因果声明）
- 分析计划 → ✅ 描述性统计 + 与 AGNP/中国共识/注册库百分位对照 + 与肿瘤（5-FU：53% 不在目标窗）跨域对照
- **判定：可行**。样本已见：P1 采样日=剂量变更第 1 天（未稳态）；母药 3/5 超范围；C/D 7.99–23.60。

- 药品共处方篮子（医嘱记录分子集）× 检验/诊断；作为 G2 协变量选择与 G5 混杂识别的辅助分析（Apriori/FP-Growth）。**并入 G2**。

## C10. TDM 指导剂量调整 vs 常规调整对临床结局的影响（因果疗效题）
- 入组标准 → ✅
- 治疗策略 → ⚠️ 可推断
- 分配机制 → ⚠️（实际处方可推断；但疗效结局缺失使分配-结局对比无法构建，见结局行）
- 时间零点 → ✅
- 结局 → ❌ **无结局量表字段**：五表均无 PANSS/BPRS/CGI 等疗效量表，也无结构化功能结局；住院时长（DAY_TOTAL）与 31 天内再入院（REIN_AFTER31_MARK）是仅有的粗糙代理
- 因果对比 → ❌ 疗效对比无法构建
- 分析计划 → ——（因结局字段缺失无法制定疗效对比分析计划，见判定）
- **缺口量化（束缚性检验）**：该估计量是"浓度指导 vs 常规"对疗效结局的对比，疗效结局在本 schema 中任何一表都不存在（病案首页只有诊断/费用/时长，无评分量表）；代理结局（LOS）受疾病严重度与系统因素混杂，且无法区分疗效与安全转归——**缺口真实束缚**，非一般性规则可绕过。
- **判定：不可行。缺失字段：疗效结局量表字段（PANSS/BPRS/CGI 或等价的纵向功能评分）。**
- **仍可回答的最强问题**：C3（合并用药→浓度）、C4（浓度→剂量调整回路）、C5（类级 C/D 分布）——即暴露层与过程层问题全部可行，只有"浓度→症状结局"一层被缺失字段卡住；若医院另备量表数据（同一患者标识可连），C10 立即复活，时间零点与暴露变量已就绪。

## 删除方向（用户决策 + 数据证据）
- **中药-西药相互作用方向：删除。** 理由：(a) 用户明确要求删除；(b) 数据证据：饮片医嘱（煎服/先煎/副药，173 行）以克重入方、多为复方（石菖蒲/珍珠母/薄荷/制远志/柴胡…）、煎煮法影响煎出率，**单体暴露量不可量化**，与西药 TDM 的"剂量-浓度"精确计量不在同一度量体系；(c) 任何"饮片 g→暴露"假设的误差都大于可检验的效应。**中药保留为协变量/混杂因素**（方剂数、饮片总克重负担），进入 C6/C7 的调整变量集。
- **C2/C9 合并**：C2 并入 C1（共用 popPK 估计量族与检验×医嘱数据路径）；C9 并入 G2（共处方挖掘仅作协变量构造步骤，不单独成题）。
- **小综述判定为"已被回答"而删除的候选**：无。六个方向的最近工作在方法上均有未覆盖轴（逐条见 research-portfolio.md 新颖性行）；C5 类级比较因样本中非阿立哌唑药仅 P2 面板 1 行/药，降级为 G6 的描述层而非独立题。
