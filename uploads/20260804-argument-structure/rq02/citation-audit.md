# 引文审计（citation-audit）

本审计记录临床证据合成运行（含服务端门禁修订轮）的引文核验情况。审计日期：2026-08-04。

## 审计执行情况

本轮最终纳入 5 个可保留工件来源、生成 20 条主张（16 条直接主张、2 条合成主张、2 条推导主张）。全部主张的 artifactPath 均指向本环境实际保留的工件（4 篇开放获取全文 + 1 份官方页面）。每条主张的引用与来源逐项核验如下。

## 1. 未解析标识符（unresolved）

- **全部纳入来源均可解析并已保留为工件**：NHS 页面（经批准网关抓取，`.evimed-sources/official-pages/f60ccb4779eccff7/page.md`）；4 篇开放获取全文经 Europe PMC XML 落盘（`.evimed-sources/PMC8287819/fulltext.md`、`PMC4548722/fulltext.md`、`PMC12733498/fulltext.md`、`PMC13094172/fulltext.md`）。
- **著者元数据未完整获取**：PMC 导出的 Markdown 不含作者字段，经 PubMed 连接器核对亦未返回作者列表；因此参考文献 3（Drug Des Devel Ther 2015）、4（J Cardiovasc Dev Dis 2025）、5（Int J Emerg Med 2026）以题名+期刊+年+DOI/PMID/PMCID 著录，未补造作者名；参考文献 2（Trials 2021）的著者取自早期文献检索记录（Ruan X 等）。此缺失在审计中如实登记。
- **部分中文指南的期刊卷期页码未核验**（参考文献 6-10）：以发布主体+标题+年份著录，未补造缺失元数据。

## 2. 重复（duplicate）

- 去重工具对候选记录按 DOI/PMID/URL/规范化标题去重；纳入来源之间无重复。
- 检索阶段观察到跨数据库重复（如 2025 ACC/AHA ACS 指南在 PubMed 出现 Circulation 版/JACC 版两条 PMID 记录、2021 胸痛指南在多个来源重复出现），均已合并为单一处理，未重复计入；其中 2025 指南与 2021 指南最终因全文不可获取未纳入主张来源（经 JCDD 综述转述其版本存在性，见 CLM-011）。

## 3. 更正/撤稿（correction / retraction）

## 5. 主张-来源匹配（claim-source mismatch）

- **支持引文全部取自已保留工件的原文**：4 篇全文工件的 verbatim 段落（含以"…"标注的省略，每侧均核验）与 NHS 官方页工件原文；引用规则为逐字引用+省略号标记，未跨句拼接省略限定语。
- **访问层级如实标注**：4 篇为 `full_text`，NHS 为 `official_page`；无将摘要/题录冒充全文的情形。
- **转述性证据已明确标注**：AHA/ACC 与 ESC 指南条文（CLM-001～004、017）以开放获取综述（PMC4548722）的逐字转述为证据载体，不确定性字段与报告正文均注明"非原指南 PDF 逐字核验"；2025 指南版本事实（CLM-011）与 ESC 2023 更新（CLM-010）同理。
- **急救呼叫类主张的引文同时含呼叫动作与症状条件**：CLM-015（NHS）引文含 "Call 999 if: … chest … does not go away" 与 "Call 999 straight away"；CLM-002 引文含 "should call 9-1-1 immediately" 与 "if no relief occurs, or if pain worsens 5 minutes after taking one nitroglycerin dose"。
- **数字-引文绑定**：每条主张中的数字（0.3–0.6 mg、5 分钟、1.2 mg、15 分钟、3 次、0.4 mg、30 min、7.5%、3.0%–7.0%、90 min、120 min、100 min、60%、2–24 h、324、5 粒/次、24 周、0.5 mg）均出现在其支持引文或来源标识（PMID/PMCID）中；文献出版年份（2015/2021/2025/2026）出现在参考文献著录与来源元数据中，未强求进入引文。
- **合成主张（CLM-017、CLM-018）各含 2 个独立保留工件来源**，其引文分别来自 PMC4548722 与 NHS 工件、PMC12733498 与 PMC13094172 工件；未以同一工件重复计数。
- **推导主张（CLM-019、CLM-020）**在矩阵中公开计算过程（method/assumptions/sensitivity），报告中以〔推导〕标注，未进入"安全优先的实际处置"；其输入主张（CLM-003、CLM-005、CLM-006、CLM-007）均为可核验直接主张。

服务端门禁要求每一条主张绑定已保留工件。经两轮全面保留尝试（开放获取全文 12 次调用、官方页面 8 次调用），以下类别的原主张因无法取得可保留工件而被删除或重构：
