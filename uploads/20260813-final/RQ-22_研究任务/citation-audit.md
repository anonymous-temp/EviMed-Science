## 已执行核验

- **标识符解析**：对每条纳入来源核对 DOI、PMID、PMCID 与标题、期刊、年份是否一致。证据矩阵所引工件标识符为 PMID:34281600 / PMCID:PMC8287819 / DOI:10.1186/s13063-021-05448-6，PMID:36103477 / PMCID:PMC9473420 / DOI:10.1371/journal.pone.0273567，PMID:38123611 / PMCID:PMC10733430 / DOI:10.1038/s41598-023-47502-0，PMID:31253098 / PMCID:PMC6599358 / DOI:10.1186/s12872-019-1133-0，以及 NHS 胸痛页面（nhs.uk/symptoms/chest-pain，2023-08-08 复核），均已逐条核验。PubMed/Europe PMC/Crossref 检索返回的题录均与所保存工件或题录逐条对照。
- **去重**：以 DOI、PMID、URL、规范化标题四重去重。`10.1002/14651858.cd004473`（条目记录）与 `10.1002/14651858.cd004473.pub2`（更新版）为同一 Cochrane 综述的两条记录，仅保留 pub2 版（PMID 18254051）作为参考文献。
- **更正/撤稿**：对纳入来源逐一核对 PubMed 与 Crossref 元数据，未检出更正、关注声明或撤稿标记（correction/retraction 均未检出）。
- **元数据局限**：见下节。
- **主张—来源匹配**：证据矩阵中每个直接主张的 `supportQuote` 均已与所保存工件逐字核对（claim-source 匹配通过）；综合主张（CLM-015）的两条支撑引文分别来自两个不同工件。
