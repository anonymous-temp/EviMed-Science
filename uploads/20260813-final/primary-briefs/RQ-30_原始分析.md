# RQ-30 原始数据分析任务

## 选题

**《心血管检查前的预防性备药：检查用药严重过敏与心脏事件的报告不成比例分析，与检查相关焦虑干预注册试验的全量普查》**

## 研究背景

年度体检或心脏影像学检查之前，受检者在随身物品里备一盒速效救心丸的做法并不少见，理由多被表述为"加一道保险"或缓解检查前的紧张，而备药者往往并无冠心病诊断。这一做法把两类彼此独立的问题收在同一枚药片上：一是检查本身携带多大风险，二是检查前的焦虑该由什么手段处置。两个问题都被大量转述过，却很少有人回到可计数的原始数据上核对——检查风险的讨论通常停在"造影剂过敏很罕见"或"负荷试验有一定风险"这类没有量级的措辞上，检查前焦虑的处置讨论则停在推荐清单的罗列上，很少有人问过：以检查前焦虑为对象的干预试验，全世界一共注册了多少项、终点在过去二十年里是否发生过迁移、其中有没有一项以中成药为干预。

这两个问题都能用公开数据真算。检查用药（碘造影剂、负荷试验用药、心脏磁共振用钆对比剂）在美国不良事件报告系统中有充足的报告量，可以逐个药物、逐个事件术语构造四格表，算出报告比值比及其区间，并按统一判据判定信号——这给出的是"检查本身携带的用药风险"在报告层面的量化排序。检查前焦虑的干预试验可以在国际临床试验注册库中做**全量普查**（不是抽样、不是综述），逐条抽取干预类型、主要终点、样本量、申办方与结果发布状态，得出可证伪的计数与趋势。同时，本品自身在注册库与不良事件库中的可检索记录也应逐条列出——这是本研究里唯一属于**直接证据**的部分，无论其计数是多少，都应当照实报出，而不是绕过去。

需要预先讲清一件事：本研究中关于造影剂与负荷用药的全部结果，描述的是**检查本身所用药物**的报告特征，与本品无关，不构成本品在围检查期使用的安全性依据、必要性依据或其反面。这一标注必须落到每一处引用，不得只在局限性里提一句。

## 需要回答的问题

1. 在 openFDA FAERS 中，碘造影剂（iohexol、iopamidol、ioversol、iodixanol、iopromide）、负荷试验用药（regadenoson、dipyridamole、dobutamine、adenosine）与心脏磁共振用钆对比剂（gadobutrol、gadoterate meglumine）分别与严重过敏类 MedDRA 首选术语（Anaphylactic reaction、Anaphylactoid reaction、Anaphylactic shock、Hypersensitivity）之间，报告比值比（ROR）、报告比例比（PRR）、Yates 校正卡方与信息成分（IC）各为多少？哪些药物—事件对达到 EVANS 信号判据？按 ROR 排序，各检查用药的次序如何？
2. 同一组药物与心脏事件类首选术语（Cardiac arrest、Myocardial infarction、Ventricular fibrillation、Hypotension、Dyspnoea、Death）之间的报告不成比例程度分别是多少？无创负荷用药与碘造影剂两类之间，各事件的 ROR 置信区间是否重叠——即"检查是安全的"这句话能否合并成一句安全性陈述，还是必须按检查类型分列？
3. 上述每一种检查用药的报告总数是多少？前两问所列事件在其全部报告中的构成比与严重性标记分布如何？把取数区间切成三个时间段分别重算，四格表与 ROR 是否稳定？
4. 在国际临床试验注册库中，以检查前／操作前焦虑为对象的注册干预试验共有多少项？按首次登记年份的年度计数、干预类型构成（结构化告知与信息提供、行为与心理干预、音乐干预、催眠、短效镇静药物、其他）、主要终点构成（焦虑量表评分、生理指标、检查完成率、图像质量、镇静用药量、其他）、样本量分布、申办方类型与国家构成、以及已发布结果的比例分别为何？
5. 上述普查范围内，以中成药或植物药为干预、以检查相关焦虑为主要终点的注册记录有多少条？以心血管检查围检查期预防性给药为设计的注册记录有多少条？这两个计数（无论是否为零）是本研究的可证伪产出。
6. 检查前焦虑干预试验的主要终点构成随注册年份是否发生迁移——量表评分类终点的占比与操作性终点（检查完成率、图像质量、镇静用药量）的占比在二十年间如何变化？趋势检验的统计量、效应量与区间估计为何？
7. 以速效救心丸（含其拼音名与常见英文转写）为干预或研究药物的注册记录，在国际注册库中共有多少条？其纳入人群、对照设置、主要终点、样本量、状态与结果发布情况分别为何？其中有无以焦虑、情绪症状或围检查期场景为终点或场景者？在 openFDA FAERS 中可检索到的提及本品的报告共有几份，逐份的报告编号、报告国、年份、药物角色与首选术语为何？

## 数据与方法要求

**数据源。** 不良事件侧取自 openFDA `/drug/event.json`；注册试验侧取自 ClinicalTrials.gov API v2 的研究检索端点。两侧一律经公开接口取数，逐次请求留痕。

**四格表的构造方式必须逐格写明，并可被逐格复算。** 每一个药物—事件对用四次独立检索读取命中总数：N（全库报告总数）、N_D（含该药的报告数）、N_E（含该事件首选术语的报告数）、a（同时含二者的报告数）；派生 b = N_D − a、c = N_E − a、d = N − a − b − c。交付前逐位校验 a + b = N_D、a + c = N_E，并另发一次 `NOT 药 AND NOT 事件` 检索直接取 d 与减法结果逐位比对，不一致即视为取数失败，该行不得进入结果表。药物腿的字段选择必须显式声明并固定：以标准化通用名字段为主分析，同时报出药品名称字段口径的计数作为敏感性分析——两个口径给出的数不同，不写明用了哪个，读者无法复算。造影剂与对比剂的商品名众多，成分名与商品名的对应关系须先做一次归一并把归一表随交付。

**统计量与判据。** ROR = ad/bc，95% 置信区间取 exp(ln ROR ± 1.96 × sqrt(1/a + 1/b + 1/c + 1/d))；PRR = [a/(a+b)] / [c/(c+d)]；卡方取 Yates 连续性校正值；IC 按标准信息成分定义计算并报出 IC025。信号判定用 EVANS 判据（PRR ≥ 2 且 Yates 校正卡方 ≥ 4 且 a ≥ 3），三条分别报出通过与否。EVANS 不是显著性检验，须另给卡方对应的原始 p 值，并对整个"药物 × 首选术语"面板做 Benjamini-Hochberg 多重比较校正（FDR 0.05），原始 p 与校正后 p 同表并列，结论以校正后为准。第 2 问中"能否合并为一句安全性陈述"由两类药物同一事件的 ROR 置信区间是否重叠回答，须明确写出比较的是区间重叠而非点估计大小。

**术语必须先验证再计数。** openFDA 对未匹配的检索词返回的是"无记录"，在下游会呈现为 0，与真正的零报告无法区分，极易被写成一个理直气壮的阴性发现。面板中任何一个返回 0 的首选术语，必须补发一次术语确认检索（对反应术语字段做精确值聚合），判定其为"真零"还是"不是有效术语"；未经确认的 0 不得进入结果表，更不得写入结论。所有 `count=` 聚合目标字段一律使用精确值形式——对文本字段直接聚合会被接口以"文本字段未针对聚合优化"拒绝。

**注册库普查必须是全量普查，不是检索示例。** 分页须循环取尽（按返回的下一页令牌逐页请求直到耗尽），并记录接口报出的匹配总数与实际取回条数，两者不一致即须说明原因；不得以第一页结果代表全体。每条记录至少抽取：注册号、简要标题、状态、研究类型、期别、入组人数、开始日期、完成日期、主要终点措辞、是否已发布结果、申办方名称、实施国家、随机化设计、主要目的、干预类型与干预名称、纳入病种。检索式须**逐条列出原文**（照抄即可发送），至少覆盖三组：检查前／操作前焦虑 × 心血管检查；焦虑 × 冠脉造影／冠脉 CTA／负荷试验／心脏超声；本品名称及其拼音与英文转写。按注册号去重，去重前后的条数都要报。**干预类型与终点类型的归类必须由事先写定的关键词规则完成，规则文件随交付**，每条记录须留下其被归入某一类所依据的命中关键词；凭阅读印象的人工判断不得作为分类依据，因为它不可复现。

**趋势检验。** 第 6 问按首次登记年份分组，以"主要终点是否为操作性终点"为二分结局，做 Cochran-Armitage 趋势检验；同时以年份为连续自变量做 logistic 回归，报出每增加一年的比值比及其 95% 置信区间。年度计数小于 5 的年份须合并并写明合并规则。

**取数预算。** 失衡分析主面板约为 11 种药物 × 10 个首选术语，加术语验证、字段口径敏感性分析与三个时间段重算，请求量在数百次量级，处于匿名调用配额（每 IP 每日一千次）之内；注册库普查按页计，须先报出预计页数。若扩充面板，须先重估请求数并写进方法学部分。

**取证尺度对称。** 本研究由本品学术内容合作方委托，正因如此，提示有利的结果与提示不利的结果必须适用同一取数口径、同一统计判据、同一多重比较校正与同一敏感性分析集合，不得对某一方向额外增设或减免检验。全文不预设方向：既不预设应当备药，也不预设不应备药；第 5、7 问的计数无论是零还是非零，都照实报出并按同一规则解读。直接证据（第 7 问，本品自身的注册记录与报告记录）与桥接证据（第 1—3 问，检查用药的报告特征；第 4—6 问，检查前焦虑干预的研究议程）在全文中分列陈述，每一处桥接都必须标注其为桥接及桥接对象是谁，不得让读者以为它们说的是同一件事。

## 这项分析回答不了什么

以下六条必须原文写入论文的局限性部分，且不得以更弱的措辞替代。

其一，**报告比不是发生率**。FAERS 是自发报告系统，没有暴露分母；ROR、PRR、IC 全部是报告层面的比值。"碘造影剂严重过敏的发生率为百分之几"这类陈述本设计一概给不出，检查风险的绝对值仍须由分母明确的登记研究或前瞻队列提供。

其二，**药物之间的 ROR 排序不是风险排序**。上市时长、使用量、适应场景、报告制度与报告文化的差异都会进入报告比；第 1 问产出的次序是报告层面的次序，不能读作"哪种造影剂更危险"。第 3 问的时间段重算只能检验结果稳定性，不能消除这一混杂。

其三，**注册库普查反映的是研究议程，不是临床实践，更不是疗效证据**。第 4、6 问的计数与趋势说明的是"研究者在研究什么、终点怎么变"，不说明任何一种干预有效或无效。

其四，**阴性计数的含义必须限定**。第 5、7 问若得到零或极小的计数，只说明在本次普查所覆盖的注册库与检索式范围内未见登记，不说明该研究未开展、也不说明该干预无效。中国注册的试验多登记于中国临床试验注册中心，该库不在本次可及范围内，普查结果**系统性低估中国研究量**，全部结论须限定为"在国际注册库可见的范围内"。

其五，**备药这件事本身没有可挖的数据层**。"受检者或陪同者自带急救药物是否改变检查中不良事件结局"需要以备药行为为暴露的前瞻队列或整群随机试验，此类研究未见开展，公开数据中不存在；本设计不产出任何相关估计。同理，本品能否缓解检查前焦虑，第 5、7 问只能给出注册记录的计数，给不出效应量。

其六，**监管、伦理与超说明书规范部分不属于本任务**。适应症覆盖范围、知情同意、安慰性用药的规范条款只存在于法规与规范原文中，是文本溯源工作，没有数据层可挖；本研究不得以任何计算结果去回答这类问题，也不得用机制或常识推理填补。

## 检索范围

openFDA `/drug/event.json` 与 ClinicalTrials.gov API v2。所有取数经上述公开接口完成，逐条记录完整请求地址与参数、发起时刻（UTC）、HTTP 状态、返回体字节数与返回体的 SHA-256、以及该次请求所得的命中总数或匹配总数。本研究不开展新的临床试验，不获取个体病例层面资料。以下来源不在可及范围内，其缺失对结论的影响方向须在局限性中写明：中国临床试验注册中心无可用接口，中国注册的检查前焦虑干预试验与本品的中国注册试验均不在普查覆盖内；中国国家药品不良反应监测系统无开放接口；中文全文数据库不可访问；本品的中国核准说明书无公开全文接口。

## 交付

一篇面向临床医师与药师的中文学术论文，按摘要／引言／数据与方法／结果／讨论／局限性／结论／临床实践要点／参考文献组织。结果部分按三节分列并分别标注其适用对象与证据类型：检查用药的报告不成比例分析（桥接证据，对象为检查本身所用药物）、检查前焦虑干预的注册试验普查（桥接证据，对象为研究议程）、本品自身的注册与报告记录普查（直接证据，对象为本品）。三节不得互相代表，也不得由其中之一推出另一节的结论。

论文之外，须同时交付四件可复算材料，缺一不可——原始数据分析的可信性不来自可引用的原文，来自读者能照着重跑一遍：

1. **查询清单**，逐条列出本研究发出的每一次请求：完整请求地址与全部参数（照抄即可发送，不得改写为自然语言描述）、请求方法、发起时刻（UTC）、HTTP 状态、返回体字节数、返回体 SHA-256、该次请求返回的命中总数或匹配总数；注册库普查的每一页请求（含分页令牌）、术语验证请求、敏感性分析请求与失败重试同样逐条在列。
2. **原始返回体保存件**，与查询清单逐条一一对应，按其 SHA-256 命名归档。
3. **结果表**（CSV，两张）。失衡分析表每行至少含：药物、成分归一后名称、首选术语、a、b、c、d、N_D、N_E、N、ROR、ROR 下限、ROR 上限、PRR、Yates 校正卡方、原始 p、BH 校正 p、IC、IC025、EVANS 三条判据各自的通过与否、药物腿字段口径、取数时刻、该行所依据的四条查询地址。注册普查表每行一条注册记录，含上文所列全部抽取字段、其被归入的干预类型与终点类型、以及归类所命中的关键词。另附成分名—商品名归一表与分类关键词规则文件。
4. **分析脚本**，只读取保存件、不联网、确定性运行；第三方在本机重跑该脚本，产出须与两张结果表逐项一致（数值容差 1e-9）。

另须随交付写明**数据版本**：openFDA 返回的库最后更新时间与全库报告总数、每次检索的命中总数；ClinicalTrials.gov 的接口版本、每条检索式的匹配总数、取回条数与页数、取数日期。论文正文与图表中出现的每一个数值，都必须能在结果表中找到对应行；只存在于正文而不在结果表中的数字一律视为未经复算，不得出现。原始计数（a、b、c、d 与三个总数、各项注册记录计数）必须与算出的比值、比例、趋势估计一并呈现，不得只给算完的结果。参考文献与外部资料逐条给出可核验标识（DOI、PMID、注册号，或说明书与指南的正式名称及版本年份）。
