# RQ-06 研究任务（派发给 EviMedScience 产品管线的原始题面）

题库中的语义问题 ⑥ 与复方丹参滴丸对比（涉及 P1 P7），转化为的学术研究命题。

---

## 派发题面

请撰写一篇学术研究报告：

**《速效救心丸与复方丹参滴丸的可核验差异：适应症、起效特征与证据强度的对比评价，并追溯"可连续服用 3 个月"说法的出处》**

研究背景与待回答的问题：

1. 两药在**说明书层面**的适应症、用法用量、疗程与禁忌分别是什么？差异是否可核验？
2. 两药的**起效特征**（给药途径、达峰时间、作用机制）有哪些经研究验证的差异？证据类型与强度如何？
3. 两药各自的临床证据强度如何？是否存在**头对头比较研究**？若无，现有间接比较（网络 meta 分析等）的可信度如何？
4. "本品可连续服用 3 个月"这一说法的**出处是什么**——说明书、指南、共识、临床研究，还是营销材料？能否追溯到可核验的来源？若不能，应如何表述才准确？

写作要求：

- 面向临床医师与药师的学术论文；按摘要—背景—方法—结果—讨论—局限—结论组织。
- 对每一项"差异"必须给出可核验来源；无法核验的差异不得写入结论。
- 第 4 问是本报告的核心之一：若检索不到该说法的权威出处，必须明确写出"未能追溯到可核验来源"，不得以合理推断代替出处。
- 不得在缺乏头对头证据时暗示某一药物优于另一药物。
