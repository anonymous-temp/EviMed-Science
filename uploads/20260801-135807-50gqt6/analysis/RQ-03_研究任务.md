# RQ-03 研究任务（派发给 EviMedScience 产品管线的原始题面）

题库中的语义问题 ③ 长期安全性与副作用（涉及 P1 P5），转化为的学术研究命题。

---

## 派发题面

请撰写一篇学术研究报告：

**《速效救心丸长期用药（≥3 个月）的有效性与安全性证据评价：证据强度分级与适用人群边界》**

研究背景与待回答的问题：

1. 速效救心丸连续服用 3 个月及以上的**有效性**证据有哪些？各研究的设计、样本量、疗程、终点指标与偏倚风险如何？按 GRADE 或同类框架，证据强度处于什么等级？
2. 长期用药的**安全性**证据是什么？已报告的不良反应谱、发生率、严重不良事件、停药率分别如何？是否有主动监测或上市后安全性研究数据？
3. 组方中冰片（龙脑）与川芎的长期暴露是否存在已知的安全性关注点（如肝肾功能、消化道刺激、妊娠期禁忌）？现有证据能否支持或排除这些关注？
4. 何种人群适合长期服用、何种人群不适合？说明书、指南与共识各自划定的适用边界是什么？彼此是否一致？

写作要求：

- 面向临床医师与药师的学术论文；按摘要—背景—方法—结果—讨论—局限—结论组织。
- 严格区分"有效性证据"与"安全性证据"，二者的证据等级分别评定，不得以有效性证据充当安全性证据。
- 缺乏长期安全性数据本身是一项重要结论，若检索确实不足，必须明确写出缺口，不以短期数据外推补齐。
- 涉及禁忌与用药边界的表述须与说明书及现行指南一致。
