# RQ-02 研究任务（派发给 EviMedScience 产品管线的原始题面）

题库中的语义问题 ② 症状初现与应急求助（涉及 P6），转化为的学术研究命题。

---

## 派发题面

请撰写一篇学术研究报告：

**《急性胸痛自救用药后症状不缓解的时间阈值与升级路径：现行指南界定的证据基础与一致性分析》**

研究背景与待回答的问题：

1. 舌下含服硝酸甘油后，现行指南（AHA/ACC、ESC、中国相关指南与共识）对"症状不缓解应升级处置"的**时间阈值**分别如何界定？各阈值的证据来源与推荐强度是什么？彼此是否一致？
2. 速效救心丸的说明书与相关共识是否给出对应的时间阈值？若给出，其证据基础是什么？
3. 支撑这些阈值的证据是什么类型——病理生理学推断、观察性研究，还是临床试验？"时间就是心肌"的定量证据（延迟时间与心肌损失/死亡率的关系）如何？
4. 升级路径应包含哪些具体步骤？在中国场景下，指南推荐的行动次序与呼叫 120 的相对位置是什么？

写作要求：

- 面向临床医师与药师的学术论文；按摘要—背景—方法—结果—讨论—局限—结论组织。
- 不同指南的阈值若不一致，须逐一列出来源与差异，不得取其一代表全部。
- 明确区分"有阈值推荐"与"该阈值有试验证据支持"两件事。
- 涉及急救行为的表述须与现行指南一致，任何自救用药不得被表述为可延迟呼叫急救的理由。
