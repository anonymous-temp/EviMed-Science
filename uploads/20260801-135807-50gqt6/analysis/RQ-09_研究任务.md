# RQ-09 研究任务（派发给 EviMedScience 产品管线的原始题面）

题库中的语义问题 ⑨ 含服后舌麻（涉及 P2），转化为的学术研究命题。

选它作为压力测试的原因：这一命题的直接临床证据很可能稀薄。合格的输出应当明确写出证据缺口，
而不是用药理机制推断填充成看似充分的结论。

## 派发题面

请撰写一篇学术研究报告：

**《舌下含服速效救心丸引起的舌部麻木感：药理机制、临床意义，及其能否作为药效指标的证据评价》**

研究背景与待回答的问题：

1. 舌下含服速效救心丸后出现舌部麻木、灼热或刺激感的**药理机制**是什么？与组方中冰片（龙脑）的
   TRPM8/TRPA1 等受体作用、局部黏膜刺激或其他机制的关系，现有证据支持到什么程度？
2. 该主观感受与药物的**吸收程度或临床疗效**之间，是否存在任何已被研究验证的相关性？
3. "舌麻说明药起效了"这一说法在临床上是否成立？将主观局部感受用作药效指标存在哪些推理谬误与
   实际风险（例如据此判断是否需要追加剂量或是否需要就医）？
4. 舌部麻木在何种情况下应被视为不良反应或过敏征兆而非正常现象？说明书与现有文献如何界定？

写作要求：

- 面向临床医师与药师的学术论文；按摘要—背景—方法—结果—讨论—局限—结论组织。
- **若直接临床证据不足，必须明确写出"未检索到直接证据"及其范围**，并说明基于机制的推断只能达到
  何种确定性等级；不得以药理机制推断冒充临床证据。
- 明确区分三类不同强度的命题：机制上可解释、有相关性研究支持、有临床终点证据支持。
- 涉及"是否需要就医"的表述须与急性胸痛处置的现行指南一致。
