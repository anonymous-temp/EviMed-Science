# RQ-21 研究任务（派发给 EviMedScience 产品管线的原始题面）

题库中的语义问题 ⑥ 高原场景（涉及 P4），转化为的学术研究命题。

---

## 派发题面

请撰写一篇学术研究报告：

**《高原低氧暴露诱发心肌缺血的病理生理机制，及速效救心丸用于高原场景是否具备适应症内临床证据的分层评价》**

研究背景与待回答的问题：

1. 高原低压性低氧暴露诱发心肌缺血的病理生理路径包含哪些环节——交感激活与心率-血压乘积升高、冠状动脉血流储备下降、低氧性肺血管收缩与右心负荷增加、红细胞增多与血液黏度升高、内皮功能障碍——每一环节分别由何种研究类型（人体高原暴露实验、模拟低氧舱研究、动物模型、流行病学队列）支持，证据强度到什么程度？
2. 高原暴露人群中急性冠脉事件与心绞痛的发生率是否高于平原对照？高原环境下"胸闷、心慌、气短"的病因分布如何，与急性高山病、高原肺水肿、高原心脏病等以低氧为共同背景但实体不同的疾病在临床表现与处置上如何区分？
3. 速效救心丸现行 NMPA 说明书的适应症、功能主治、用法用量、禁忌与注意事项原文如何表述？其适应症边界（气滞血瘀型胸痹心痛、冠心病心绞痛）是否涵盖高原暴露、高原反应预防或健康人群的低氧耐受？是否存在与高原场景相关的已批准适应症或注册记录？
4. 是否存在在高原环境（须记录海拔高度与暴露时长）下开展、以本品为干预的临床研究或试验注册记录？其受试人群是否落在说明书适应症内，终点、对照、样本量与结论分别是什么？
5. 现行高原医学指南与共识对既往确诊冠心病者赴高原的风险评估与用药建议是什么？是否有指南推荐任何中成药用于高原场景的预防或自救，其推荐强度与证据等级如何？

写作要求：

- 面向临床医师与药师的学术论文；按摘要—背景—方法—结果—讨论—局限—结论组织。
- **必须先依据说明书原文界定适应症边界，再判断"高原场景"这一人群/情境是否落在该边界之内**；两步不得合并，也不得以问题库预设的目标答案作为论证起点。
- 若高原场景落在适应症边界之外，结论必须写明"无适应症内证据"，并将其与"机制上可解释"分别陈述；**不得以高原低氧的病理生理推理代替本品在该场景的临床证据**。
- 明确区分三类强度不同的命题：机制上可解释；在适应症内人群中有临床证据；在高原环境下有临床终点证据。
- 检索限于 PubMed、Europe PMC、Crossref、NMPA 说明书索引、指南索引与临床试验注册库；只采用可定位的文献、法规与说明书记录，检索式、数据源与命中数须在方法部分列出。
- 涉及高原胸痛处置、是否就医与是否下撤的表述，须与现行高原医学指南及急性胸痛处置指南保持一致。

## 判定条件

- **肯定结论成立的条件**：仅当检索到在明确海拔与暴露时长的高原环境下开展、受试人群落在说明书适应症内、以临床终点或经验证的替代终点为结局的对照研究时，方可作出"本品在高原场景可用/有效"的肯定表述，并须同时给出研究设计、样本量与效应量。
- **证据不足时的降级表述**：若仅有平原人群的适应症内证据加高原低氧的机制推理，判定为"无高原场景的适应症内证据"，表述降级为"说明书适应症限于气滞血瘀型胸痹心痛（冠心病心绞痛），未检索到高原场景下的适应症内临床证据"；不得改写为"可用于高原""有助于缓解高原反应"一类表述。
- **检索结果为阴性时**：须明写"未检索到"及其覆盖的数据源与检索式，并声明阴性检索只支持"不存在已发表证据"，不支持"不存在效应"。
- **说明书出处**：适应症边界须引用现行说明书原文并标注可核验来源；若无法定位现行版本，明写"未能追溯到可核验出处"，不得以既往版本或二手转述替代。
- **逐条判定**：对该语义群目标答案中的每一条主张，给出"支持 / 部分支持 / 不支持 / 无证据"四类判定之一，并附判定依据。
